# 星轨投放助手

腾讯 ADQ 开户准备、投放诊断、出价分析、广告创意与投后复盘。一个标准 Agent Skill，配套官方知识资料、素材索引、客户模板及报表脚本。

## 安装

以下命令在电脑终端执行，适用于安装器支持的本地 Agent。**不支持豆包安装，不要粘贴到豆包普通聊天框。** 豆包使用手册中的附件对话流程；本项目尚未验证豆包原生 Skill 导入。

电脑安装 Node.js LTS 和 Git 后，进入目标项目文件夹，在终端执行：

```bash
npx -y skills add tonyliu2525-code/xinggui-adq-assistant -y
```

自动识别本机已安装且受支持的 Agent，安装完整技能，无需逐个指定。完成后重新加载技能或新建对话。更新时运行同一命令；客户资料另存到项目目录。安装器尚未支持的平台，可在原生技能入口导入完整目录。

## 使用

> 使用星轨投放助手。请根据业务资料、后台设置和同周期报表，提供具体调整方案与观察条件。

## 运行环境

读取规则与模板不依赖脚本。自动核算使用 Python 3 标准库；知识库检索使用 Node.js。截图理解、联网与图片生成由所用 Agent 提供。账户操作由客户执行；未连接腾讯 API。官方资料及第三方素材按来源说明和实际授权使用。
