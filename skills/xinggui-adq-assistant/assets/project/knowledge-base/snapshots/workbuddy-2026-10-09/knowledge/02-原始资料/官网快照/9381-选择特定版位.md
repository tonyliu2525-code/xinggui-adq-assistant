# 一、能力介绍

区别于【自动版位】，【选择特定版位】允许客户指定主要投放的流量版位，帮助客户更灵活地满足特定营销场景。



# 二、选择特定版位

## 1. 选择特定版位：允许客户指定主要投放的流量版位

### 1.1. 当前展示营销支持流量版位：

* 微信视频号

* 微信朋友圈

* 微信公众号与小程序（微信公众号与小程序；微信新闻插件）

* 腾讯平台与内容媒体（QQ浏览器；QQ、腾讯音乐及游戏；腾讯新闻；腾讯视频）

* 腾讯营销联盟

* PCQQ、QQ空间、腾讯音乐、PC腾讯视频

* 腾讯视频电视端

* QQ购物



### 1.2. 当前搜索营销支持流量版位：

* 微信搜一搜

* QQ浏览器等







其中，微信视频号、微信朋友圈、微信公众号与小程序（微信公众号与小程序；微信新闻插件）、腾讯平台与内容媒体（QQ浏览器；QQ、腾讯音乐及游戏；腾讯新闻；腾讯视频）、腾讯营销联盟 版位已全量支持全流量通投，**推荐客户投放版位时同时选中进行通投**。



# 三、全流量通投

## 1. 流程精简门槛降低、快捷投放无压力

### 1.1. 一条投放腾讯营销全媒体，无需分版位创建多条营销

客户可通过一条营销触达腾讯营销所有主流流量版位，相比以往需要针对不同版位创建多条营销，效率倍增。



### 1.2. 创意形式标准统一，一套素材覆盖所有流量

针对客户此前需针对不同媒体版位需准备多套素材的痛点，腾讯营销对全流量创意形式及对应素材进行了标准化拉通，并通过系统衍生能力智能适配更多素材。客户使用一套视频/图片素材，文案，落地页即可覆盖全流量。



## 2. 数据打通，全局调优，起量达成效能更佳

除了投放环节的打通和精简，腾讯营销投放平台在全流量的调价策略和预估模型也实现了统一。这意味着单营销下可用的数据样本更多、数据积累速度更快，从而大大提高了模型预估的准确性，客户可以更快地度过冷启动，进一步优化营销起量率和效果达成率。







### 2.1. 新营销探索更充分

通投营销冷启动探索时会充分参考其他流量的跑量情况，累计转化数据，使冷启动探索更精准充分

### 2.2. 跨流量样本复用，效果预估更准确

通投营销的样本跨流量复用，在多个流量同时累积样本，模型积累转化的速度比单投快，bias收敛更快，预估效果更好





### 2.3. 全局达成调优

通投从全局视角保证营销整体成本达成，通过跨流量协同风控调价，整体成本达成率更高



## 3. 赔付政策降门槛，成本保障更有力

为最大程度降低客户超成本的风险，针对通投场景，腾讯营销升级了赔付政策，统一 oCPX 赔付的转化数门槛。在保障周期内，只要通投营销总计有 6 个转化，且满足[腾讯营销投放平台赔付政策](https://support.e.qq.com/detail?cid=3773&pid=2004)，即可自动赔付。

# 四、使用门槛

不同流量版位存在行业、政策门槛。若发现部分版位无法投放，请联系您的运营经理。



# 五、操作说明

## 1. 版位选择

在投放流程【营销版位】中选择【选择特定版位】，即可选择营销优先投放的版位。选择后，投放流程右侧会显示对应版位示意图与预估覆盖人群和曝光量级。





## 2. 创意投放

创意投放流程中，建议使用【自动匹配】创意形式投放模式，并打开【自动衍生更多素材】，让系统自动适配更多尺寸素材，覆盖更多流量。



若使用【手动指定】创意形式投放模式，建议选择带有【通投】角标的创意形式，使营销可覆盖全流量版位。





## 3. 分版位数据报表查看

客户也可随时查看分版位的效果数据，获取数据趋势和数据报表，可通过投放平台 -【报表】-【效果数据】，或通过【推广】-【推广计划、营销、营销创意管理列表】-【更多】-【查看数据】进入相关页面。





# 六、常见问题

**Q1：目前有哪些版位支持一条营销同时通投？**



A1：目前，微信视频号、微信朋友圈、微信公众号与小程序（微信公众号与小程序；微信新闻插件）、腾讯平台与内容媒体（QQ浏览器；QQ、腾讯音乐及游戏；腾讯新闻；腾讯视频）、腾讯营销联盟 版位已全量支持全流量通投。建议客户投放时同时选择上述全部流量，帮助营销达到更优效果。



**Q2：发现部分版位无法投放？**



A2：不同流量版位存在行业、政策门槛。若发现部分版位无法投放，请联系您的运营经理。
