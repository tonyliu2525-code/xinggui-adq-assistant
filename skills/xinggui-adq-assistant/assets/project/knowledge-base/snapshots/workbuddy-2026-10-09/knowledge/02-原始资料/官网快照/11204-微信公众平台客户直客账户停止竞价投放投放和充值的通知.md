# 微信公众平台客户直客账户停止竞价投放投放和充值的通知

| *更新日期* | *2025年1月8日* | *内容更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

基于营销平台投放模式全面升级，平台计划对微信公众平台客户直客账户停止提供竞价投放服务和充值服务。

为确保您账户内资金能够继续用于投放，您可以选择将微信公众平台客户直客账户中的余额迁移至您的腾讯营销投放平台账户。
# 注意事项：
1. 合约投放暂不受影响，但我们仍建议您提前迁移至ADQ账户进行投放，体验更灵活高效的投放系统
2. 账户登录及账号内历史数据查看功能暂不受影响，您可以继续访问和查看您的账户历史信息
3. 若有其他咨询，请[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)了解具体情况

#
***以下为具体指引：***
## 第一步：前往腾讯营销投放平台开户
腾讯营销投放平台（ad.qq.com），是为客户提供的一站式投放系统，可触达腾讯生态包括微信朋友圈、微信公众号与小程序、QQ、腾讯信息流、腾讯音乐、腾讯新闻与腾讯视频、腾讯营销联盟等全域流量，以及QQ浏览器等和搜一搜的搜索资源。同时，涵盖营销优化、数据分析、创意生产、托管投放等功能，帮助客户实现营销推广的目标。
* 如果您没有腾讯营销投放平台账户，请[根据指引开户](https://support.e.qq.com/detail?cid=3744&pid=10175)
* 如果您已经有腾讯营销投放平台账户，请跳过此步骤
### 此步骤注意事项
* 请在开户后完成账户认证，以激活投放和财务功能

## 第二步：回到微信公众平台执行划转
1. 操作入口：微信公众平台—客户—账户—财务信息—资金迁移
![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/396_20250108161935_217109.png)
2. 资金迁移：
*  输入资金要迁入的ADQ账户
* 确认可迁移的资金账户余额
![image2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/396_20250108161939_612016.png)

3. 确认迁入资金：账户符合规则可立即完成迁移，您可登录相应的ADQ账户查看迁入资金情况。
![image3.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/396_20250108161943_797247.png)

### 此步骤注意事项
* 迁移账户需满足当天账户无消耗
* 迁移后的账户需满足平台规则要求：账户审核通过、身份验证通过、保证金通过
* 迁移后的资金遵循原有的有效期限制，如资金本身设有有效期，迁移至ADQ账户后资金的有效期将保持不变，继续生效

## 第三步：前往腾讯营销投放平台确认资金划转到账

### 邮件申请注意事项
* 邮件发起划转时，需同时将账户内所有资金类型的所有金额全部完成迁移，不能仅划转部分资金或部分金额
