# 腾讯营销 电子发票退票

| *更新日期* | *2025-3-10* | *自助退票上线* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您需要 对已开具的数电发票申请退票，请通过以下方式发起：

# 线上自助退票
*
## 功能入口

**客户**	登录腾讯营销投放管理平台 → 顶端“财务”标签 → 二级导航栏“发票管理” → 进入发票管理板块

**服务商** 登录腾讯营销服务商系统 → 顶端“财务”标签 → 二级导航栏“发票管理” → 进入发票管理板块

*注：以上平台，仅限账户超级管理员、管理员和财务人员，可进入发票管理板块查询和提交开票*

*
## 操作指引
### 发起申请
在“发票管理”标签页查询已开具发票的记录，选择需要退票的订单，在操作栏点击“退票”，进入退票页面

* **需退票的已开具发票信息展示**
* 开票类型：

“现金开票”即现金账户预充交易的已开具发票

“信用金开票”即信用金账户消耗的已开具发票

* 充值月份 & 消耗月份：

“现金开票”按月开票，显示已开具发票的充值的月份

“信用金开票”跨月开票，显示已开具发票的消耗阶段

* 开票金额：

已开具发票的开票金额

* **填写退票申请**
* 红字确认单号：

请输入已在税务系统税局乐企平台开具的红字确认单编号

* 退票金额：

不支持部分退票，展示退票金额即已开具发票的开票总金额

* 退票原因：

请根据实际情况选择您的退票原因

* 退票申请备注：

若有补充信息，请填写备注

* **确认纳税人信息**
* 纳税人信息必须与税务登记、企业开户许可证保证一致
* 若展示信息与实际不符，请点击“编辑”进行信息更新
* 务必在退票申请提交前，复核完整的纳税人信息，避免退票失败

### 获取发票
在“退票查询”标签页，展示了账户的退票申请记录，当退票状态更新为“已退票”，即可点击“查询”预览开具的负数发票（红字发票），下载PDF、XML和OFD格式的发票文件

*
## 注意事项
* 因数据限制，2024年1月1日前开具的发票，无法使用线上自助退票功能，请按以下邮件退票方式进行退票申请
* 若申请人发起申请后未在处理时效内收到反馈，或对反馈结果有异议的，请主动[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)了解具体情况
* 以上仅针对营销充值和投放开具的发票进行退票，保证金退票请前往保证金管理平台进行咨询

## 退票材料
发起退票申请时，请提供以下材料：

* **需退票的电子发票蓝票PDF**
* 所有退票需求均需提供已开票PDF
* **提供《红字信息确认单》**
* 仅针对专票且已认证需要提供
* 进入电子税务局的红字发票开具模块，选择红字信息确认单录入
* 查询选择需要冲抵的发票
* 开具《红字信息确认单》
* 截图并附于退票申请邮件中

## 处理流程
1. 客户发送邮件并提供相关材料
2. 收到邮件和完整的材料后，政管中心发起退票流程
3. 税务处理票据
4. 10个工作日内处理完毕
