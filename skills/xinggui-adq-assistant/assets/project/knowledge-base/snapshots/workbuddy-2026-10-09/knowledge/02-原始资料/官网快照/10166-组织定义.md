# 1、组织定义

| 集团 | 存在合作关系的组织合集（可以是政策集团 或能提供合作关系的主体集合等）  |
| -------- | --------
| 主体  | 即企业类客户唯一营业执照/个人类客户唯一身份证对应主体，管理实体  |
| 业务单元 | 一个虚拟的营销组织集合，可关联相关组织信息（如账户、成员等），并实现数据资产、资金等资源的共享 |
