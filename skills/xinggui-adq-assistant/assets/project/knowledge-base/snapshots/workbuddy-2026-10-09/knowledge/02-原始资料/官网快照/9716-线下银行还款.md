# 腾讯营销 线下转账还款

| *更新日期* | *2023-11-20* | *内容更新* |
| -------- | -------- | -------- |

您好，若您需要对信用账户进行还款，且无法通过线上还款方式自助还款，请通过以下方式：

## 对公转账

请按照帮助中心内[《腾讯营销常用主体信息》](https://support.e.qq.com/detail?cid=4089&pid=9087)提供的银行信息进行转账

转账后，需发起线下付款核销流程，对营销应收进行核销后，才视为完整的还款过程

## 注意事项

* 请优先使用线上自助还款功能进行划转，请参照帮助中心内[《线上自助还款》](https://support.e.qq.com/detail?cid=4073&pid=9714)；
* 非平台消耗只能通过线下方式进行还款；
* 请每期还款时完整核对账单邮件，确保应还款账单完整、全量的进行还款，避免因遗漏造成的逾期扣罚。
