## 投放营销涉及【世界杯】需要提供相应授权
## 一、 基础规则
##

1. 在未经授权的情况下，客户生产、销售的商品、及营销营销活动中不得使用世界杯相关元素

| **元素示例** |   |
| -------- | -------- | -------- |
| ![世界杯产品1.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108152203_991244.png)   | ![世界杯产品2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108152241_640297.png)  |
| **X 未授权使用世界杯相关元素**   | **X 未授权使用世界杯相关元素**  |

2.  未经授权的情况下，任何主体不得使用世界杯元素作为商业名称、企业名称、公众号名称等

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![世界杯名义1.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108152856_241893.png)     | ![世界杯名义2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108152910_212200.png)  |
| **X 未授权名称使用世界杯元素**   | **X 未授权头像/图片使用世界杯元素**    |

3. 未经授权的情况下，营销落地页不得使用世界杯相关元素及名义作为网站域名

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![世界杯网站.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108153821_630744.png)   | ![世界杯网站2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108153839_987297.png)   |
| **X 未授权营销落地页使用世界杯域名**   | **X 未授权营销落地页使用世界杯域名**    |

4. 未经授权不得使用参赛运动员、教练员、训练员或官员的肖像、姓名、图片或运动成绩作为营销元素出现

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![世界杯球星.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108153955_509773.png)     | ![世界杯球星2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108154010_521009.png)     |
| **X 未授权使用参赛运动员肖像/名义**   | **X 未授权使用参赛运动员肖像/名义**    |

5. 营销中不支持以世界杯门票作为奖品进行抽奖、促销等任何形式的促销、竞赛或抽奖奖品

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![世界杯抽奖1.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108154137_429477.png)    | ![世界杯抽奖2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108154157_584916.png)    |
| **X 世界杯门票促销奖品**   | **X 世界杯门票抽奖奖品**    |

6.  未经授权不得擅自宣传可直播转播世界杯赛事，需有国际足球联合会的授权

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![世界杯直播1.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108154836_336991.png)   | ![世界杯直播2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108154859_789945.png)     |
| **X  未授权直播世界杯赛事**   | **X  未授权直播世界杯赛事**    |

7. 营销中不支持变形或模仿世界杯相关元素，需要客户提供明确的官方授权文件

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![世界杯周边产品.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155101_034627.png)    | ![世界杯周边产品2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155116_206758.png)    |
| **X  变形/模仿世界杯元素**   | **X  变形/模仿世界杯吉祥物**    |

8. 需国际足球联合会官方授权可使用的描述：为世界杯加油

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![世界杯口号.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155340_833832.png)   |![世界杯口号2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155400_177047.png)    |
| **X  未授权使用“为世界杯加油”描述**   | **X  未授权使用“为世界杯加油”描述**    |

9. FIFA权益人享有以营销或推广目的使用FIFA官方标志的排他性权利，除了官方授权的FIFA权益人，其他企业均不可以合作伙伴或赞助商的身份进行营销宣传

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![世界杯赞助商1.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155526_027700.png)   | ![世界杯赞助商2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155556_942776.png)     |
| **X  未授权使用赞助商身份进行宣传**   |**X  1. 未授权使用世界杯相关元素    X  2. 未经授权不得售卖官方纪念币**  |

10. 任何与FIFA、比赛、仪式、主题曲等音视频、影视材料、文字材料等，未经FIFA授权不可使用

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![比赛录像1.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155647_323553.png)    | ![比赛录像2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155703_437665.png)     |
| **X  未授权使用售卖世界杯影视资料**   | **X  未授权使用售卖世界杯影视资料**    |

11.  其他使用世界杯元素进行隐性营销的，即故意或无意地与世界杯创造虚假的、引人误解的商业联系，误导公众，使公众认为其与世界杯、国际足球联合会 具有商业合作关系或与世界杯标志权利人之间有赞助或者其他支持关系的情况，均需要核实是否有授权或者合作关系

| **元素示例** |  |  |
| -------- | -------- | -------- |
| ![蹭热点1.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155755_709761.png)    | ![蹭热点2.png](https://bbx-pic.gtimg.com/bbx/pictures/2022/282_20221108155807_420543.png)     |
| **X  使用世界杯元素进行隐性营销**   | **X  使用世界杯元素进行隐性营销**    |

**声明：本文中的素材仅为说明审核要点之目的，请勿做其他用途**
