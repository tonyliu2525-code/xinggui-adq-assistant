# 一、推广产品是什么

**推广产品一句话概括指的是您投放营销时主要想推广以及考核是什么？比如具体的产品、服务等**。  

➢**举例：** 短剧客户想要推广一款“热门短剧”，那其推广产品就是“短剧产品”。



“**推广产品”在营销层级里位于【营销内容】模块**，该模块主要用于帮助客户输入完整的营销营销表达，模块整体包括以下信息：  

1、营销目的（即您本次推广希望达成的核心目标是什么？为了商品销售还是线索留咨等等）  

2、推广产品（即如上所述，基于您的业务场景此次推广考核的最小单元是什么？）  

3、营销载体（即用户点击营销完成转化行为的必经场景，通常是落地内的交互载体）  

4、优化目标（即您希望通过营销来获取的具体转化行为，比如点击、注册、下单等等）  

推广产品作为该营销内容模块重中之重的一环，是客户在腾讯营销进行精准投放的核心资产之一。

# 二、推广产品有什么用

**推广产品是腾讯营销中用于帮助客户精准匹配目标人群、优化营销策略和提升转化效果的核心资产**，它不是冷冰冰的系统后台选项，而是直接影响营销效果的关键杠杆。选对推广产品可以实现：  

● 精准锁定目标人群，提高投放效率。推广产品内置行业标签和人群模型，更精准匹配高意向人群，减少手动调节试错成本。选对产品=系统帮您过滤不相关人群，减少预算浪费。  

● 优化营销策略，提升投放效果。推广产品支持对产品信息进行标准化录入和管理，选对推广产品使系统模型准确理解产品特征，从而帮助您匹配对应正确的营销形态和计费方式。



简而言之，**推广产品=您的营销武器，选对了才能高效起量**。先明确目标，再匹配产品，最后动态优化，这才是优化师的正确姿势。（如果您是新手，可一定要先想清楚自己要什么这个核心目标，再开始后台配置哦～）



# 三、创建、使用推广产品的关键步骤

## 1、明确创建入口

每一个资产库都有对应的最高效便捷的创建入口，平台目前一共支持4种创建入口：  

●客户工作台  

●全域商品平台  

●投放管理平台  

●微信小店

## 2、创建推广产品

找到正确入口后就要创建资产啦，绝大部分资产都需要被提前创建，才能在投放端选择并进行推广哦～为了让您更直观了解具体行业对应资产库的创建方式，我们分行业列举了各资产库的详细创建方式，请按照您的所属行业戳左侧对应目录，一起高效创建推广产品吧！



**注意**：后续的“营销创意”阶段会有“一致性校验”环节，即系统会检查选择的推广产品/营销对象是否和真实投放的创意元素（文案、图片、视频元素、落地页）一致，不一致的话会影响您正常投放，因此在创建推广产品阶段就需要准确填写，以更快捷地开启投放。详细的一致性校验解释可见[推广产品一致性校验](https://doc.weixin.qq.com/doc/w3_Ad4A8QavANwCNZ03fY39JTb2B3u18?scode=AJEAIQdfAAod8P1HudAd4A8QavANw )



## 3、使用推广产品

大部分推广产品需要提前创建好才能在投放端使用，登录[腾讯营销 - 投放管理平台](https://ad.qq.com/ )，点击【竞价推广】tab，选择【新建营销】，填写【营销内容】模块，在该模块下选择正确投放的【推广产品】，继续填写并完成营销创建。
