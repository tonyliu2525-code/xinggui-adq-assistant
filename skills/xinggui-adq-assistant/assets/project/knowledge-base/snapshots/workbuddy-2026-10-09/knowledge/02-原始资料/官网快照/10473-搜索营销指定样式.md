# 一、能力介绍



搜索营销指定样式工具适用于投放搜一搜版位的客户，提供对投放中的搜索直投营销指定若干创意样式进行投放的能力。



# 二、解决哪些问题



搜索直投营销组件化投放，由引擎进行组件优选并拼接成最终的创意样式。美奢等行业对创意样式有指定需求，可通过指定样式工具实现。



# 三、使用门槛



搜索营销指定样式工具白名单支持；



客户需要提前创建好投放搜一搜版位的搜索直投营销，且营销状态为投放中；



部分样式需要确保创意中包含某些组件才可成功播放；



# 四、操作说明



## 1、入口



工具——>投放管理——>搜索营销指定样式









## 2、新建样式组



点击【+新建样式组】进入新建样式组页面









**2.1 选择绑定的营销**



● 营销的下拉列表仅展示投放状态=投放中的营销；



● 请确保所选择的营销其版位包含【搜一搜】，否则不生效；



● 单账户最多允许绑定500条营销；



● 支持重新选择营销；



**2.2 添加创意样式**



部分创意样式必填某些组件（除营销必填组件外），请确保绑定该创意样式的营销包含这些必填组件，具体为：



● 竖版视频——9:16视频



● 横版图片——16:9图片



● 横版视频——16:9视频



**2.3 设置样式组名称并点击【添加到营销】**









## 3、编辑样式组



样式组列表——>操作列，点击【编辑】，进入编辑样式组页面









支持重新选择营销、创意样式，重新设置样式组名称。









## 4、其他操作



● 支持删除样式组；

● 支持下载所有带绑定关系的样式组数据；









# 五、常见问题



**Q：为什么营销列表中没有可选的营销？**



A：指定样式仅对搜索直投营销生效；已经创建的搜索直投营销的投放状态必须为投放中
