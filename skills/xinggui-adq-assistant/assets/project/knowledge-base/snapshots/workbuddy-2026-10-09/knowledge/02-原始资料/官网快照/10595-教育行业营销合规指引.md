一、教育培训营销通用合规要求：





1. 教育培训营销资质要求


1.1 公办教育机构（包括学前教育、基础教育和高等教育机构）发布教育培训招生营销的，应当提交下列证明文件：


1.1.1 人事部门或者编制委员会批准设立的文件；


1.1.2 高校发布“在校内举办非学历教育培训”招生营销，应当提交“学校非学历教育归口管理职能部门”同意发布营销的书面意见；


1.1.3高校发布“在校外举办各类非学历教育培训”（包括在高校校园外与其他办学机构或单位的合作办学）招生营销，应当提交校外办学点所在地区、县教育行政部门出具的教学点备案证明。



1.2 民办教育机构发布教育培训招生营销的，应当提交下列证明文件：


1.2.1《营业执照》或《事业单位法人证书》；


1.2.2《民办学校办学许可证》（以下简称“办学许可证”），其中，开展学历教育、学前辅导、自学考试辅导及其他文化教育培训的民办学校，提供由当地人民政府教育行政部门核发的办学许可证；开展以职业技能为主的职业资格培训、职业技能培训的民办学校，应提供由县级以上劳动保障部门核发的办学许可证；


1.2.3涉及民办学校的招生营销，应提交当地人民政府教育行政部门或劳动保障部门出具的民办学校营销备案证明材料。



1.3 经营性教育培训机构发布教育培训招生营销的，应当提交营业执照，且营业范围并包含“教育培训”。



1.4 营销中涉及合作办学内容的，合作各方均应具有合作办学涉及的教育培训办学资质和教育培训项目内容，如合作从事高等教育自学考试辅导培训的，各方都要具备高等非学历教育资质。





2. 禁止投放下列教育培训营销


2.1 针对中小学及学前教育阶段的学科类、非学科类校外培训营销；
2.2 未经教委认定的境外教育课程营销；
2.3 义务教育阶段学校开设国际课程的招生营销；
2.4 学前教育阶段的线上（学科类和非学科类）培训营销和线下学科类（含外语）培训营销。





3. 教育培训营销不得含有下列情形和内容


3.1 对升学、通过考试、获得学位学历或者合格证书，或者对教育、培训的效果作出明示或者暗示的保证性承诺；如“包过”“不过退款”；


3.2 明示或者暗示有相关考试机构或者其工作人员、考试命题人员参与教育、培训；


3.3 利用科研单位、学术机构、教育机构、行业协会、专业人士、受益者的名义或者形象作推荐、证明；

3.4 借重大国事和政治活动等名义从事商业营销宣传；


3.5 烘托、渲染紧张氛围，误导公众教育观念，制造学生或者家长的焦虑情绪，如使用“自学考试即将取消”“考纲变化”“考试难度加大”“学制延长”“加考数学外”等政策变化用语或“别让孩子输在起跑线上”“不学就会落后”等制造焦虑的用语；


3.6 在营销中以虚构原价、虚假折扣等方式进行宣传。如虚构“原价xx，立即购买享超值折扣”“1元课”“1折享”等；


3.7 实施义务教育的民办学校在营销中宣传使用境外教材。实施以职业技能为主的职业资格培训、职业技能培训的民办学校营销宣传规避监管，以不正当手段获取职业资格证书、成绩证明等；


3.8 教育培训营销在营销中虚构教师资质、夸大培训效果、夸大机构实力、编造用户评价等。如虚构“英语专业八级，高级教师资格证”“十年以上教学经验，累积输送到四大名校的学员500余人，考取四大名校的比例均在90%以上”；


3.9 除经批准设立的大学、学院以及由其设立的内部机构或由其发起并依法登记的组织机构外，其他教育培训机构在营销宣传中使用“大学”“学院”字样；


3.10 以欺骗方式诱使用户点击投放内容。如编造“最新通知”“最后一次机会”“xx考试即将取消”等；


3.11 民办学校发布含有实施军事、警察、政治等特殊性质教育的营销；


3.12 民办学校在筹设期内发布招生营销；


3.13 民办学校应当贯彻教育与宗教相分离的原则，不得发布利用宗教妨碍国家教育制度的营销；


3.14 利用不满十周岁的未成年人、违法失德人员作为营销代言人；


3.15 针对未满十四周岁未成年人的教育培训营销含有劝诱其要求家长购买营销所宣传的教育培训商品或服务的内容和可能引发其模仿不安全行为等内容；


3.16 校外培训营销不得含有提供境外教育课程培训和聘请在境外的外籍人员开展培训活动的内容。





4. 不得以新闻报道、软文等形式变相发布校外培训营销。





5. 不接受高校所属机构（二级学院、系、处，及校内其他部门）或个人投放以高校及所属机构名义，面向社会举办（或与其他办学机构合作举办）非学历教育的营销。



6. 不接受从事基础教育（小学、中学阶段）的教学机构投放非学历教育营销。



7. 不得在以未成年人为服务对象的在线教育网络产品和服务中推送营销等与教学无关的信息。学校、幼儿园不得安排未成年人参加商业营销活动。



8. 教育培训营销应当以国家通用语言文字普通话和规范汉字为基本的用语用字。不得使用繁体字、异体字，如“傢俬行”“薬房”；不得使用错别字或者篡改成语，如“默默无蚊”“百衣百顺”；不得单独使用外国语言文字。



9. 教育培训营销中表明附带赠送的课程、图书礼包等商品或者服务，应当明示所附带赠送的品种、规格、数量、期限和方式。



10. 教育培训营销使用“升学率”“通过率”等数据、统计资料、调查结果、文摘、引用语等引证内容的，应当真实、准确，并表明出处。



11. 民办学校在营销中只能使用一个名称。民办学校的名称应当符合有关法律、行政法规的规定，不得损害社会公共利益，不得含有可能引发歧义的文字或者含有可能误导公众的其他法人名称。营利性民办学校可以在招生营销和招生简章上使用经审批机关批准的法人简称。



12. 营销中涉及颁发境外学历、证书等内容的，培训机构应当具有中外合作办学资格。



13. 营销中涉及研究生培训（包括MBA、EMBA、MPA等）内容的，培训机构应当为普通高校以及国务院学位办批准的教育机构（如中欧国际工商学院）。



**参考法律法规：** 《》《未成年人保护法》《民办教育促进法》《关于进一步减轻义务教育阶段学生作业负担和校外培训负担的意见》《关于做好校外培训营销管控的通知》《深圳市教育培训营销合规指引》《上海市营销协会教育培训营销发布标准》











二、学历及非学历教育培训营销合规要求



除遵守通用合规要求外，涉学历及非学历教育培训营销的，还应当遵守如下合规要求：



1. 未经高校法人书面授权或省级自学考试管理机构审查备案，任何主体不得发布或以教育咨询、学历提升服务等名义变相发布涉及具体高校的高等学历继续教育和自学考试助学活动营销。



2. 不接受高校校内二级学院和高校设置的函授站、校外学习中心（含公共服务体系学习中心）自行开展或授权其他主体投放的营销。



3. 学历教育营销需遵守如下规则：


3.1 有关入学条件、最低学习年限、学费标准及收取方式、报名途径、高校招生网站地址、毕业证书和学位证书获取条件等信息必须真实、准确、合法，不得出现“无需学习”“无需上课”等虚假违规内容，不得出现“快速取证”“免考包过”“考不过退款”等对教育效果作出明示或者暗示的保证性承诺；


3.2 不得模糊自学考试助学活动与主考学校学历教育的关系区别；


3.3 不得混淆技师学院，专修学院、研修学院等非学历高等教育机构与开展学历教育高校的性质区别。



4. 普通高等学校（职业高等学校、独立设置的成人高等学校、开放大学）以提升受教育者专业素质、职业技能、文化水平或者满足个人兴趣等为目的，以培训、进修、研修、辅导等形式举办非学历教育的，应当符合如下主体要求：


4.1 高校内非实体性质的单位、职能管理部门、群团组织及教职员工个人不得擅自以高校名义举办非学历教育；


4.2 高校独资、挂靠、参股、合作举办的独立法人单位不得以高校名义举办非学历教育；


4.3 名称中带有高校全称或简称的法人举办非学历教育均应纳入高校统一管理；


4.4 高校非学历教育招生仅能由高校自行组织，不得委托校外机构代理招生，且招生宣传内容必须真实、明晰、准确。营销素材中禁止出现除高校外的任何主体推广代理招生业务的内容；


4.5 高校进行非学历教育的合作办学时，不得转移、下放、出让学校的管理权、办学权、招生权和教学权，并严禁项目整体外包。其中，脱产学习超过一个月的非学历教育以及受委托的领导干部培训项目仅能由高校独立实施，严禁委托给社会培训机构或与社会培训机构联合举办。营销素材中不得出现上述违法情形。



5. 高校举办的非学历教育进行营销宣传不得含有下列情形和内容：


5.1 不得以“研究生”“硕士、博士学位”等名义举办课程进修班；


5.2 不得出现招收领导干部的宣传，面向社会招生的非学历教育不得冠以“领导干部”“总裁”“精英”“领袖”等名义；


5.3 营销若涉及毕业证书、结业证书的表述或展示，不得明示或以任何形式暗示该证书为学历证书，防止误导大众；


5.4 除高校自身外，其他任何机构、单位、个人、合作方等不得以任何名义收取或代收取非学历教育办学中的任何费用。因此非学历教育营销中不得出现代缴费、代收费等宣传内容。



6. 非学历教育机构不得利用合作办学发布含有学历教育内容的营销，中等教育机构不得利用合作办学发布含有高等教育内容的营销，职业培训机构不得利用合作办学发布文化教育培训招生营销。普通高校不得以合作办学等方式委托不具备高等学历教育的培训机构开展委托招生、教学并发布招生营销。



7. 非学历教育机构不得以“计划外招生”“招收（录取分数）线下考生”等名义发布招生营销。



**参考法律法规：** 《深圳市教育培训营销发布标准》《关于加强高等学历继续教育营销发布管理的通知》《普通高等学校举办非学历教育管理规定（试行）》









三、 课外体育培训营销合规要求



除遵守通用合规要求外，涉课外体育培训营销的，还应当遵守如下合规要求：



1. 课外体育培训营销资质要求


1.1 如开展高危险性体育项目的课外培训（如游泳技能培训、滑雪培训等），需取得《高危险性体育项目经营许可证》。


1.2 如宣传执教人员，相关人员应当持有以下至少一种证书：（1）体育教练员职称证书；（2）社会体育指导员职业资格证书；（3）全国性单项体育协会颁发的体育技能等级证书；（4）体育教师资格证书；（5）经人力资源和社会保障部确定的人才评价机构颁发的体育职业技能等级证书；（6）经省级（含）以上体育行政部门认可的相关证书。


1.3 课外体育培训主体可聘请持技术等级证书的社会体育指导员开展体育志愿服务。


1.4 开展高危体育项目的课外体育培训，需提交从业人员具备国家规定的职业资格的相关证明。


1.5 若宣传聘用外籍执教人员的，应提交符合相关法律规定的外籍执教人员持有资质证书的认证工作。


1.6 上述各类资质证书应在有效期内。



2. 若营销素材中涉及学员或者执教人员数量的相关宣传时，原则上宣传中每班次学员人数不超过35人，超过10名学员的应至少配有2名执教人员。



3. 营销应当明码标价，且收取课程费用的时间跨度应不超过3个月。



4. 营销素材中不得出现向参加体育培训人员出售含有酒精的饮料和以任何形式暗示、教唆、帮助参加培训人员获取和使用兴奋剂的内容。



**参考法律法规：** 《课外体育培训行为规范》
