# 腾讯营销 如何实现多主体共享信用额度？

| *更新日期* | *2023-11-6* | *内容更新* |
| -------- | -------- | -------- |

## 共享条件
1. 相关主体需在同一政策集团内
2. 相关主体均需完成腾讯集团信用评级
3. 相关主体共同签订《腾讯广告账期框架协议》和担保协议
4. 相关主体需共担债务

## 限制条件
合约信用额度和竞价信用额度的授信逻辑不同，无法共享额度

## 实现方式
当您将相关主体完成以上准备条件后，即可实现信用额度共享，可在账户后台的“信用金管理”界面将信用额度互相划转
