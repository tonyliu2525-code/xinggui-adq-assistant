# 一、产品介绍



## 1.1. 链路定义



营销链路（Conversion Link）是客户在投放中设置的、引导消费者（Who）从点击到产生消费的主干路径，是客观事实的提炼与抽象，由载体（Where）下的关键行为事件（What）按照一定序列（When）串联构成。



以一条典型的营销链路为例，其组成要素如下：



● 在什么场景/环境（Where）：用户关键行为事件发生的载体，如示例中链路经过的载体有官方落地页、企业微信、外部微信小程序三种



● 按照什么样的时序（When）：用户在载体内的关键行为事件序列，代表不同行为事件的发生顺序，如示例中企业微信载体内的”加群→点击链接”



● 发生了哪些关键行为事件（What）：用户关键行为事件的具体类型，如示例中浏览商详页、下单等







## 1.2. 产品简介







在「转化归因」工具（转化归因功能介绍参考[帮助中心-产品介绍说明](https://e.qq.com/ads/helpcenter/detail?cid=3556&pid=10217)）中，为客户提供了「营销链路」能力，供客户在投放前，管理营销链路的配置信息、数据回传和数据联调，实现客户在投放过程中的营销链路表达，并保障在选择对应优化目标时，已满足链路的数据回传要求。



## 1.3. 产品功能



| 功能 | 介绍 |

| -------- | -------- |

| 营销链路选择 | 在新建转化规则时，选择对应分类和适用营销链路，并配置上报数据的链路节点。 |

| 链路数据联调 | 支持在自带的联调工具中，对营销链路要求回传的节点数据进行联调。 |

| 营销链路共享 | 设置转化规则的共享范围，无需重复创建相同营销链路的转化规则。 |



## 1.4. 概念说明



| 名词 | 说明 |

| -------- | -------- |

| 营销链路 | 营销链路是指用户在营销活动中，从点击到完成转化所经过的完整路径，由承接转化的营销载体和多个行为节点序列组成。客户通过在营销创编中选择带有营销链路的转化规则，精准表达营销标的和转化路径。 |

| 转化类型 | 转化类型对应投放的「营销载体」概念，是营销链路的优化目标（或生意目标）发生的场所。例如某次投放的优化目标是促进用户在某小程序上完成交易，那么在为该营销选择营销链路时，需要选择小程序作为转化类型。 |

| 上报节点 | 在营销链路的节点序列中，客户需回传对应数据的节点，即上报节点。上报节点既包括所选优化节点要求的必传节点和推荐回传节点，也包括客户自行选择的非必传节点，所选的上报节点均需在联调工具中完成数据联调。 |



## 1.5. 链路分类



| 链路分类 | 说明：客户引导用户发生转化行为的核心场景（载体） | 举例 |

| -------- | -------- | -------- |

| Android应用 | 希望用户在应用发生转化行为 | 引导用户进行应用的激活 |

| iOS应用 | 希望用户在应用发生转化行为 | 引导用户进行应用的激活 |

| 快应用 | 希望用户在快应用发生转化行为 | 引导用户在快应用进行付费 |

| 网页 | 希望用户在客户自定义页面/微信客服页面发生转化行为 | 引导客户在H5页面进行留资 |

| 微信公众号 | 希望用户在公众号发生转化行为 | 引导用户进行公众号关注 |

| 微信视频号 | 希望用户在视频号（直播间）里发生转化行为 | 引导用户在直播间留咨 |

| 微信小程序 | 希望用户在小程序里发生转化行为 | 引导用户在小程序留资 |

| 企业微信 | 希望用户在企业微信里发生转化行为 | 引导用户在企业微信进行咨询 |

| 微信小游戏 | 希望用户在微信小游戏里发生转化行为 | 引导用户在微信小游戏进行注册 |

| QQ小游戏 | 希望用户在 QQ 小游戏里发生转化行为 | 引导用户在 QQ 小游戏进行注册 |

## 2.4. 如何使用营销链路



功能描述：在营销创编流程中使用带有营销链路的转化规则。



**● 应用范围：**



○ 竞价投放-信息流：oCPX营销可选择带有营销链路的转化规则，CPM/CPC营销则无需选择转化规则



○ 竞价投放-搜索：无转化规则



○ 合约投放：无转化规则



**● 应用限制：**



○ 数量限制：1 条营销最多选择 1 条转化规则



○ 修改限制：当新建营销选择营转化规则并保存成功后，编辑营销时不可修改转化规则（包括历史营销）



○ 链路正确性：客户选择的营销链路，需和实际投放链路一致，后续会校验正确性，以保障营销的稳定性预估



操作流程：「投放管理平台」—「选择转化规则」



| 详细步骤 | 示意图 |

| -------- | -------- |

| 步骤1：在投放管理平台新建营销时，营销内容中，选择新建的营销链路资产。 |   |



# 三、FAQ



## 1. 转化规则创建和管理



Q：在「工具→转化归因」的列表中，对应的转化规则没有【删除】入口？



A：被授权的转化规则无法进行【删除】操作，请联系转化规则的创建方进行删除处理



Q：配置监测链接时，无法填写曝光监测链接/选择带有曝光监测链接的监测链接组？



A：配置曝光监测链接，需对应选择「曝光归因」这一归因方式；如有需要，请联系您所对接的行业运营，进行内部申请配置



Q：编辑转化规则的点击监测链接时，提示「can't add feedback_url for conversionSpce with empty feedback_url」报错信息？



A：如果转化规则创建时未配置点击监测链接，目前暂不支持在编辑时，在该转化规则下新增监测链接。可重新创建一个转化规则填写对应的点击监测链接



## 2. 转化规则联调



Q：为什么转化规则创建后，没有进行联调，转化规则的状态自动变成了「已激活」？



A：需判断是否以下原因：



● 是否联系过对接的行业运营，对当前账号配置了「免联调」权限



● 相同数据源下，相同优化目标如历史已联调成功过，新建相同优化目标的转化规则时，无需重复联调



● 部分优化目标（如「点击」）无需联调



Q：为什么点击【开始联调】按钮后，报错「您使用创意形式、版位和商品类型组合不支持当前品牌形象类型。」？



A：这是因为您没有对应营销版位的投放权限，导致联调营销创建失败，请联系您所对接的行业运营，开通相关营销版位的权限：



● App、网页、QQ 小游戏类型的转化规则：需开通「腾讯平台与内容媒体」版位的权限



● 企微、小程序、公众号、微信小游戏类型的转化规则：需开通「微信朋友圈」版位的权限



Q：为什么点击【开始联调】按钮后，报错「未通过身份验证，暂不支持使用，请前往ADQ完成身份验证」？



A：如投放账户未通过身份验证，将被限制投放营销素材，导致联调营销创建失败。请完成身份验证后，且账户将恢复投放等功能后进行重试

完成账户身份验证的流程具体可参考：[新身份验证流程指引（对外）](https://doc.weixin.qq.com/doc/w3_AJUAqgZGACgLB1A6zbaTcG1UEWmII?scode=AJEAIQdfAAoik5OaiIAH8A_QZ1ACg)



Q：为什么点击【开始联调】按钮后，报错「不支持的营销四元组类型,XXXX。」？



A：如投放账户没有对应的营销内容（如营销目的、营销载体等）的投放权限，将导致联调营销创建失败。请联系您所对接的行业运营，开通相关营销内容的权限



Q：为什么联调时，使用手机微信朋友圈不断刷新，无法找到联调营销/显示「暂无可预览的营销」？



A：



● 确认微信客户端版本是否为最新版本，未升级到最新版本可能导致刷不到营销；



● 若已经更新，则在手机后台「退出微信」重新进朋友圈刷营销



Q：为什么联调时，使用手机 QQ 扫码后，无法找到联调营销/显示「暂无可预览的营销」？



A：



● 可将手机 QQ 客户端更新到最新的版本后重试；



● 如创建转化时选择的是「Android」类型，请使用安卓设备进行联调，如选择的是「iOS」类型，请使用 iOS 设备联调；



● 请确认手机 QQ 相关能力是否开启：



* 1.qq-＞设置 一＞个人信息保护设置 一＞营销推荐设置一＞个性化营销 开关打开

* 2.qq-＞ 设置-＞隐私一＞授权管理-＞管理列表中有腾讯营销相关的应用

* 3.打开qq空间刷动态，直到刷出任意一条营销



Q：为什么联调时，上报数据一直显示为 0？



A：需按如下步骤完成自查：



● 与开发同学确认对应的数据（action_type）是否成功上报



● 确认上报的数据是否对应点击联调预览营销发生的转化（例如 clickid/用户 ID 是点击预览营销用户对应的 ID）
