# 一、新工作台定位

**全局管理**：支持主体、人、钱一站式统筹管理，提供全链路解决方案



**经营管理**：真实还原公司经营模式，通过人员验证降低套户等风险



**资产管理**：主体资产自动共享、快捷复用，提升效率

# 二、新工作台面向用户

工作台主要面向与腾讯合作的客户，可能涉及多类不同客户角色



**客户管理人员**：管理整个公司，负责公司内部组织、成员、账户、资金等管理



**客户优化师/运营**：负责公司下部分账户的资产、资金的维护管理，日常盯盘数据



**客户财务人员**：负责公司资金相关的转入转出，对账等日常工作

# 三、新工作台核心升级点

新工作台是面向客户组织的全新营销管理平台。

## 3.1 注册/登录方式

为了避免黑产/套户等风险，新工作台增加人员身份验证，需要保证组织下员工身份的真实性

| 类型 | 升级前 | 升级后 |

| -------- | -------- | -------- |

| 注册/
登录     | 任何人员都可直接注册/登录
可选择是否要关联账户     | 需进行人员身份验证（人脸+管理员确认）
自动关联账户    |





## 3.2 组织管理模式

系统还原真实的内部组织架构，账户由管理员分配，无需人工认领，提升组织管理效率

| 类型 | 升级前 | 升级后 |

| -------- | -------- | -------- |

| 用户维度| 1个用户可归属多个BM（管家）
1个用户可拥有BM外的单账户     | 1个已认证用户不可拥有BM外的单账号     |

| BM维度| 1个BM对应多个无关主体 | 1个BM对应1个主体
1个BM对应多个相关主体 |



## 3.3 资产管理模式（开发中，敬请期待）

资产溯源，BM内资产（素材、商品等）自动共享，无需额外授权；跨服务商资产隔离

## 3.4 资金管理模式（开发中，敬请期待）

建立客户钱包，账户自动按需消耗公共客户钱包中的金额，提升资产流转效率，降低停投风险

## 4.3 成员邀请

**场景：1期工作台中组织成员的加入，主要依赖子客开户及已有成员的邀请**

### 4.3.1 邀请管理员加入

主要应用于当前BM不存在管理员的场景，由企业认证员工邀请管理员（法人）加入组织



**step1: 登录后，在首页点击“邀请法人认证”**



**step2: 将此二维码转发给管理员，由管理员进行扫码认证**



### 4.3.2 邀请企业员工加入

主要应用于当前用户为管理员的场景，可邀请其他成员加入组织



**step1: 登录后，点击“管理—成员管理—邀请成员加入”**



**step2: 将此二维码转发给管理员，由管理员进行扫码认证**



**step3: 员工扫码后，管理员可在管理—成员管理—成员申请审批 中审批**



**step4: 审批通过后，需要给对应成员配置角色+分配账户**



**注意：如果分配权限为“管理员”，则需勾选免责声明**

场景：此页面主要支持用户查看自己的身份及对应组织的相关资质材料等，无实际操作

## 4.5 资产

**场景：跨账户数字资产的共享，经常是优化师们头疼的问题。如何将效果优秀的落地页快速应用到其他投放账户呢？资产授权能力可以帮您解决这个难题。**



资产授权服务可以帮助您更高效的对您的数字资产进行管理和共享，您可以将某个投放效果较好的资产授权给其他投放账户，被授权的账户可以直接使用授权资产进行投放，不需重复审核，即使解除授权也不会对营销效果产生影响



**注意：被解除的资产将不可再用于新建营销**



### 4.5.1 授权方式

针对不同类型的资产特性，授权方式分为两种类型：

**4.5.1.1 账户维度授权**

**定义：将某个账户下所有某类资产进行打包一次性授权，授权后新增的该类资产会自动同步给被授权账户。**



**比如：您可以将某个账户A下所有的枫页落地页一次性授权给账户B，那么账户B投放时可以选择来自A的任意枫页落地页。**

**4.5.1.2 资产维度授权**

将某个账户某类资产下的单个资产进行授权，被授权账户只会接收到单个资产。



**比如：您可以将某个账户A的1个人群包B授权给账户C，那么账户C投放时只可以选择来自A账户人群包B，不可选择A账户的其他人群包授权范围**

### 4.5.2 授权范围

不同类型的资产可授权范围是不同的，授权范围主要有以下几种：

**4.5.2.1 授权给投放账户**

授权给相同公司主体下的某个账户

**4.5.2.2 授权给商务管家**

授权给其他商务管家下的所有账户（包括未来该商务管家内新增的账户）

**4.5.2.3 授权给公司主体**

授权给相同公司主体下的所有账户（包括未来该公司主体内新增的账户）



**注意：资质审核时的营业执照信息将作为是否同一主体的依据**

## 4.6 财务

### 4.6.1 财务基础信息

**场景：支持各类财务专员及优化师进行资金数据及日结数据的记录查看等**

**4.6.1.1 资金管理**

**场景：您可以按所属管家查看所管理账户的实时余额情况，也可以通过点击【查看财务记录】，查询该账户该账号下历史所有的财务记录数据（从开户日至今），包括营销扣费、服务商的转账和管家操作的转账等，支持按年数据下载（单次10w条）**



### 4.6.2 日结报表

**场景：您可在日结报表中查看相关管家每日的转入、转出、结余等情况，支持数据下载**



## 4.7 报表

**场景：可查看管家下全部账户的投放相关数据，支持多口径的切换、分时段的查询下载等

跨账户报表可以查看当前组织下您作为操作者或观察者的腾讯营销账户的指标报表数据**



支持对希望查询的账户进行筛选，并按日期区别查看的至多4项指标的趋势



支持分日、分时、分时段、合计维度进行查看



支持细分版位查看详情数据



支持切换口径包括：营销播放口径、转化回传口径、转化激活口径



同时为方便您对投放效果进行多维度分析，跨账户报表支持以投放时所使用的图片素材、视频素材、商品库或商品为维度查看投放数据



其中，当您查看素材及商品报表时，可以在页面左下角选择是否包含授权数据，即所管理账户的素材和商品库授权给其他账户时产生的数据



## 4.8 推广

**场景：推广页展示了当前组织内，跨账户的计划、营销、创意、商品列表及其数据，您可在此进行跨账户的投放详情情况查看与分析**



**首先，您需要在右上角的账户选择组件中选择账户。可选择的账户范围是当前管家下您作为操作者或观察者的腾讯营销账户和公众平台账户，可通过搜索、筛选来快速查找账户，最多可选择20个账户。**



选择账户后，即在在列表区域查看所选账户内的计划、营销、创意、商品投放情况。可一次性查看最多20个账户的数据情况，助您高效分析与决策。
