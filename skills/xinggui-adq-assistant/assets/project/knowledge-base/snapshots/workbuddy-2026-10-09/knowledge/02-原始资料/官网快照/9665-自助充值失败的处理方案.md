# 腾讯营销 自助充值失败的处理方案

| *更新日期* | *2024-3-22* | *流程更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您需要 将自助充值的过程中支付失败或款项未到账重置到账，请通过以下方式发起：

# 微信支付
通过微信支付完成支付，系统收到支付结果后，即刻完成充值。
若充值未到账，请根据以下情况查实后重新支付：
* 付款成功但款项未充值到账。款项将即刻原路退回支付所使用的微信，请核查微信支付交易记录中的退款情况，并重新进行付款充值流程。
* 付款未成功。请重新进行付款充值流程或更改支付方式。

# 网银支付
通过网银支付完成支付后，系统收到支付结果后，即刻完成充值。
若充值未到账，请根据以下情况查实后重新支付：
* 付款成功但款项未充值到账。款项将即刻原路退回支付所使用的银行卡，请核查银行卡交易记录中的退款情况，并重新进行付款充值流程。
* 付款未成功。请重新进行付款充值流程或更改支付方式。

# 转账汇款（固定识别码支付）
通过转账汇款完成支付后，预计一个工作日内收到支付结果并完成充值。
若充值未到账，请根据以下情况查实后处理：
* 转账未成功。请重新进行付款充值流程或更改支付方式。
* 转账成功但款项未充值到账。
* 款项非实时到账，预计一个工作日内收到支付结果并完成充值，请耐心等待。
* 因金融合规监管，付款方主体需与充值账户主体一致。若不一致，将导致资金拦截款项无法充值到账。请使用合规主体重新进行支付，非一致主体的已付款项需申请退款处理。
* 请复核转账汇款的收款银行账户，与投放端后台显示是否一致。若不一致，将导致无法辨识充值账户，造成充值失败。此时需发起线下补充修正充值流程，详情如下：
