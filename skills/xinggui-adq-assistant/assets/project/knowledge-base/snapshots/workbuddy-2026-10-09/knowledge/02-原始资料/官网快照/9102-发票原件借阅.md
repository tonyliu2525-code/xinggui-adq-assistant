# 腾讯营销 发票原件借阅

| *更新日期* | *2023-9-6* | *流程更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您需要 对遗失发票的原件进行借阅，请通过以下方式发起：

# 邮件申请
*
## 收件人
收件人：*[ 您的销售经理/渠道经理 ]*

抄送人：AMS_JS@tencent.com

*
## 邮件主题
【腾讯营销】发票原件借阅 - *[ 客户名称 ]*

*
## 邮件正文
我司已签署《发票遗失证明》见附件，申请以下发票的记账联：

|发票类型（发票上的发票类型）|	发票号	|金额
|-|-|-|
|Text|Text|Text|
Text|Text|Text|

并申请将此文件复印后盖章，快递至已下地址：

收件人：

联系电话：

收件地址：

*
## 邮件附件
* 已签署的《发票遗失证明》扫描件

# 处理流程
1. 申请人签署《发票遗失证明》
2. 申请人发起邮件进行借阅申请
3. 腾讯营销业务侧在内部系统完成申请后同步材料

# 注意事项
* 记账联扫描件为未盖章原始发票，若需盖章扫描件请备注
* 无需原件的，不需要提供快递信息
* 若申请人发起申请后未在处理时效内收到反馈，或对反馈结果有异议的，请主动[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)了解具体情况
