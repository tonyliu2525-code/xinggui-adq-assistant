# 一、背景
在当前的腾讯营销投放平台的创意相关环节，存在素材&组件两个概念和能力，两者之间有前后依赖关系。
在实际的过程中，客户反馈对这两个概念的理解和使用有很多疑问，主要如下：
1）**概念理解困难**：难以理解素材和组件的差别（在投放单图、单视频的情况下，素材和组件一一对应，客户感知没有区别）；加之竞品没有组件概念，会时常混淆；
2）**流程繁琐**：在投放流程中上传素材后还要再制作组件，增加了操作步骤；
3）**授权逻辑复杂**：组件和素材的授权逻辑不同（组件仅支持业务单元共享，可设置共享范围，素材业务单元默认全部共享，额外支持跨账户授权），导致客户理解成本增加；同时增加了内部能力迭代难度；

基于以上背景，腾讯营销投放平台团队针对创意相关能力升级，“合并”素材和组件两个概念，升级为“创意资产管理”，合并后主要有以下好处：
1）**概念统一**：素材&组件合并升级概念统一更清晰，所有涉及到素材&组件的投放端模块，均合并升级为“创意资产管理” ；
2）**创编简化**：多步变一步快速创建创意；
3）**功能强大**：视频高光帧、多维筛选等升级版特色能力；

现针对该能力升级主要功能点进行说明

# 三、Q&A
Q1：**我为什么要参与素材和组件的合并升级？**
A：此次升级主要解决您在使用素材和组件时遇到的概念理解困难、流程繁琐以及授权逻辑复杂等问题。升级前，您可能难以区分素材和组件的差别，在投放单图、单视频时，虽二者一一对应，但仍易混淆，且竞品无组件概念，增加了您的对接成本。同时，投放流程中上传素材后还需制作组件，增加了操作步骤，API 也需调用更多接口。此外，组件和素材的授权逻辑不同，导致您理解成本增加，内部能力迭代难度也相应提升。升级后，将实现概念统一、操作简化，为您带来更清晰的使用体验和更高的效率。

Q2：**我看到的管理界面在升级后有什么变化？**
A：升级前，管理界面包含创意素材管理和创意组件管理两个独立界面，能力相互独立，各自演进，您难以区分差别。升级后，在统一后的“创意组件管理”界面中，您可进行所有图片、视频、文案等管理，单图、单视频支持内容标签、投放标签标注，图片、视频支持“去关联”创意，新增支持“所属类型”，区分自有、授权的图片/视频，单图/单视频还支持多账户授权，管理更加集中和便捷。

Q3：**我的创编流程在升级后是如何简化的？**
A：升级前，创编流程步骤较多，您在选择素材时需先在素材库操作，之后生成组件，再生成创意，且素材库缺少筛选能力，组件类型混合展示，不方便筛选查看。升级后，对于单图、单视频，您无需在上传后创建组件，上传后即可用于投放，直接在创建流程中选择图片/视频，支持切换视频/单图/多图 tab 快速区分，支持数据指标排序，视频支持多种筛选条件，图片也有多项筛选功能，多图/橱窗支持部分筛选，操作更加简便高效。

Q4：**我在升级后如何进行创意资产管理？**
A：升级后，所有涉及到素材和组件的投放端模块均合并升级为“创意资产管理”。您可通过统一的管理界面进行操作，其中管理方面，由原来的素材管理及组件管理合并为创意资产管理；创意创编环节，由素材库及组件库合并为创意资产库；报表方面，由素材报表及组件报表合并为创意资产报表；授权方面，由素材授权变为创意资产授权。您可在该统一界面下更清晰、便捷地管理创意相关内容。

Q5：**创意素材授权逻辑在升级后有什么调整？**
A：升级前，素材授权默认全共享，组件仅支持业务单元共享且可设置范围，授权逻辑不同，导致您理解成本增加。升级后，统一为“创意资产授权”，仅支持账户维度授权（不支持主体维度），同主体下可批量授权，当授权视频时，图片需跟随一起授权，授权逻辑更加简单清晰，降低了您的理解成本。

Q6：**升级后数据报表有什么不同？**
A：升级前，若您用同一个图片既投放了单图，又拼接成多图进行投放，素材报表中可查看图片在单图和多图中汇总的投放数据，组件报表中可分别查看单图和多图的投放数据。升级后，合并后的组件报表仅支持分别查看单图和多图的投放数据，单图数据中不会包含多图的数据。同时，由于日志报表侧升级全新报表结构，当前仅支持回溯 10 月 1 日之后的数据，放量后可查看 10 月 1 日之后的组件报表数据，如需查询 10 月 1 日之前的数据，可提供切换旧素材及组件报表进行数据查询的能力。

Q7：**升级后使用业务单元组件时有什么需要注意的？**
A：升级后，业务单元组件暂不支持部分账户授权，所有组件均默认业务单元下全部账户可见可用，长期将支持设置部分账户可见可用，但此调整仅对业务单元维度管理素材，并使用部分账户授权的您有影响，请您在使用时留意这一变化。

Q8：**升级后使用视频相关功能有什么变化？**
A：升级后，视频相关功能有部分调整。一方面，选的视频本身默认首帧作为封面，可更换封面，但仅当前创意生效；另一方面，合并后的组件报表不能细分查看一个视频配置不同封面图的效果数据，仅支持查看视频汇总的投放数据。若您有视频封面相关特殊需求，可能需要适应这些变化。

Q9：**升级后使用 API 接入时需要注意什么？**
A：升级后，API 仍保留素材 ID 及组件 ID 的两套报表查询能力，您可不做变更。但由于投放端针对单图/视频披露的素材 ID，其他类型披露的组件 ID，若您在 api 上传素材并创建组件，又提供组件 ID 给优化师，优化师在投放端可能搜不到，所以在使用 API 接入时，请您留意这一情况，避免出现查询不到相关内容的问题。
