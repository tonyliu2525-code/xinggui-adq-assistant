# 专题目标简述

针对【*电商通道*】频繁投诉类违规营销类型集中展示与解析，便于对审核规则的理解和修改

***注：所有案例仅为演示说明合规要求之目的，未经允许，不得使用***

## 驳回具体原因

1. *请勿使用夸大、承诺、绝对化用语及虚假宣传的描述，请修改*
2. *客户未提交相关资质或提交的资质不合要求，请上传至投放管理平台-账户中心-营销资质，并重新提交营销*
3. *涉及知名人士肖像或名义，请将对应个人的授权证明，上传至投放管理平台-账户中心-营销资质，并重新提交营销*
4. *请勿宣传违反社会公序良俗的内容，请修改*
5. *请勿使用与推广商品及目的的无关联的内容，请修改*
