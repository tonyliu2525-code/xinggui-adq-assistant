# 一、使用门槛

## 1.使用准入

### 1.1.月度消耗门槛标准

**1.1.1.一方客户接入：由自有产研团队对接** 



**RTA**  

●该客户通过RTA决策产生的营销总消耗需达到日均10万元



**ADX**  

●该客户当前直投日耗超50万元，接入后通过该客户的ADX决策产生的营销总消耗达到日均2万元



**1.1.2.三方代理角色接入：由代理的产研团队对接，为代理子客提供服务**



**RTA**  

●需提供在其他媒体平台连续三个月通过RTA决策日耗10w+的截图证明  

●代理级通过RTA决策产生的营销总消耗达到日均10万元 



**ADX**  

●代理级当前直投日耗超50万元，接入后通过此代理的ADX决策产生的营销总消耗达到日均10万元



### 1.2.消耗增幅评估

接入RTA或ADX后，为此客户、代理的营销消耗带来的增幅越大，接入优先级越高（优先级指人工客服、问题排查）

### 1.3.客户背景与业务规模评估

通过客户填写的问卷、行业、互联网信息获取，主要角度包括不限于：  

●当前营销的日均消耗情况  

●其他媒体接入与消耗情况  

●业内影响力  

●技术能力储备  

●行业客情  

●数据价值

### 2.2.质量维度

●客户RTA超时率或错误率大于5%，且警告后7天内仍未解决的  

●客户参竞质量影响大盘性能，对内产生性能质量波动的  

●其他技术性能指标产生异常情况的  

符合上述条件的，会直接冻结客户RTA请求，根据实际影响严重程度，判定限时整改或直接解除合作

### 2.3.合规维度

接入方在接入前需与腾讯营销签署《数据保护协议》。若接入方存在违反《数据保护协议》的情形，腾讯营销有权终止合作并保留追究责任的权利。



# 二、对接流程

## 1.基于准入标准套餐，完成自身资源、成本评估，明确接入需求

新接入客户只能使用程序化营销标准套餐，下发的用户ID类型为均为设备ID，待完成接入稳定运行后再申请使用高阶原子能力，标准套餐配置如下：

### 1.1.ADX



| QPS(上限)	| pretargeting	| 媒体优选/营销位优选| 

| -------- | -------- | -------- |

| 2万	| 开放，自行调用| 	不开启| 

### 1.2.RTA



| QPS(上限)	| 缓存	| 策略ID回复上限	| 二次请求	| 加权/出价能力| 

| -------- | -------- | -------- | -------- | -------- | 

| 30万	| 接受：1小时
拒绝：24小时	| 100	| 不开启	| 可按需开启| 



## 2.填写信息评估收集表并提交到行业销售/运营

明确接入需求后，填写自身公司资料，便于腾讯营销评估准入资格  

●[DSP信息评估收集表](https://docs.qq.com/form/page/DSkxvT2xWSUdQZWpl?nlc=1#/result) --ADX  

●[RTA接入信息评估收集表](https://docs.qq.com/form/page/DSktSTmhxVXR3U2V3) --RTA  

●[RTA准入申请表](https://doc.weixin.qq.com/forms/AJEAIQdfAAoASYAcwZBAF4CNq3CPpamOf?#/fill) --RTA客户完成开发和自测后，填写该表  



## 3.资质审核

根据提交的信息评估收集表，对客户的准入资质进行审核，审核通过后即可进入下一环节



## 4.协议签署

双方签署《数据保护协议》，协议文本线下提供



## 5.技术对接与测试

5.1 客户拿到文档进行开发和自测——2-4周，根据客户研发能力决定  

5.2 腾讯营销生产RTA ID和 token，注册客户DSP角色——0.5天  

5.3 腾讯营销安排研发与客户进行单测、压测验证——约1-5天，根据客户研发能力决定  

其中5.1和5.2可并行



## 6.准入观察期考核

**以下为准入标准套餐的要求：**  

●**RTA**： 以全量请求发送日为D0，D1-D15无要求。在D31时回顾D16-D30通过RTA决策的消耗总和，需达10万/日。  

●**ADX**： 为客户预留冷启时间，接入后首月消耗门槛2万元、次月20万元，第三个月起固定60万元



**额外说明**  

●支持客户自定义考核开始时间：在完成前期准备工作后，双方确定正式请求发送时间（即考核开始时间）  

●如子行业制定了更严格的考核要求，按子行业与客户约定的规则执行



## 7.存量客户月度考核

具体规则参考第一部分中消耗维度的清退标准  

●**腾讯营销每月中旬回顾程序化客户过去30天消耗情况，评估是否进入预警状态**  

●**进入预警的客户，腾讯营销在下一次月度考核中再次考核，若仍未达标则关停请求**  

**注：存量客户月度考核为消耗维度，使用过程中若触发质量维度不达标，则随时根据质量维度的使用门槛警告与清退！**



# 三、常见问题

## 1.正式启用前会经历哪些阶段？

●**客户开发**：腾讯营销会提供对接文档，客户根据交互开发接入服务;  

●**模拟验证**：媒体侧人工发起请求，客户需提供少量设备号以便媒体平台验证接受 拒绝等场景的回复是否符合预期;  

●**压测评估**：媒体侧发起压测请求，QPS在压测中可控制。逐步放到申请QPS最大值且质量指标符合预期则为通过。  



## 2.正式接入后的服务质量指标在哪里看？

●请前往[Grafana](https://stat.algo.com.cn/) 。使用媒体平台提供的RTAID/Token登录。
