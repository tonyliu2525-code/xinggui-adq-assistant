# 一、规则更新
## 1、央视三方名义及logo
* 不得使用未经央视授权的称号描述或以央视名义举办的活动或业务
* 涉及央视授权，需核实具体授权内容、授权范围、使用范围等内容，确保推广内容与授权内容一致

| **素材投放示例**|
| -------- |
| ![image1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100106_682680.png) |
|✖ 素材中出现CCTV、2025年中央广播电视台春节联欢晚会名义及logo，不支持   |  |

## 2、云养经济
* “云养经济”领域违法犯罪活动高发，借助互联网进行宣传推广，从事投资融资违法犯罪活动，侵害公众合法利益，损害农业产业健康发展，不支持投放

| **素材投放示例**|
| -------- |
|![image2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100126_567401.png)  |
| ✖ 素材中出现“线上农场、在线认养”等暗示云养殖业务，不支持  |

## 3、自助棋牌室加盟
* 经营项目：不得涉及赌博类棋牌或游戏机等服务
* 不得出现真人打牌、打麻将、真实的扑克牌形象

| **素材投放示例**|
| -------- |
|![image3.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100203_849521.png)  |
|X素材中涉及真人打牌，且包含赌资，不支持   |

## 4、禁渔期
* 推广内容不得涉及“长江流域”或其他禁渔水域内的非法捕捞、垂钓、加工、售卖水产

| **素材投放示例**|
| -------- |
| ![image4.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100233_548468.png) |
| X素材涉及“长江鱼”，因长江流域十年禁渔，不支持  |

## 5、动漫形象
* 素材不可涉及胸部放大特写、触摸、湿身透视、挤压胸部等场景
* 素材不支持裸露身体敏感部位

| **素材投放示例**| **素材投放示例** |
| -------- | -------- |
| ![image5.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100259_020880.png) | ![image6.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100310_993509.png)  |
|X素材中人物湿身透视，不支持   | X素材中人物臀部完全裸露，不支持 |

## 6、信用卡业务涉及星巴克优惠券审核要求
* 银行信用卡投放中涉及星巴克优惠券活动，需提供与星巴克的合作证明

| **素材投放示例**|
| -------- |

|X素材中涉及星巴克咖啡券，未提供资质证明，不支持   |

## 7、反共组织、媒体相关敏感内容
* 营销素材推广不得涉及发表美化侵略战争、批判中国制度、反党反政府等伤害民族情感的三方媒体

| **素材投放示例**|

|  ✖ 素材中“新唐人电视台（ntdTV）”，涉及反共媒体，不支持 |

## 8、推广目标—应用下载
* 推广应用下载视频、落地页/小程序、外显文案、均需体现产品名称
* 涉及实物奖品/虚拟奖品兑换，视频内容、落地页、外显文案、需明确领取条件，包括但不限于：升级完成任务可领、直接说 XX级可领XX等

# 二、拒绝top行业
## 1、护肤彩妆
### （1）养肤功效
* 彩妆类产品使用养肤描述，化妆品备案登记证明需包含养肤功效描述，或提供质检报告

| **素材投放示例**|
| -------- |
|![image11.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100517_009424.png)  |
|✖素材推广素颜霜描述养肤功效，无资质证明，不支持   |

### （2）虚构营销故事
* 营销中不得利用虚假情景演绎的形式做宣传，包括但不限于：XX人（包括但不限于博士、专家、研究生等）历经艰辛研究出的全新产品、科技突破等描述

| **素材投放示例**|
| -------- |
|![image12.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100542_371910.png)  |
|X素材中描述“科研成果、创新突破”，涉及虚假营销场景，不支持   |

### （3）功效承诺
* 不支持使用夸大、承诺、绝对化用语及虚假宣传的描述

| **素材投放示例**|
| -------- |
| ![image13.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100608_625431.png) |
|X素材中涉及使用夸大功效宣传的描述，如【修复】，不支持   |

## 2、珠宝钟表眼镜
### （1）翡翠玉石
* 翡翠玉石开户行业须划分至珠宝钟表眼镜/珠宝首饰，营业执照经营范围需包含珠宝首饰售卖

| **素材投放示例**|
| -------- |
|![image14.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100640_145710.png)  |
| X素材中推广翡翠，营业执照经营范围未包含珠宝首饰售卖，不支持  |

### （2）虚假营销故事
* 文章为直售缅甸/云南等地原石/宣称无中间商赚差价/保证源头/展示加工产业链/提供专属服务等编故事的形式推销翡翠玉石类产品，利用二维码引导添加微信号、了解、购买，暂不支持投放

| **素材投放示例**|
| -------- |
|![image15.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408155438_406721.png)|
| X素材中涉及暗示保障源头等内容，如【在产区有自己的玉料开采场、源头+引流】，不支持  |

### （3）仿新闻
* 标题/封面图片不得使用仿新闻报道标题误导用户

| **素材投放示例**|
| -------- |
|![image16.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100733_098245.png)  |   |
| X素材中使用模仿新闻报道形式推广，如【速看】，不支持  |

## 3、汽车
### （1）危害国家政权
* 投放内容不支持涉及对中国特色社会主义的不当言论
* 不支持宣扬包括但不限于西方国家医疗、教育制度、社会福利更好等西方优越的不当言论

| **素材投放示例**|
| -------- |
|![image17.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100758_369284.png)  |
| X素材中涉及贬低国内现状，如【薪资对比、工作时长对比】，不支持  |

### （2）危险驾驶行为
* 汽车产品推广涉及常规路段驾驶，使用辅助驾驶功能下不支持双手脱离方向盘

| **素材投放示例**|
| -------- |
|![image18.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100823_490451.png)  |
| X素材涉及驾驶过程中，双手脱离方向盘，不支持  |

### （3）国家形象
* 不得使用涉嫌假冒、借用国家名义、形象背书，包括但不限于国/央企”、“民族XX”、“国民XX等

| **素材投放示例**|
| -------- |
|![image19.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100850_911177.png)  |
| X素材中使用国家名义背书的描述，如【国车】，不支持  |

## 4、软件工具
### （1）禁止准入
a）投放内容不支持涉及作弊的教育活动，包括但不限于代写论文、代写公文等

| **素材投放示例**|
| -------- |
|![image20.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100918_099276.png)  |
|  X素材中涉及AI代写论文，不支持 |

### （2）混淆医疗
a）营销素材不得利用医疗项目及服务变相发布医疗营销

| **素材投放示例**|
| -------- |
|![image21.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408100947_374033.png)  |
|X素材宣传出现变相发布医疗营销的内容，如【解读体检报告服务】，不支持   |

### （3）国家机关人员名义及形象
* 不得使用党和国家领导人及国母的名义或者形象
* 不得使用国家机关、国家机关工作人员的名义或形象。包括但不限于名义、身份、姓名、职务、别称、肖像、雕塑、描绘及特定物等

| **素材投放示例**|
| -------- |
|![image22.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408160044_971442.png) |
| X素材中出现国家领导人，政协委员名义及肖像，不支持  |

## 5、生活服务
### （1）推广价格不一致
* 营销各元素间推广的内容（包括但不限于商品、服务、价格、销量、折扣、活动、游戏玩法等重要信息）需保持一致，且外层素材推广的内容需在落地页有对应体现

| **素材投放示例**|
| -------- |
|![image23.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408160151_238426.png) |
|X素材中出现落地页套餐价格与视频宣传不一致，不支持   |

### （2）虚假距离定位信息
* 不得出现通过模拟虚拟定位功能泄漏个人信息的描述及设计，避免使用“附近”“周边”等描述指代用户位置信息

| **素材投放示例**|
| -------- |
| ![image24.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250408101119_692561.png) |
|X素材中出现了虚假指代用户位置信息，如【附近】，不支持   |

### （3）仿国家政策通知
* 不得使用容易误导为政府发布的文字描述作为标题，涉嫌诱导点击的描述，包括但不限于“最新通知”、“好消息”、“重要XX”等宣传描述
