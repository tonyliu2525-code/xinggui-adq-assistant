# 一、功能简介

首页为如翼用户提供营销核心指标概览、人群资产概览和人群资产趋势分析三个关键子模块功能，帮助用户洞察投放情况，评估和诊断人群资产状况和趋势，为品牌用户的营销策略决策和优化提供有力的支持。



# 二、应用场景

* 当品牌用户希望了解某个时间区间内其品牌整体的投放情况，可使用核心指标概览子模块，查看看到时间区间内品牌的所有营销活动的曝光量、花费、人群曝光次数等指标统计。

* 当品牌用户需要了解某个时间点其品牌人群资产的各个指标跟benchmark对比情况，以及本品牌在行业中所处的地位排行，可使用人群资产概览子模块。该模块呈现资产广度、资产深度、资产健康度、资产持久度四个维度的雷达图，可以清晰的看到本品牌与行业benchmark的对比，以及本品牌在行业内的排名。用户可以对品牌的人群资产有一个整体认识和初步诊断。

* 当品牌用户希望评估本品牌的人群资产指标在一段时间内的走势情况，做趋势分析和诊断，可以使用人群资产趋势分析子模块。



# 三、使用门槛和操作说明

## 1. 使用门槛



用户账号有腾讯营销如翼旗舰版的权限。





## 2. 操作过程



**1) 进入页面**



用户第一次登录会默认进入首页， 或通过页面左侧菜单导航栏，点击“首页”菜单，可以进入首页。







**2) 核心指标概览**







选择时间起始区间后，即可查看该时间区间内品牌所有营销的投放汇总后的下列指标：

* 曝光量

* 花费

* 人均曝光次数

* 千次展示均价

* 目标转化成本

* 目标转化量



鼠标hover到指标上面，会有tips显示该指标的详细说明。



**3) 人群资产概览**



选择一个时间点，即可查看截止当日，资产广度、资产深度、资产健康度、健康持久度四维雷达图，展示本品牌和行业benchmark的各指标的对比情况，可以清楚的了解到本品牌在哪些指标上优于benchmark，哪些指标不如benchmark







左上角可以切换不同的benchmark：行业均值、竞品均值、行业TOP5均值







可通过右上角【指标设置】按钮，选择需要呈现在雷达图上的指标（最少3个，最多6个指标）







每个雷达图下方，显示该指标的行业排名和行业内TOP品牌







可以在下拉选择中切换其他指标，查看不同指标的行业排名







**4) 人群资产趋势分析**



选择时间区间，显示该时间段内某指标和benchmark的趋势：







可以切换不同的benchmark：行业均值、竞品均值、行业TOP5均值：







可更换显示的指标：







点击右上角【多指标对比】按钮，在弹窗中选择多个指标，可在页面上同时显示多个指标（最多6个），可以一次观看多个指标趋势，方便在多个指标间对比趋势。
