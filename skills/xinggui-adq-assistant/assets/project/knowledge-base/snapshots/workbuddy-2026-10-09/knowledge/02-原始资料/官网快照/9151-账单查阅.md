# 腾讯营销 账单查阅

| *更新日期* | *2023-9-7* | *流程更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您已开通信用金账户，需要	查阅信用金账单	，请通过以下方式发起：

# 线上查阅

* 登录账户后台 → 顶端“财务”标签 → “信用金管理” → 进入信用金账单板块。
* 账单分为“竞价”和“合约”两个标签页内分别展现。
* 每个账单标签页内又分为“待还款账单”、“全量账单”和“还款记录”分别展示对应账单内容。
* 账单数据根据外层字段聚合展示，在“账单明细”栏点击“查看”可查阅具体账单明细。
* 账单仅展现所登录账户的信用金消耗所产生的账单，若需查阅更多账户的账单，请分别登录所在账户的相关板块进行查阅。

# 邮件查询

* 请先完成信用金邮件账单联系人登记。
* 信用金邮件账单默认按账户主体名称聚合主体下所有账户ID的账单。
* 若需按集团维度聚合集团内所有主体和账户ID的账单，请联系商务收益组触发集团账单。

# 账单说明

### 账单数据
账单内应收条目均以实际消耗进行计费，若有改单和结算流程在当月内完成，相关实结数据会进入次月结算周期内。未实结项目，需按腾讯数据进行支付。

开票金额和余额等字段非实时更新，需自行关注开票情况。实结时间仅记录订单第一次实结的日期，重复实结将不再更新字段。

### 付款与核销
请根据平台推送数据在后台进行线上付款，后台已全部启动在线还款功能。

### 发票与合同
请及时申请发票，若因发票未开具无法付款造成的逾期，同样适用相关扣罚规则。

### 逾期与欠款
务必在账单中标识的最晚还款日之前付款，若逾期付款将产生违约金扣罚、返点返货扣罚和重新进行信控评估，涉及额度和账期调减，并将影响贵司赋能评分，情节严重将列入集团高风险应收客户名单。
客户逾期付款时将承担以下责任 ：

1、如客户逾期付款，应支付违约金。违约金自逾期当日起算，每逾期一个自然日，客户须向腾讯支付相当于逾期未付款项万分之四的违约金，直至款项全额付清之日。腾讯有权从已满足发放条件的返点返货激励中扣除违约金。激励中不够的部分，客户需要进行现金补缴。原15天内逾期免支付违约金政策已取消，逾期第一天开始计算违约金。

2、客户按期足额付款，是获得腾讯给予的返点返货激励的前提。客户逾期付款将对返点返货激励产生如下影响：

1）客户逾期付款期间，腾讯暂停发放所有返点返货激励。

2）逾期付款时间在30个自然日至60个自然日之间，且最终付款完毕的，腾讯发放对应返点返货激励的50%。

3）客户逾期付款时间超过60个自然日，腾讯不再发放全部对应的返点返货激励。

3、返点返货激励为客户按期全额付款后的额外激励。客户逾期付款，即使腾讯按上述安排不再发放返点返货激励，客户仍应全额付款并支付违约金。
