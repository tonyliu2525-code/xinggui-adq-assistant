# 【规则调整】个人护理-口腔护理产品规则
1. 支持宣传基本清新口气功能文案，如“清新口气”“赶走口腔异味”“口腔难闻快用它”等描述
2. 不支持使用“祛除/去/解决+口臭”等描述
3. 不支持使用演绎口腔吐出黄黑污渍，夸大产品使用效果
4. 未提供备案证明的情况下，不支持描述修护牙釉质
5. 不支持口腔护理产品素材中利用真人/3D偏病症类画面暗示产品功效

# 【规则调整】房地产不动产权证-权利类型
集体产权性质的土地禁止宣传房屋/门店/摊位等售卖，可支持租赁

# 【规则调整】通用-涉及低质PS素材更新
不得涉及低劣PS人兽素材

**注**：可支持精美创意设计，如女娲、美人鱼、牛魔王等原创画面非PS相关形象
