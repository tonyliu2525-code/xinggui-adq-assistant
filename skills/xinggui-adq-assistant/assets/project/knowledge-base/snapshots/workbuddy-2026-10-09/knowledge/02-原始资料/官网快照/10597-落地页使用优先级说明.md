# 一、能力介绍



搜索营销在创意、关键词、组件三个层级上，都支持DP（iOS对应ulink，Android对应deeplink）、生态（小程序/小游戏/原生页/蹊径落地/官方落地页）、H5三种落地页形式；创意至少有1种落地页；关键词、组件可配置0-3种落地页。

点击组件区域和营销卡片内非组件区域时，按优先级跳转落地页。



# 二、优先级说明



不同点击区域对三种落地页优先级

● 点击组件区域时，按照“DP>生态>H5”的优先级进行跳转；DP、生态、H5的取值则按“当前组件>关键词>创意”的优先级来进行填充。

● 点击营销卡片内非组件区域时，按照“DP>生态>H5”的优先级进行跳转；DP、生态、H5的取值则按“关键词>创意”的优先级来进行填充。
