# 一、功能介绍

营销分析包含账户、营销、营销创意、创意组件四个维度的报表，供客户查看内容核心维度的效果数据，并根据数据调整和优化相关创意，提升投放效果。



## 二、操作说明

## 2.1 基本操作



● 时间选择及时间维度：目前天报表支持查看最长2年的报表数据，单次查询跨度不超过一年。小时报表支持查看最长3个月的报表数据，单次查询跨度不超过7天。跨长时间周期数据的查询可能影响您的查询性能。



● 指标口径切换：目前支持营销播放、数据上报、激活时间三个口径展示报表数据，不同的报表口径会将营销带来的转化数据统计到不同的发生时点，关于口径的详细介绍请查看文档“报表口径”



● 筛选项：在不同的报表中，支持不同的筛选项，通常包括营销ID/名称、营销版位、数据指标等。





● 数据趋势：默认为折叠状态，您可以点击“展开趋势图”获取完整的趋势图信息。您可以点击“自定义展示指标”定义趋势图中需要呈现的数据指标，最多支持6个指标进行对比，点击确定后关闭指标筛选器。在趋势图卡片内，您可以点击对应的指标名称，决定是否将该指标展示在趋势图内。目前暂不支持自定义图形类型。



● 数据下载：点击下载报表可进行数据下载，当所需要下载的报表数据量级较大（超过500条）时，您的下载将转移至离线下载中心，您可以在离线中心统一管理下载文件进度，请注意离线下载中心仅保留近7天的数据。



## 2.2 报表维度

通过左侧目录点击不同的报表，代表您所需要的不同数据分析维度，在不同维度下，我们支持了多种属性指标辅助分析。





| 维度| 时间维度 | 数据计算key |

| -------- | -------- | -------- |

| 账户   | 支持分日、分时、分时段进行分析，小时更新    | 账户UID    |

| 营销   | 支持分日、分时、分时段进行分析，小时更新 | 营销名称/营销ID  |

| 营销创意    | 支持分日、分时、分时段进行分析，小时更新   | 动态创意名称/动态创意ID  |

| 创意组件  | 支持分日进行分析，天级更新     | 创意组件ID（支持创意组件预览）   |



## 2.3 数据筛选



营销维度下，支持按照营销、营销版位、优化目标、深度优化目标、数据指标等进行筛选，呈现的数据为您所设置全部筛选项的交集。



创意维度下，支持按照创意、营销版位、数据指标等进行筛选，您可以通过营销选择指定创意，或者直接搜索创意名称进行筛选。





创意组件维度下，支持按照创意组件类型、创意组件、数据指标等进行筛选，您可以通过营销-创意-创意组件选择指定创意组件，或者直接搜索创意组件名称进行筛选



创意组件维度中，筛选创意组件类型后，您可以点击属性指标，将创意组件类型加入数据列，以便于清晰查看您所选择的创意组件类型。

# 三、常见问题

**Q : 不同维表中，如营销报表和组件报表，消耗加总值不同？**



关键词：花费对不齐/消耗对不齐/创意组件报表/素材报表



A : 营销和组件是一对多的关系，一个营销可能关联多个组件；消耗/花费实际是计费平台按照营销/创意维度统计的，报表将消耗归属在组件，由于一对多的关系存在，就会出现组件报表展示的总消耗大于营销报表的消耗；

这里使用营销库数据进行匹配和计算，能够确保每个营销/组件的消耗数据都是真实有效的了；但是由于统计逻辑比较复杂，也不严格遵守倍数关系，不应该用营销/组件的总消耗进行对账。



**Q :营销报表和其他报表，花费/消耗存在细微不同？**



关键词：花费对不齐/消耗对不齐



A :对于基础类指标，包括计费数据cost等，不同报表层级的数据会存在微小差异，实际花费以财务结算数据为准。



●对于核心报表，也就是账户、营销、创意报表，我们进行了优化，核心报表的财务数据和报表花费一致；



●对于非核心报表，比如渠道包报表等，会存在花费/消耗数据和和核心报表有细微差异，属于正常现象，请以财务结算数据为准。



**Q :超过停止投放时间，仍有花费/消耗？**



关键词：超时仍有消耗回传



A :这里是正常的，数据回流存在延迟。营销停投并不代表会立刻停止计费，已经进入投放序列的数据是已经展示的，只是计费数据还没回流过来，可以等数据全部回流后切换数据展示的口径，再次核对数据。



**Q :点击人数和曝光人数有异常？**



关键词：点击人数对不齐/结案报告点击人数



A :基础类指标的人数类指标，比如点击人数和曝光人数等，资源限制导致是预估指标，仅供参考。

投放端报表，基于不同维度进行分别去重，因此在不同维度的确可能带来预估的微小差异。另外，在结案报告中，计划层级的人数指标是营销层级的加总获得，而投放端各层级的人数指标是分别去重获得，因此不同位置相同维度存在微小差异，属于正常现象。



**Q :点击率大于100%？**



关键词：点击率偏高/点击率异常



A :点击率如果大于100%也是正常的，可能的情况：1）统计维度的分子和分母口径没对齐；2）存在作弊数据。

1）请先核对同周期内该标的物的点击次数和曝光次数；2）偶有作弊情况发生，曝光会命中作弊逻辑，减少有效曝光次数，但是点击次数还在，因此造成点击率偏高。





**Q :按版位细分功能出现未知数据？**



关键词：版位数据/查看版位/未知(0)



A :暂只支持时间维度为分日数据，只支持查询前一天及以前的数据；不支持实时数据查询，不支持选择今日数据。由于流量差异较大，极少量数据可能会显示版位“未知”，属于正常情况。查看总计是正常的，版位也都是客户所选版位，未知不会持续发生。
