# 一、能力介绍
搜索营销（竞价）（以下简称搜索营销）通过关键词匹配搜索词，召回营销和创意，最终实现营销播放。投放端包括4个层级：计划-营销-关键词-创意。

# 二、操作说明
## 2.1  投放流程
### 2.1.1 创建计划
●设置营销目的和营销载体类型。

| **营销目的**	| **营销载体**	| **适用场景**|
| -------- | -------- | -------- |
| 用户增长	| Android应用	| 提升应用的下载、安装、激活、付费等，适用于有手机客户端应用下载需求的客户|
| 用户增长	| IOS应用	|   同上                               |
| 加粉互动	| 微信公众号	| 推广公众号，吸引更多用户关注|
| 商品销售	| 页面跳转	| 提升线上商品，带来更多客户和订单，适用于电商推广类的客户|
| 品牌宣传	| 页面跳转	| 扩大品牌影响力，吸引更多用户参与活动，适用于品牌曝光强诉求的客户|
| 线索留资	| 页面跳转	| 提升销售线索的获取量，适用于希望通过落地页引导在线转化或线索收集的客户|
| 用户增长	| 微信小游戏	| 吸引更多用户玩小游戏，适用于微信小游戏推广类的客户|
●设置计划日预算
设置计划日预算，控制一个推广计划下所有营销每日消耗总和的最大值

●设置计划总预算
设置计划总预算，控制一个推广计划下所有营销消耗总和的最大值

●设置推广计划名称
设置推广计划名称，为你的计划设置名称，方便管理；
可使用“命名规则”通配符按自定义规则自动批量命名；![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20251118104849_952069.png)

### 2.1.2 创建营销
●设置营销形式
常规搜索营销：适合常规投放场景或拥有海量商品投放需求的场景，需设置关键词；
搜索动态商品营销：适合拥有海量商品投放需求的场景，围绕商品进行投放和动态创意生成，不设置关键词
![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20251118104904_899805.png)
●设置商品库
营销形式=常规搜索营销，商品库和商品系列选填；
营销形式=搜索动态商品营销，商品库和商品系列必填；
![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20251118104919_563377.png)
●设置目标详情
○推广目标和目标详情对应关系

| **营销目的**	| **营销载体**	| **目标详情**|
| -------- | -------- | -------- |
| 用户增长	| Android应用	| 应用ID|
| 用户增长	| IOS应用	|    应用ID           |
| 加粉互动	| 微信公众号	| 公众号开发者ID|
| 用户增长	| 微信小游戏	| 小游戏ID|
![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20251118104933_552285.png)

○转化归因设置
■当该账户未开通新版归因链路白名单，需要设置转化归因：可设置为”全网归因“或“精准匹配归因”。
全网归因：表示所有数据源回传的数据都有可能匹配到你的营销；
精准匹配归因：表示只有通过绑定的数据源回传的数据才能匹配到你的营销；
■当该账户开通新版归因链路白名单，则无需设置转化归因
![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20251118104951_788920.png)
●设置营销版位
支持单独选【微信搜一搜】、【QQ浏览器等】【腾讯营销联盟搜索】版位，支持多版位通投；
【微信搜一搜】【QQ浏览器等】支持设置PC、移动流量场景。
![image (5).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20251118105005_840264.png)

![image (6).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20251118105023_810164.png)
●设置排期、出价和预算
排期：仅在投放日期和时间内展示营销；
出价：支持oCPC和CPC出价方式，oCPC出价方式支持设置优化目标、出价策略；预算
![image (7).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20251118105035_430019.png)

为营销设置名称，方便管理，支持使用命名规则；

### 2.1.3 创建关键词
支持系统拓词（以词拓词、行业拓词）、手动填词；
出价方式=CPC，关键词支持设置出价；出价方式=oCPC，关键词不支持设置出价；
关键词匹配类型详见[匹配类型说明](https://doc.weixin.qq.com/doc/w3_AWcAGwafAIQgr1B2a2bQiuiohE0EK?scode=AJEAIQdfAAobNIet3wAWcAGwafAIQ )

# 三、常见问题
Q：**搜索直投营销层级出价、关键词出价优先级是怎样的？**
A：CPC出价方式，关键词出价优先于营销出价；oCPC出价方式，使用营销出价，不设置关键词出价。

Q：**搜索营销竞价排序的规则是怎样的？**
A：搜索营销竞价排序主要由综合商业价值eCPM决定。eCPM则主要由客户出价 、质量度综合得分等因素决定。排名按eCPM从高到低排序，eCPM越高，营销竞争力越强，胜出概率越大。其中：
●质量度综合得分：基于相关搜索下历史点击转化数据，主要结合用户搜索意向、用户搜索匹配度、创意及落地页质量与相关性等因素，计算出用户搜索场景对营销综合得分。
●客户出价：代表客户在投放端表达的出价，出价越高，营销竞争力越强；支持 oCPC、CPC出价方式。

Q：**搜索竞价投放按什么计费？**
A：曝光或点击后，按照实际扣费公式计算，实际扣费=下一名eCPM+0.01元。  其中 oCPC 出价方式，平台针对用户意图实时动态出价，满足优化成本的目的。

Q：**搜索竞价投放一般展示在哪些位置？**
A：搜索营销一般展示在搜索结果页的首页，具体位置根据竞价排序规则及搜索平台的具体情况会有不同。搜索营销会带有“营销”标识，可通过该标识了解搜索营销展示位。
