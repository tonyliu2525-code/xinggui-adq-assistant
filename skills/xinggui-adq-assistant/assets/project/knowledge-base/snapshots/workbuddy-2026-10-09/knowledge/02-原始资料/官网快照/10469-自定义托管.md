# 一、功能介绍



自定义托管（原智能投手-自定义托管）可帮助优化师实现系统实时盯盘和营销优化，如想要控制营销的成本（可选择需要监控的营销范围，设置转化成本超过X元或出价的Y%，自动调低出价或暂停）解放优化师长时间紧盯电脑的人力消耗，盯盘效率每半小时即可检查所有账户，减少损失。



# 二、规则新建



1）入口1：新版投放平台-概览，点击托管机器人开启存量规则与执行记录管理弹窗，再点击“新建托管规则”按钮，即可进入自定义托管规则新建界面









2）入口2:工具-自定义托管，在存量规则与执行记录管理界面点击”新建托管规则“按钮，即可进入自定义托管规则新建界面









3）规则命名









4）执行范围：支持账户维度、营销维度



● 账户维度（托管所选账户下所有营销）：支持指定账户、全选账户



● 营销维度（托管指定账户下的指定营销）：必须先选择账户，再选择账户下需要托管的营销









5）满足条件：可设置规则的触发条件（如消耗小于x时执行操作）



● 数据口径：仅支持转化回传口径



● 指标类型：支持营销属性指标、营销数值指标



营销属性指标：仅营销维度托管时支持，可使用如”营销版位”、“出价类型”、“日预算”等营销属性指标作为条件

营销数值指标：支持使用报表数据，如”花费“、”曝光次数“、”目标转化成本“等报表指标作为规则触发条件



● 条件：支持等于、小于、大于、等触发条件









6）执行操作：支持启停营销、删除营销、修改投放开始日期、修改日预算、开关一键起量、修改出价、修改深度出价等托管操作；同时，可支持设置单日的执行次数上限，超过上限后，该托管操作将在此日内停止执行。









7）执行时间：



规则的运行时间，可选择每半小时、每小时、固定时间对执行范围进行扫描。因运行规则需要时间，实际规则操作时间可能会在开始运行后15分钟内完成。



● 每半小时：规则创建成功后每半点/整点对运行对象进行一次扫描，如13:05分创建规则，则在13:30进行第一次扫描，之后则每隔半小时进行扫描。



● 每小时：规则创建成功后每整点对运行对象进行一次扫描，如13:05分创建规则，则在14:00进行第一次扫描，之后则每隔1小时进行扫描。



● 固定时间：可指定在周一至周日的具体某个时间点进行扫描。









# 三、规则管理与查询



1）可在自定义托管页面，对自己创建的规则或者协作者创建的规则进行查看及操作。









2）通过创建者信息，可查询规则的创建角色
