# 一、功能解析

在数字营销的演进历程中，"定向"始终扮演着至关重要的角色。新版“智能定向”平衡了"尊重业务边界"与"突破效果天花板"的双重诉求， 告别传统手动定向的复杂设置，拥抱AI驱动的智能投放新时代。通过"智能找人+效果调优"双引擎，突破定向边界限制，为客户带来GMV和消耗的双重增长。该功能已于2025-09-04起逐步放量至全行业。



相比常规的手动定向，「智能定向」可以：



●提供更精简的定向表达



●探索高质量人群，并配合后台策略进行效果优化



根据行业特性，不同账户的定向探索能力存在差异，详情可以参考下方智能定向使用说明。



# 二、使用指引

## 1.腾讯营销投放平台操作流程

### 1.1 新建营销

客户新建营销时，将默认进入「**智能定向**」

![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164059_897323.png)

客户点击「**展开更多选项**」，出现“**定向受众**”，下方提示“系统将在XX、XX定向上为您做人群拓展”，并保留“**手动定向**”切换入口；

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164453_926463.png)

客户可通过点击「**全部定向**」，展开更多定向设置（**展开定向设置在不同行业间存在一定差异**）；

![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164518_635763.png)

**1.1.1 「智能定向」切换至「手动定向」**



如客户需使用“手动定向”，点击“**手动定向**”切换按钮时，会触发相关弹窗提示“建议使用「智能定向」，您依然可以表达定向受众，系统会基于您的定向表达探索更多优质人群，提升投放效果”

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164536_066682.png)

如客户依然选择“**使用手动定向**”，则进入“**手动定向**”设置界面，客户可通过点击“重新开启”再次进入智能定向；

![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164552_767041.png)

客户可通过点击「**全部定向**」，展开更多定向设置，上方提示“建议使用「智能定向」，您依然可以表达定向受众，系统会基于您的定向表达探索更多优质人群，提升投放效果”；

![image (5).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164612_927244.png)

**1.1.2 「手动定向」切换至「智能定向」**  

在「手动定向」设置界面，客户可通过点击“**重新开启”/“返回智能定向**”，切换至「智能定向」，部分定向设置仅在手动定向中支持，切换至智能定向可能会下线（**下线定向设置在不同行业间存在一定差异**）。  

在切换至「智能定向」过程中：  

●在「手动定向」设置的定向在「智能定向」中不涉及下线，则可直接切换至「智能定向」

![image (6).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164635_581720.png)

●在「手动定向」设置的定向在「智能定向」中下线时，系统会弹窗提示“**XXX定向仅在手动定向支持，切换到智能定向后不再生效**”，如点击“确认”，则进入智能定向，如点击“返回手动定向”，则保持在手动定向。

![image (7).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164647_147446.png)

### 1.2 编辑营销

当客户针对存量营销进行编辑时，系统会默认进入「手动定向」设置，保留存量营销定向设置内容，客户可通过点击“**重新开启**”切换至「智能定向」，切换至「智能定向」的相关操作具体见1.1.2（「手动定向」切换至「智能定向」）部分。  

注：如该营销历史已选择过进入「智能定向」，则编辑时将继续保留在「智能定向」

![image (8).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250917164704_717171.png)

## 2. Marketing API开发指引

adgroups/add 和 adgroups/update 新增参数 smart_targeting_mode，非必填：  

●智能定向：不传，默认是智能定向  

●手动定向：SMART_TARGETING_MANUAL（每次调用adgroups/add 和 adgroups/update都要携带）



adgroups/get 新增参数smart_targeting_status，客户可以通过该参数获取当前营销的定向模式：  

●智能定向：SMART_TARGETING_AUTO  

●非智能定向：SMART_TARGETING_NONE 或者为空  



相关接口：  

adgroups/add: [点击查看](https://developers.e.qq.com/v3.0/docs/api/adgroups/add )  

adgroups/update: [点击查看](https://developers.e.qq.com/v3.0/docs/api/adgroups/update )
