# 本地商务服务新手专属！3 步速通朋友圈表单营销，让潜在客户主动留资

商务服务行业想通过朋友圈获取线索，却被资质准备、落地页搭建难住？这份教程用「准备 - 新建 - 创意」三步流程，帮你绕开线索收集的所有雷区！现在跟着三步走，明天就能在朋友圈收获第一批咨询线索！

# 1.准备工作

|  **任务**	  |   **路径**	  |   **示意图**  |

| -------- | -------- | -------- |

|    1.确保可以看到[投放管理平台](https://ad.qq.com/)以及[工作台](https://ad.qq.com/cm/home)	  |    **点击[投放管理平台](https://ad.qq.com/)以及[工作台](https://ad.qq.com/cm/home)查看**；
若看不到工作台，可以询问右侧浮窗的“妙问”AI，或参考[【客户工作台】操作手册](https://doc.weixin.qq.com/doc/w3_AXQAsgaGABAGvhwf0N5T5mrc8YELP?scode=AJEAIQdfAAov8uppyFAVwAbgYtAMA) 。|             

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613162341_928227.png)![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613162348_664888.png)             |    

|    2.新建商务服务推广产品	|    点击进入[客户工作台](https://ad.qq.com/cm/home) 操作
●点击【**资产**】➡️点击左上角（如右图）➡️切换到“**业务单元**”➡️点击推广产品，选择“**商务服务产品库**”➡️点击“**新建产品**”|   

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613162526_866110.png)         |    

|    3.填写相关的信息描述产品	|    ●填写相关的信息描述产品。以专攻离婚案件的律师事务所为例：
➢「**类目**」选择“**商务服务**”➡️“**律师及法律服务**”
➢「**业务范围**」选择“**限定**”➡️下拉选择“**婚姻家庭**“
➢  填写「**名称**」➡️点击“**确认**”。|      

![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613162542_942382.png)            |    

|    4. 准备好图片素材	|    ●准备好一张用于朋友圈营销显示的创意素材（图片大小≤400KB)；
●准备好一张512X512的图片用于朋友圈营销显示的品牌头像素材	|                  |    

|    5.准备好审核通过的官方落地页	|    **点击进入  [投放管理平台](https://ad.qq.com/)**：
●点击【**工具**】➡️点击“**官方落地页**”
●新建“**官方落地页**“
➢「**顶部**」：选择“**引用外层创意**“；
➢「**转化**」：选择“**表单**”➡️选择“**常规位置**”➡️填写右侧的落地页相关信息
➢点击“**提交**”，等待审核通过。	|       

![image (5).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613162558_580861.png)                |    









# 2.新建营销



|   **任务**	|   **路径**	|   **示意图**  |   

| -------- | -------- | -------- |

|    1.明确营销类型	 |    点击登录[**投放管理平台**](https://ad.qq.com/ )
●点击【竞价推广】➡️【新建营销】	|

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150131_833900.png)![image.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150145_820898.jpg)                    |    

|    2.填写营销内容	  |    ●填写收集用户联系方式下的营销内容
➢「**营销目的**」：选择“**线索留资**”；
➢「**推广产品**」：选择“**商务服务**”，勾选弹窗已创建好的产品；
➢「**营销载体**」：选择“**页面跳转**”；
➢「**优化目标**」：下拉选择“**表单预约**”；| 

![image (1).jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150156_826618.jpg)                     |    

|    3.设置朋友圈版位和出价	  |    ●设置朋友圈营销的版位和出价
➢「**营销版位**」：选择“**选择特定版位**”➡️仅勾选“**微信朋友圈**”
➢「**出价设置**」：“**元/表单预约**”为获取一个联系方式出的钱；
举例：我愿意为获取一个对打官司有需求的电话出300元，即在此空上填写300。（仅供参考）	 | 

![image (1).jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150222_513573.jpg)   

![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150214_107554.png)                     |                  

|    4.提交营销     	|    ●点击“**提交并新建创意**”。	 |![image (3).jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150243_161182.jpg)                       |    







# 3.新建创意

|    **任务**	|    **路径**	|    **示意图**    |    

| -------- | -------- | -------- |

|   1.导入准备好的图片素材	|
**”点击/拖拽上传“将准备好的创意素材图片导入**|  

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150726_361692.png)                  |   

|   2.填写文案	|    填写营销文案	   | 

![image (4).jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150741_307629.jpg) | 

|   3. 勾选落地页	|   选择已经创建好的“**官方落地页**”	|   

![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150829_463156.png)               |   

|   4.制作品牌形象	|   选择“自定义”➡️点击左下角“+”号➡️在弹窗中选择“自定义”➡️上传准备好的品牌头像素材➡️填写品牌名称（即朋友圈营销显示的账号名称），点击“**确定**”。	| 

![image (5).jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150849_234963.jpg)![image (6).jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613150854_164958.jpg)                      |   

|   5.提交创意	|   点击“**提交创意**”。
一条收集用户联系方式的朋友圈营销便创建好了！|
