# 【规则新增】教育-复读

1. 禁止投放中考复读

2. 高考复读不支持使用低龄化素材、学校教师面向孩子的场景

# 【规则调整】电商- 虚假人设或事件

1. 虚构人物行为类：不支持编造违背常理的人物行为，借此宣传产品

2. 过度神化身份类：不支持采用过度神化人物身份及状态，借此宣传产品

3. 借高龄老人博眼球暗示功效类：不支持利用高龄老人形象博人眼球，暗示产品具有特殊功效

4. 过度渲染身份影响力类：不支持过度渲染人物身份影响力来推广产品



# 【规则放宽】金融-基金名称及代码使用规范

金融/基金行业允许在营销中使用基金名称及代码，但须符合以下要求

1. 不支持明示或暗示保本/保收益，预测基金的证券投资业绩及其他夸大类描述；包括但不限于”稳赚不赔“、”收益稳冲4%“、“历史100%兑付”“爆款产品已超募集金额”等

2. 不支持虚假营销活动的描述，包括但不限于“限时限量”、“最后一波”等

3. 不支持引用未经核实、预测性或者模拟的数据
