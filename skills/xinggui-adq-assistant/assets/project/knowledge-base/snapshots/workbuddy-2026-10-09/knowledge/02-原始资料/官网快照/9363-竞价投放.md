# 一、能力介绍

在营销进行投放时，客户创建的营销会通过定向表达自己的目标受众，平台会对满足目标设置的营销开放竞价窗口，使营销能够公平竞争获得曝光。竞价投放在不同版位、场景的售卖规则不同，目前提供5种售卖方式：CPC、CPM、CPA、oCPC、oCPM



# 二、售卖方式介绍



* **CPM:** Cost Per Mille (每千次曝光的花费)，按展示出价，按展示计费



* **CPC:** Cost Per Click(每次点击的花费)，按点击出价，按点击计费



*  **CPA:** Cost Per Actio(按每次下载付费)



*  **oCPM:** Optimized CPM，以展示计费的智能出价。选择特定优化目标，并提供期望平均转化成本后，系统预估每一次展示的转化价值，自动出价，按照展示扣费



* **oCPC:** Optimized CPC，以点击计费的智能出价。选择特定优化目标，并提供期望平均转化成本后，系统预估每一次展示的转化价值，自动出价，按照点击扣费
