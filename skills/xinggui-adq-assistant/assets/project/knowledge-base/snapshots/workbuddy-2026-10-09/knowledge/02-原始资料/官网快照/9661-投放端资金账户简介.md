# 腾讯营销 投放端资金账户简介

| *更新日期* | *2023-11-6* | *内容更新* |
| -------- | -------- | -------- |

资金账户作为交易的基础，基于不同场景的资金来源，建立了以下类别的资金账户

## 虚拟账户
包括测试金、补偿金、合约配送金

## 赠送账户
包括服务商激励（赠送金）、客户激励（专用赠送金or专用金）

## 现金账户
包括线上充值现金、线下对公转账

## 信用账户
包括竞价信用金、合约信用金

## 备注
根据资金不同的充值场景和来源，资金共分为四大类。资金账户作为一种资金池形态，涉及资金安全；同时资金账户系统本身属于会计范畴，使用过程中需要遵守一系列的会计准则。不同类型的资金分别进入不同的资金账户中，其分别有不同的政策规则。在政策结算中，不同的资金类型有不同的政策规则，需分别核对。
