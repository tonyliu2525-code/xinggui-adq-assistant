# 服饰运动优化师速看！3 步引爆视频号直播流量，ROI 优化有公式

想通过视频号直播卖爆服饰运动单品，却不懂如何投放营销引流？**本文档主要面向【服饰运动行业的投放新手】，教你零基础创建一条【视频号直播间营销】**！通过用「准备工作 - 新建营销 - 添加创意」三步法创建一条营销，带你从直播间授权到创意投放全流程落地！


●提前备好 3 条 9:16 竖版视频，结合 “商品销售 - 视频号直播 - 下单” 的优化目标链路，系统自动匹配高转化人群；


●ROI 计算公式（客单价 × 期望 ROI）直接套用，出价不再凭感觉；


●浮层卡片、直播标签等营销组件一键开启，让用户刷到视频就能秒进直播间；


●24 小时审核时效 + 成本保障规则，新手也能放心投放，开播即引流！

# 二、新建营销的关键信息





|**任务**| **路径** | **示意图** |

| -------- | -------- | -------- |

| 1.明确营销类型    | 【**投放管理平台**】[投放管理平台](https://ad.qq.com/)
【竞价推广】-【新建营销】   |

![二1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612173126_653836.png)   |

| 2.主投优化目标     |【营销目的：商品销售】
【推广产品：视频号直播】
【选择具体视频号，并勾选“我已知晓”】
【优化目标：下单】  |  

![二2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612173202_019763.png)  |

| 3.设置主投版位与出价     |【营销版位】-【选择特定版位】-【微信视频号】-【定向拓展：开启】
【出价与预算】-【计费方式：oCPM】-【出价类型：稳定拿量】
【出价：输入为了用户下单您期望支付的具体价格】
➡️举例：客单价=80元，期望ROI=1.2，出价大约可以为67元
【高价值人群探索：开启】-【策略类型：种草人群探索】
【营销日预算：不限】
➡️避免频繁调整出价，减少账户/营销预算下调操作，避免大幅下调；具体预算设置及操作详见：[腾讯营销「预算设置」操作指引 ](https://doc.weixin.qq.com/doc/w3_AH0AYga-ACc1QHzUrgTT0itOvCwAg?scode=AJEAIQdfAAol1aou2uAd4A8QavANw)    | Text
