# 腾讯营销 交易合规要求

| *更新日期* | *2024-3-5* | *流程更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

根据合规要求，交易过程需遵守资金流、发票流及货物流“三流合一”的原则，即合同、资金、发票、服务的主体信息应一致。请您使用与投放账户主体名称一致的银行账户或实名认证的电子支付账户进行充值或退款。您的实名信息将提供给合作的支付机构进行核验，主体非一致交易将被系统拦截或人工驳回。

| 交易场景 | 交易方式 | 一致性校验 |
| -------- | -------- | -------- |
| 线上 | 网银支付 | 付款主体一致性校验 |
| 线上 | 微信支付 | 个人账户实名校验 / 个体工商户法人实名校验 / 企业无微信支付
| 线上 | 固定识别码 | 付款主体一致性校验 |
| 线下 | 对公转账 |  付款主体一致性校验 |
