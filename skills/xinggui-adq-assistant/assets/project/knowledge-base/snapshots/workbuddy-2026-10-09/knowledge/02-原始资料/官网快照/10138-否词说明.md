# 一、能力介绍

支持对通投营销设置否定词，当用户搜索词匹配到否定词，不展示该否定词所对应的营销。

# 二、适用场景

当关键词匹配到的某些搜索词流量的效果欠佳，可配置否定词屏蔽对应流量。

# 三、操作说明

操作路径： 推广-->营销-->编辑营销否定词



点击编辑按钮打开「设置否定词」弹窗。







支持设置短语否定词和精确否定词，合计最多设置900个词。短语否定指搜索词包含否定词，精确否定指搜索词与否定词完全一致。

点击「点击新增词」按钮添加否定词。







输入或粘贴否定词后，回车新增词。



单个否定词最长20个字；同一否定词词面不能同时设为短语否定和精确否定。



支持编辑、删除单个否定词，支持一键复制和清空全部否定词。
