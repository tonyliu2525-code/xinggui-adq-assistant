# 一、什么是【首发标签】

●**首发**，指的是历史**未在腾讯营销投放系统中出现过**的**高创新度**素材或组件。被打上【首发标签】的素材，被称为**首发素材**

●在投放端平台中，满足首发条件的**素材及组件**会获得【首发标签】（满足条件见第3节），客户可通过以下两条路径查看【首发标签】（具体路径见第4节）：

○**投放管理平台 ⇒ 新版创意投放 ⇒ 图片 / 视频编辑页面**

○**投放管理平台 / 客户工作台 / 服务商系统 ⇒ 资产 ⇒ 创意素材管理 / 创意组件管理**

# 为什么要做【首发标签】
**对客户**

●**专属的平台激励** ：作为新发产品福利，标记为首发的素材和其对应的创意组件，将会获得**首发素材冷启探索**，帮助新素材更快起量！数据分析表明，相比于重复或是老旧创意，首发素材在探索策略加持下消耗**显著提升**！

○**小窍门**：若在多个账户中创建了相同的素材，那么仅会对最先过审的账户的素材上打首发标签，并在单一账户内获得首发权益。**若想让首发素材跨账户使用，并都获得首发权益**，请将素材上传至[【高维业务单元】](https://doc.weixin.qq.com/doc/w3_ALsAcQaSAD4dem2KPvbRFKE3w7EqL?scode=AJEAIQdfAAoMdw5POVASwARgb5AOA)（点击链接可跳转至具体操作指引）

**对用户**

●**更好的营销体验**：多元、新鲜、丰富的营销创意，将会给用户带来更好的观览感受，让营销本身成为一种有趣有料的内容体验

# 三、如何获得【首发标签】
## 【首发标签】判定规则

●**素材获得首发标签**

○首次使用的高创新度图片 / 视频素材，当其关联创意**通过内容审核**，并被系统（首发标签的获得以腾讯营销的自行判定为准）判定与所有历史同类型（如视频和视频比，图片和图片比）过审素材对比均**存在明显差异**，即被认定为首发素材

●**组件获得首发标签**

○**单图组件**：组件内对应的单图素材为首发素材

○**视频组件**：组件内对应的视频素材为首发素材

## 如何生产符合首发标准的新素材
●**避免重复**：不要反复使用 / 创建相同素材

●**避免相似**：只对老素材做简单翻改 / 调整，将无法达到系统的查重阈值，**无法获得首发标签和对应首发素材冷启探索**

●**鉴往知来**：盘点既往跑量和效果俱佳的优质素材，作为灵感源泉创作新素材

●**破旧立新**：不论是原创新素材还是借鉴老素材，都要保障足够充分的视觉创新度，才能成功被系统识别

●**快速行动**：及时上传即将用于投放的高创新度素材

# 五、常见问题
Q1：**完全相同的首发素材，在不同的投放账户下投放使用，会如何展示标签？**

A1：系统经过对比大盘全局已有的素材，基于视觉相似度，判断是否赋予首发素材标签，当相同的素材在不同的账户下被创建使用，会依据审核通过的时序，**优先过审的会标记为首发**（举例：某首发素材在A和B两个账户下分别创建，但在A账户先过审，则该素材只会在A账户内获得首发标签和首发素材冷启探索）。若想让同一素材在多个账户内都享受首发素材冷启探索，请见问题2。

Q2：**我有一套全新的创意素材，希望在多个账户投放，如何能让它们都享受到首发素材冷启探索？**

A2：可以上传创意素材到[【高维业务单元】](https://doc.weixin.qq.com/doc/w3_ALsAcQaSAD4dem2KPvbRFKE3w7EqL?scode=AJEAIQdfAAo0OWlBL3ASwARgb5AOA)（点击可跳转至具体操作指引），该业务单元下所有账户均可在投放过程中引用这套素材，若素材符合首发判定标准，则使用了首发素材的多个账户均可享受到首发素材冷启探索。

Q3：**首发素材标签的校验范围是？**

A3：创意过审并完成和大盘已有全部同类型过审素材的对比（比如视频和视频比，图片和图片比），经系统按首发规则计算校验后，就会生效。

Q4：**API来源的素材会参与首发打标吗？**

A4：会，只要是自建素材，都会参与打标。

Q5：**图片和视频素材都会参与首发打标吗？**

A5：2025年6月中下旬前仅支持对视频素材的打标，之后会同步支持图片素材，请关注第6节的产品迭代日志，尽情期待。

Q6：**同一条首发素材，删除之后再上传，会持续保留首发标签吗？**

A6：素材删除前，如果没有绑定营销并过审，则不会进入系统的首发判定流程，删除后再次上传仍会获得首发标签。但如果在过审后删除素材，由于该素材已经存在被打上首发标签的系统记录，则删除后再次上传过审将不会再获得首发标签。

Q7：**做了一条新素材，为什么没有获得首发标签？**

A7：客户认定素材不重复，但却没有获得首发标签，可能是由于与大盘其它客户无感知的历史素材重复，或是素材本身仍未达到系统判定首发的阈值门槛。首发标签的获得以腾讯营销的自行判定为准。
