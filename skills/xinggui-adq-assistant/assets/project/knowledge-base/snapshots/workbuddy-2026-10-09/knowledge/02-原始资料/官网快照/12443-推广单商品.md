# 微信小店商品库

## 1、资产库定位和适用场景

**适配已在微信小店开店并完成商品上架的客户，在腾讯营销推广时，可通过授权的方式，完成微信小店商品信息拉取**，关联至投放。营销中关联的小店商品信息将会进入腾讯营销模型，并应用于投放优化。



## 2、两步完成微信小店授权

### 2.1 授权入口

腾讯营销投放端[【腾讯营销 - 投放管理平台】](https://ad.qq.com/) -> 工具 ->微信生态授权管理 -> 微信小店授权 

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813173212_156304.png)



### 2.2 授权流程

**发起授权->输入小店名称并点击校验（确认是自己要关联的小店）->小店管理员扫码确认授权（必须是小店管理员才能授权）**

![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813173224_389951.png)



### 2.3 授权状态说明

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813173236_085124.png)

●授权成功：可前往创建营销  

●待授权：已发起该小店授权，请联系小店小店管理员完成扫码授权;  

●取消授权：该小店授权已被取消，请点击下方重新申请；  

●授权过期：该小店授权已过期，如需续期，请点击下方续期授权关系；  



## 3、用[微信小店商品]搭建营销

### 3.1 选择微信小店商品

**创建3.0营销时，在“推广产品”中选择“微信小店商品”，可拉取到已授权小店内【状态正常】的所有小店商品，点选想要推广的商品，操作路径如截图**  

注意1：商品为【上架】状态，且关联标品成功（腾讯营销自动关联）的商品才允许投放营销；**商品删除、下架或在审核中均无法投放营销**；  

注意2:一条营销仅支持选择一个微信小店商品，不支持对同一个商品创建完全相同的多个营销；

![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813173248_734978.png)





### 3.2 创意落地页

**直跳微信小店商品详情页（推荐）  

落地页选择【微信小店商品页】->系统自动拉取营销层级上填写的小店商品信息填入落地页中（不允许编辑）->填入后支持唤起二维码预览页面**

# 商品库

## 一、商品创建

### 1.1 资产库定位和适用场景

**适配电商行业推广单个商品客户**，创建商品成功后，在腾讯营销系统关联至投放。营销中关联的商品信息将会进入腾讯营销模型，并应用于投放优化。



### 1.2 三步完成商品创建

**1.2.1 商品创建入口**

创建入口：进入全域商品管理中心，[全域商品管理中心](https://youhuo.tencent.com/login)  

操作步骤：投放账户登录-->在组织账号维度下，**选择业务单元进入**（注意！**只有在业务单元下创建的商品才能投放腾讯3.0营销！**）

**关于第2步录入方式的说明**：

![image (14).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813173516_052093.png)

●在线录入：手动逐一录入，适合商品数量较少时使用  

●手动上传（XML）:按模板一次性批量上传商品，适合商品信息无须频繁更新时使用  

●定时拉取：通过XML文件地址的方式自动化对接，适配商品数量较多，且商品信息会频繁更新时使用，**定时拉取需要开发XML文件以及配置服务器地址，须由研发人员参与对接**，对接技术文档[腾讯AMS商品营销商品数据对接技术白皮书 ](https://docs.qq.com/doc/DVUN6RXpjQ0liUGl1  )



**关于第4步关联标品的说明**：  

●**什么是标品**：又称标准化商品单元，是一缚描述某产品特征的信息集合，是腾讯营销系统内商品粒度信息聚合的最小单位，更好地帮助营销冷启动；  

●**商品和标品的关系**：简单理解标品是商品的聚合，例如，录入的商品是iPhone 15 256G金色，则会关联或创建iPhone 15的标品进行绑定；在全域商品中心录入的是商品，商品录入后会自动关联标品，并应用于投放；  

●**关联标品的方法：系统识别、手动录入**  

一般在录入商品后，系统会自动识别并匹配标品；  

如果认为系统识别标品不准确时，可点击进行手动录入；  

![image (15).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813173600_433847.png)

●**关联标品有什么价值**：1）用利于标准化表达营销推广的标的物；2）便于模型理解和数据聚合，更好的帮助冷启动；3） 便于投放内容理解，有利于优化人货匹配；  

●**关联标品的状态请重点关注**  

商品创建完成后，【投放场景】中【**投放3.0】标识为蓝色时，代表可投放3.0营销，为灰色时，无法投放3.0营销**，可能是尚未关联标品或落地页唯一性校验未通过

## 三、如何保障[商品]信息一致



### 3.1 为什么营销创意必须要与推广产品信息一致？对投放有什么影响？

![image (19).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813173723_571982.png)



在一个陌生的路口问路，路口仅有的2个人，一个人说向左走，一个人向右走，这时是不是会陷入困惑，仍然不知道哪个方向才是对，**矛盾或不一致的信息往往造成混乱**！  

**营销信息不一致，会给营销系统带来干扰信息，造成”找路“一样的困境，从而影响投放和跑量效果**！  



如A营销上，**【推广产品】选了连衣裙，营销创意是运动鞋，落地页上又是遮阳帽**，究竟应该找对连衣裙感兴趣的人，还是要找对运动鞋、遮阳帽感兴趣的人？哪个是才是推广者真正想要的？



腾讯营销新系统（3.0）中，营销创编选择的【推广产品】【创意元素】【落地页信息】都会输入营销系统，并应用于营销模型、营销策略、冷启动等场景，是营销系统的重要数据输入。为避免误操作等原因带来的营销信息不一致给系统输入干扰信息，**腾讯营销上线了针对推广产品与营销创意、落地页信息一致性比对能力，并在系统校验出不一致时进行审核拦截，修改一致后才能正常投放。**



由于腾讯营销系统支持表达的【推广产品】类型较多，目前比对信息一致的能力正在逐步推进和覆盖，**本文主要围绕电商行业且推广产品为【商品】展开说明**

## 四、商品库常见QA

### 4.1 投放3.0营销，商品创建用什么账户？

必须进入**业务单元下**进行商品库的搭建和商品录入，同一个业务单元下的账户会**自动共享**该业务单元下创建的所有商品库和商品资产；

![image (39).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813174307_442290.png)



### 4.2 为什么创建营销时找不到商品

1）商品库仅在同一业务单元下可见：请先确认营销账号与商品库所在账户是否归属于同一个业务单元；  

2）检查商品状态：进行入全域商品管理中心，查看商品【投放3.0】标识是否为蓝色

![image (40).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250813174317_969922.png)

### 4.3 商品创建后可以更换标品吗？

**不可以**，一旦商品创建并完成标品关联，不支持进行二次编辑和更换标品，原因有2个，一是会影响资产唯一性及营销唯一性，二是可能会带来模型输入，给正在投放的营销带来数据波动；

### 4.4 为什么一直关联不上标品？

关联标品有人工审核流程，需要一定时间的，请耐心等待；
