# 腾讯营销 查询资金到账

| *更新日期* | *2023-10-19* | *内容更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您需要查询账户的资金到账情况	，请通过以下方式发起：

## 客户在“工作台”查询充值到账情况

登录工作台 → 顶端“财务”标签 → 进入资金管理

选择具体账号后，点击“查看财务记录”

![工作台-老-资金管理.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2023/396_20230918143613_950980.jpg)

![工作台-老-资金管理-查看财务记录.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2023/396_20230918143620_334666.jpg)

## 客户在“投放管理平台”查询充值到账情况

登录投放管理平台 → 顶端“财务”标签 → “财务记录”二级标签 → 进入记录列表

查阅时请注意筛选项，默认“广告充值金”，若需查看专用赠送金，请这资金类型处进行切换

![投放管理平台-财务记录.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2023/396_20230918143624_796112.jpg)

## 服务商在“服务商系统”查询充值到账情况

登录腾讯广告服务商系统 → 顶端“财务”标签 → “财务记录”二级标签 → 进入财务列表

请注意“ADQ广告”和“MP广告”在不同标签页，需分别查阅

![服务商系统-财务-财务记录.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2023/396_20230918143629_833969.jpg)
