# 腾讯营销 自助信用金账户资金划转

| *更新日期* | *2023-10-19* | *流程更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您需要对信用金在不同账户之间进行划转	，请通过以下方式发起：

## 线上自助划转

登录账户后台 → 顶端“财务”标签 → “财务信息” → 进入资金账户总览，可看到信用金的具体余额情况

![划转首页.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2023/396_20231019165747_874601.jpg)

点击“转账”按钮，选择需划转的账户类型，分别为ADQ账户和MP账户

![划转弹窗.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2023/396_20231019165752_737297.jpg)

选择划转账户类型后，系统将自动调取该账户类型下，可划转的具体账号信息

选择具体账号后，再选择投放账户类型，分别为“竞价信用账户”和“合约信用账户”

最后录入转移额度，此处需注意，金额勿超过系统提示的上限金额

![账号和额度选择.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2023/396_20231019165756_551475.jpg)

## 划转中的常见问题

* 请于“腾讯营销服务商系统”通过绑定同一集团下不同主体（已签署账期协议或担保函提供互相担保）或者同一主体下不同账号，实现ADQ和ADQ之间信用金跨主体自助互转，ADQ-MP之间同主体自助互转，总授信额度不变；
* 竞价滚动信用额度和合约滚动信用额度不能互转；
* 资金账户的账期不一致不能互转；
* 转移时需转出账户信用金余额大于转出额度；
* 若因特殊原因无法进行账号绑定，或其他原因无法线上划转，请参照帮助中心内《线下信用金账户资金划转流程》进行线下信用金划转支持。
