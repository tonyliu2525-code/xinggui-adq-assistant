# 一、能力介绍

定向是指在腾讯营销系统中，根据用户的某些特征，将用户归类到不同的群体中，通过不同的类别多维度触达目标人群，以便更好地投放营销。





# 二、操作说明

## 1. 新建定向

### 1.1. 新建定向：地理位置、年龄、性别、学历等等





### 1.2. 全部定向：如设置更多定向，如用户行为、自定义人群等等，可展开全部定向进行设置





### 1.3. 保存为定向模板：支持将常用定向保存为定向模板，最多可创建200个定向模版，下次创建营销可直接选择定向模板进行使用。





如无特殊特殊投放需求，不建议过多设置，避免定向过窄，影响人群覆盖。



## 2. 选择定向模版

创建营销是可直接复用定向模板，多个营销可以使用同一个定向模版。



定向模板可在新建定向过程中保存为定向模板，或在【资产】-【数据营销】-【定向模版管理】进行创建





## 3. 预估覆盖人群及曝光数据

根据选择的定向，系统会显示预估可覆盖的人群与曝光
