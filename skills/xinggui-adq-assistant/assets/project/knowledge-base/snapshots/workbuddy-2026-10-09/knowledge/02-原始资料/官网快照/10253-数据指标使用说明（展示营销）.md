# 1.功能介绍

当前腾讯营销投放端通过pc端、小程序、API接口为您提供了近千个精准高效的数据指标，可以完成营销全生命周期的数据分析。在帐户、营销、创意、素材等多个层级，均涵盖曝光次数、点击次数、花费、APP下载/转化/激活等常见的基础指标，如果需要平均点击单价（CPC）、平均千次展示价格（CPM）、平均转化率、平均转化成本等更多指标数据，您可以根据我们提供的基础数据自行计算得出。

通过腾讯营销丰富维度和海量指标提供的数据，您可以了解到不同营销在不同时段以及不同人群上的表现，并可以据此进一步优化投放。



# 2.操作说明

## 2.1 产品界面



![1.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/211_20240329150822_744639.png)



●指标选择器支持的功能包括：搜索、拖拽排序、保存常用指标组合等，您可以在左侧通过指标分类或者搜索选择您所需要的指标，在右侧管理指标排列顺序，点击应用即可生成所选指标的报表。





●为方便您查看各维度的指标数据，当将指标拖动在“以上指标将横向固定”上方时，为列表的冻结列，这些指标将固定在左侧展示，不会跟随您列表的左右滑动而滑动。





## 2.2 版本说明

●腾讯营销投放平台已于2023年8月全面升级新指标体系，并于2023年10月在投放端站内全部使用新指标体系，当前新指标体系为客户获取投放效果数据的主要渠道。





○新旧指标体系对比详见：[报表新旧指标梳理（对外）](https://docs.qq.com/sheet/DV2lJVk9vZ3dGSUN4?tab=BB08J2)，您也可以点击指标选择器右上角“新旧指标对比”快速进入该文档。





●为了给所有客户提供高效统一的报表体验，我们将于2024年4月20日停止维护旧指标体系，新旧指标体系接口不同，数据不会自动兼容。如果您在API接口获取数据仍使用旧指标体系，为保障您的投放体验，请您即刻开始结合接口变更与“新指标体系”进行改造，避免账户在投放平台升级新指标体系后，API接口依然无法跟进使用。



○快速区分新旧指标体系：旧指标体系中展点销相关指标名称为“曝光量”“点击量”等，新指标体系中为“曝光次数”“点击次数”等。



## 2.3 指标分类



![2.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/211_20240329151227_056735.png)



●新指标体系中主要分为基础指标、互动指标、转化及生命周期指标、视频号生态指标、公众号生态指标共计5大类。您在竞价展示营销中将主要用到通用指标对应的基础指标、互动指标、转化及生命周期指标这3类。
