# 一、什么是一致性校验

为了保障投放效果的稳定性，系统会对您营销关联的【推广产品】与真实投放的【创意元素】（如文案、图片、视频、落地页）进行一致性校验，而营销创意与推广产品不一致比较常见的表现类型主要有以下两种：



**1、类目/品类不一致**，如推广产品选择饼干，实际创意为麦片，此时需根据实际投放的需求来正确创建/选择推广产品；  

**2、品牌信息不一致**，如推广产品选择子品牌A的产品，而实际创意为子品牌B的产品，此时需根据实际投放需求更改为正确品牌的推广产品。



简而言之，新建营销选定的推广产品与营销创意及落地页里表达的产品是同一个产品，二者之间需要保持一致。



# 二、为什么要进行一致性校验

【推广产品】【营销创意】【落地页信息】不一致，主要有两方面的影响：  

**1、干扰营销系统学习，阻碍精准推荐**。不一致的营销信息会干扰系统模型的判断，难以确定客户真正想要获取的目标人群，从而影响推荐效果。  

**2、影响消费者感知，破坏品牌形象与营销效果**。如果信息不一致的营销被推送给消费者，比如创意是“连衣裙”，但用户点进来落地页是“皮鞋”，实际推广产品又是“短裤”，那么就容易造成消费者认知混乱，难以达到预期的营销效果。



因此，需要对推广产品与营销创意、落地页信息进行一致性比对，系统校验出不一致时会进行审核拦截，客户修改一致后才能正常投放3.0营销，以保障更高效准确的投放。



# 三、不一致的后果是什么

● 当创意元素表达的产品与营销推广产品选择的产品不一致时，创意元素将被拒审，客户可在「**投放管理平台->竞价推广->创意->状态**」列点击「**审核详情**」查看不一致原因，并进行**修改**，使二者一致再重新提交。  

● 当被拒审后发现创意表达的产品与推广产品一致时，可以点击「**复审**」，申诉原因选择“拒绝原因在营销中未涉及”，详细描述填写”创意与推广产品一致“，然后提交复审。  

➢**注意**：每日可申诉额度有上限，若复审通过，不占用当天该账户的复审额度。

# 四、一致性校验的节奏

目前已上线一致性校验的推广产品库：**商品库、短剧库、小说库、汽车商品库、金融产品库；**   

**其余推广产品**库预计2025年**下半年上线**一致性校验能力。
