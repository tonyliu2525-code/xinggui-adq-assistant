# 1.推广产品全集及设置方式概括

不同营销目的和行业支持的产品类型不同，全集如下，需在行业及营销目的支持的范围内选择投放的产品。

| 产品类型 | 设置方式概括 |
| -------- | -------- |
| 商品     | 1.在商品库创建3.0商品；
2.在投放流程中推广产品选择“商品”，再选择可拉取的具体商品即可。
|
| 活动     | 1.在客户工作台/服务商系统业务单元下创建活动。
2.在投放流程中推广产品选择“活动”，再选择可拉取的具体活动即可。     |
| 店铺     | 1.在客户工作台/服务商系统业务单元下创建店铺。
2.在投放流程中推广产品选择“店铺”，再选择可拉取的具体店铺即可。     |
| 商品集合     | 1.在商品库创建3.0商品，并打包商品集合；
2.在投放流程中推广产品选择“商品集合”，再选择可拉取的具体商品集合名称即可。
|
| 两品一械商品    | 1.在adhome进行药品及资质上传，并进行审核；
2.由运营/销售进行风控分配方可进行投放。     |
| 小说     | 1.在客户工作台/服务商系统业务单元下选择书城的小说创建为产品。
2.在投放流程中推广产品选择“小说”，再选择可拉取的具体小说即可。
|
| 短剧     | 1.在客户工作台/服务商系统业务单元下选择剧城的短剧创建为产品。
2.在投放流程中推广产品选择“短剧”，再选择可拉取的具体短剧即可。     |

2.在投放流程中推广产品选择对应产品类型，再选择可拉取的具体产品即可。     |
| 消费医疗     | 1.在adhome进行资质上传及风控行业分配，并进行审核；
2.完成分配后方可进行对应产品投放。     |
| 门店     | 1.在资产-区域与门店管理中创建门店，也可以将多个门店打包成门店包；
2.在投放流程中推广产品选择对应“门店”，再选择可拉取的具体的一个门店/门店包。     |
| 门店产品组合     | 1.在投放流程中推广产品选择“门店产品组合“；
2.选择已创建的门店和产品即可。
|
| Android应用     | 1.在应用推广管理工具/应用宝上传应用，获取应用ID；
2.在投放流程中填写应用ID或选择已投放过的应用即可。
|
| iOS应用     | 在投放流程中填写已上架的ios 应用ID或选择已投放过的应用即可。     |
| 微信小游戏
QQ小游戏     | 在投放流程中输入小游戏ID进行投放。     |
| PC游戏     | 在投放流程中填写游戏主域名进行投放。     |
| 企业微信     | 1.需在工具-企业微信授权与客服管理进行企业微信授权绑定；
2.在投放流程中选择已完成授权的企微进行投放。
|
| 视频号直播
视频号直播预约
视频号账号     | 1.需在工具-微信生态授权管理中进行视频号授权绑定；
2.在投放流程中选择对应的产品类型，选择已完成授权的视频号账户。
**3.注意：不可选择营销专用视频号作为推广产品，如需使用营销专用视频号投放视频号版位，推广产品选择实际推广的内容，如教育产品等，载体选择页面推广，版位需包含视频号版位，创意层级选择营销专用视频号即可；**    |
| 微信公众号     | 1.需在工具-微信生态授权管理中进行公众号授权绑定；
2.在投放流程中选择“公众号“，选择已完成授权的公众号账户。     |
| 快应用     | 在投放流程中选择或新建快应用进行投放。
|
| 微信小程序     | 在投放流程中输入小程序ID进行投放。     |
| 个微小店     | 1.在客户工作台/服务商系统业务单元下创建个微小店。
2.在投放流程中推广产品选择“个微小店”，再选择可拉取的具体小店即可。     |
