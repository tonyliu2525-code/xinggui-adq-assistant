# 一、定位和使用场景

【航司票务产品库】适用于投放推广飞机机票及航空公司品牌的业务场景。您可根据实际推广诉求，灵活选用库中和自身生意模式相匹配的资产类型，实现精准投放。



# 二、创建推广产品（客户工作台/服务商系统）

在客户工作台或服务商系统左上角/右上角登录进已创建的“业务单元”中，**仅“业务单元”支持创建和管理“航司票务产品库“的资产**。

## 1、创建入口

进入后点击资产，左侧列表展开推广内容，选择航司票务产品库。

![image (16).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250905162431_387231.png)

## 2、创建流程和要求

1）**创建流程**  

点击新建产品，出现新建弹框。先选择产品类型，包含航空公司、机票两种。





| 产品类型	| 操作界面示例	| 说明| 

| -------- | -------- | -------- |

| 航空公司		|    

![image (23).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250905162539_669878.png)  | 当选择航空公司类型时，下拉框选择可投放航空公司即可，点击确定即可创建成功。支持航空公司名称内搜索。| 

| 机票		|    

![image (22).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250905162546_170879.png)     | 当选择门票套餐类型时，下拉框选择可投放的航空公司+出发城市+目的地城市即可，点击确定即可创建成功。支持航空公司、出发城市、目的地城市搜索。| 



2）**创建要求**  

**不可在同一个“业务单元“下创建完全相同的航空公司/机票产品**。例如：已创建航空公司类型的“北京国航”；相同业务单元不可再创建“北京国航”，在提交时会进行报错提醒。



# 三、使用推广产品（投放管理平台）

创建3.0营销时，点击“选择产品”：   

●当只有工作台/服务商其中一个来源有资产时或者已经在工具中明确产品来源，默认展示该来源的资产。

![image (19).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250905162600_738939.png)

●如果有多个来源，且没有在工具中设置来源，则需先选择来源，选择后拉取所选择的业务单元的产品。

![image (20).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250905162609_919256.png)

●一条营销仅支持选择一个产品，点击“产品信息”可查看具体设置的关键属性。不可对同一个产品创建完全相同的多个营销。

注意：当账户切换所属的业务单元后，新建营销将只可以拉取到新归属的业务单元下的产品。历史产品（前业务单元的产品）创建的营销建议删除，如不删除，对于相同关键属性的产品，也不可再创建相同的营销。



●如需切换资产来源（如从客户工作台资产切换至服务商系统资产），可进入资产-产品库进行修改。
