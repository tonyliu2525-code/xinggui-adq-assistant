# 一、能力介绍



搜索营销商品直投主要服务于电商行业客户，在搜索直投营销上绑定商品库和商品系列，无需买词，通过简单的创意设置，即可投放商品样式营销。



# 二、使用门槛



商品直投是白名单能力，客户需要联系运营经理开白才能投放。



# 三、操作说明



商品直投仅支持搜索直投营销。



### 3.1 创建计划



推广目标支持商品推广、应用推广、销售线索收集、品牌活动推广



### 3.2 创建营销



营销形式选择搜索动态商品营销，并填写商品库和商品系列。



版位支持微信搜一搜及QQ浏览器等的移动QQ浏览器等流量场景。



其他配置项与常规搜索营销相同。



编辑营销时，不支持修改营销形式、商品库和商品系列。



![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018143845_952049.png)



### 3.3 创建关键词



不添加关键词。



### 3.4 创建创意



微信搜一搜版位：只需设置品牌形象、落地页跳转链接、创意名称。



![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018143937_958302.png)



QQ浏览器等版位：只需设置品牌形象、落地页跳转链接、商品标题和描述、附加跳转能力、创意名称。



![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018144007_468040.png)



# 四、常见问题



Q1：常规搜索营销配置商品库和商品系列，是否一定出商品样式？



A1：是的。



Q2：搜索商品快投能绑定的商品库有哪些要求？



A2：需要满足以下要求：（1）商品库类型为搜索；（2）搜索商品库创建后，需将商品库授权至具体的投放账户；（3）商品库需要审核通过。
