# 一、定位和适用场景

【运营商产品库】是为运营商行业量身打造的推广产品库，高效、准确匹配客户号卡、流量包等各类推广需求。您需根据推广诉求，正确选择库中相匹配的推广类目进行资产创建，模型会根据您创建的正确产品进行找人优化，实现精准投放。



# 二、创建推广产品（客户工作台/服务商系统）

在客户工作台或服务商系统左上角/右上角登录进已创建的“业务单元”中，**仅“业务单元”支持创建和管理“运营商产品库“的资产**。

## 1、创建入口

进入后点击资产，左侧列表展开推广产品，选择运营商产品库。

![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144632_385111.png)

## 2、创建流程和要求

1）**创建流程**  

点击新建产品，出现新建弹框。先选择类目，根据所选择的类目，将联动展示不同的关键属性，所有关键属性都是必选。以移动流量包类目为例：  

➢关键属性包含类目、通用流量、月租、定向流量、发行省份、包含会员数；  

➢支持在下拉框中搜索；  

➢产品名称：可以由客户自定义，用于区分和管理创建的产品。

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144641_757911.png)

2）**创建要求**  

不可在同一个“业务单元“下创建关键属性完全相同的产品，如有重复创建，在提交时会进行报错提醒。不同类目下产品的关键属性不同，详见页面说明。  

➢例如：已创建类目为移动彩铃，月租9-19元/月，发行省份为天津，包含1个会员的命名为“移动彩铃A套餐“的产品；相同业务单元不可再创建类目为移动彩铃，月租9-19元/月，发行省份为天津，包含1个会员但命名为“移动新客专属彩铃”的产品。如有重复创建，在提交时会进行报错提醒，如图。

![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144652_948820.png)



# 三、使用推广产品（投放管理平台）

创建3.0营销时，点击“选择产品”：  

●当只有工作台/服务商其中一个来源有资产时或者已经在工具中明确产品来源，默认展示该来源的资产。

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144703_135484.png)

●如果有多个来源，且没有在工具中设置来源，则需先选择来源，选择后拉取所选择的业务单元的产品。

![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144711_056683.png)

●一条营销仅支持选择一个产品，点击“产品信息”可查看具体设置的关键属性。不可对同一个产品创建完全相同的多个营销。  

注意：当账户切换所属的业务单元后，新建营销将只可以拉取到新归属的业务单元下的产品。历史产品（前业务单元的产品）创建的营销建议删除，如不删除，对于相同关键属性的产品，也不可再创建相同的营销。  

●如需切换资产来源（如从客户工作台资产切换至服务商系统资产），可进入资产-产品库进行修改。
