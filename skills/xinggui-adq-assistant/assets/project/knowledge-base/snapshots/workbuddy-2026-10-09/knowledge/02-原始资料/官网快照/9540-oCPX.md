# 一、能力介绍



## 1. 智能出价是什么？



智能出价为客户提供基于投放目标和出价的效果自动优化，持续提高客户的营销的效率和投入产出比。



当客户在选择特定的优化目标（例如：应用激活,下单等），提供愿意为此投放目标而支付的平均价格，并及时、准确回传效果数据，我们将借助转化预估模型，实时预估每一次请求对客户的转化价值，自动出价，最终按照点击或曝光扣费；同时，我们的转化预估模型会根据客户的营销转化数据不断自动优化。





## 2. 工作原理



营销系统实时预估每次曝光的转化概率，并根据您设置的转化出价，实时计算出每次曝光对您的转化价值；并基于转化价值，智能调控出价，竞拍每次曝光，确保最大化地实现您的转化目标。可以用以下两个公式来简单说明。



**转化价值 = 您设置的转化出价 x 曝光到转化的概率**



**营销系统的实时出价 = 转化价值 x 智能调控因子**



智能调控因子由营销的日预算消耗情况、转化成本的达成情况等因素共同决定，其存在的目标是帮助您在预算范围内获得尽可能多的转化量、同时实际转化成本尽量不超出您的预期。





## 3. 收费方式





为优化目标设定出价并不等同于按转化收费。营销系统会根据您的优化目标出价，时刻寻找最有可能完成转化的用户。最终实际转化价格将与设置的转化目标出价尽可能接近，但不会完全一致。



平台支持按照点击计费的oCPX营销（oCPC），展示计费的oCPX营销（oCPM），下载计费的oCPX营销（oCPA，仅适用于应用宝流量投放）





# 二、操作说明





## 1. 数据对接



进行智能出价（oCPX）投放的营销，需先完成转化数据的接入。



如优化流量可进行上报的行为，如点击/下载，则无需上报转化数据；



如优化平台落地页可监测的行为，如投放蹊径落地页的表单预约，枫页落地页的下单，QQ小程序的付费等，也无需再上报转化数据；



如优化平台无法监控的行为，如应用内注册/付费等行为，需客户上报转化数据方可优化。



## 2. 投放创建



在投放流程中的出价选择ocpc/ocpm，代表使用了智能出价。

# 三、优化指南

## 1. 使用规则

营销一旦创建成功，营销将无法再修改优化目标。



营销一旦创建成功，微信流量营销将无法再修改出价方式，非微信流量营销允许从非智能出价营销切换成智能出价营销，但不允许从智能出价营销切换成非智能出价营销。



可以修改每日限额，出价金额及投放人群等。



## 2. 合理出价



### 2.1. 为优化目标设置出价

首先，请计算最近3天使用相似投放方法（相似投放人群及相似素材组合）时，实际的平均转化成本（总消耗/总转化量）。



* 如果主要推广诉求是获得更多转化量，建议优化目标出价高于计算得出的平均转化成本，低于您能承受的最高成本。



* 如果主要推广诉求是稳定成本、不考虑争取更多转化量，建议以平均转化成本作为优化目标出价。



### 2.2. 调整优化目标出价

您在设置优化目标出价时，只需要填写针对该投放人群的真实成本预期，就能获得最好的投放效果，而不需要通过频繁修改出价来获益。优化目标出价修改的幅度过大，可能会引起实际转化成本骤升、曝光量骤减等不必要的损失。



## 3. 投放效果



### 3.1. 实际转化成本

实际转化成本不会和优化目标出价完全一致。营销系统总是以优化目标出价去寻找最合适的用户，但系统预估与用户的实际行为难免存在偏差。因此，就单条营销、单天的营销数据而言，实际转化成本不会和优化目标出价完全一致。



出价合理、投放策略（投放人群与素材的组合）具有竞争力的营销，随着转化数据逐步累积，多天汇总的实际转化成本会非常接近优化目标出价。



### 3.2. 实际转化成本的波动



如果单天实际转化成本高于出价的比例在20%以内，是合理的波动范围，可以放心继续投放。



如果出价不合理，实际转化成本可能与优化目标出价差距较大。营销系统会自动减少营销的曝光量，以减少不必要的损失。针对这类营销，建议调整投放策略（投放人群、素材、出价的组合），或暂停营销。



### 3.3. 影响因素



* 新上线营销



每条营销上线初期，营销成本可能会产生较大波动。如果成本和预算在可承受的风险范围，建议等待24小时后，再根据效果数据进行投放策略的调整。



* 营销变更



修改营销后，实际转化成本也会出现明显波动。如果实际转化成本和消耗情况在可承受的风险范围内，建议等待6小时以上且营销实际转化成本接近优化目标出价后，再根据数据决定是否调整或暂停投放策略。



* 竞争环境



每天的流量情况、营销竞争环境不同，因此即使对优化目标出价保持不变，营销实际转化成本仍然有可能产生波动。但长期来看，投放稳定的智能出价营销，多天汇总的实际转化成本与优化目标出价非常接近。



* 数据质量



特别注意，如果回传转化数据延迟或不稳定，将造成智能出价营销实际转化成本波动较大、营销效果严重不符合预期等问题。



## 4. 效果优化



### 4.1. 风险控制



如您对实际转化成本存在担心或疑虑，我们建议您在投放初期控制日限额，等投放稳定、实际转化成本接近出价时，再逐渐提升，以降低成本风险。特别注意，低出价不能帮助您规避成本风险，反而会导致曝光量过少。



### 4.2. 获得更多的转化量



根据您的投放经验，合理优化营销素材、提高出价，调整出价策略等会提升营销的竞争力，从而获得更多曝光量和转化量。



### 4.3. 投放人群



投放人群是投放策略最重要的因素之一，修改投放人群可能会对营销效果产生巨大影响。



因此，如果投放人群变更幅度较大（如投放人群扩大数倍、投放人群跟之前完全不相同等），建议根据风险承受能力，适当控制日预算。



对于营销实际转化成本符合预期、稳定投放的营销，如果想获得更多转化量，可以逐步扩大投放人群，但要注意控制扩大的幅度。



# 四、常见问题

**Q：为什么有些优化目标不能使用？**



A：部分优化目标灰度控制中，可联系对应运营开放白名单进行使用。



**Q：智能出价（oCPX）成本稳定，但还想获得更多转化量，怎么办？**



A：



* 放宽定向：客户对营销放宽定向，扩展更多的目标用户，如果使用人群包投放，可以使用lookalike扩展人群包



* 使用优先拿量：在出价策略中选择“优先拿量”模式，获取更多转化量。



* 逐步提高出价。
