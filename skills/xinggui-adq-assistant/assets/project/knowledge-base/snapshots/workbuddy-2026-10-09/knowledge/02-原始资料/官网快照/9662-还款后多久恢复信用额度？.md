# 腾讯营销 还款后多久恢复信用额度？

| *更新日期* | *2023-11-6* | *内容更新* |
| -------- | -------- | -------- |

## 投放端线上还款
额度即时恢复，推荐线上还款

## 线下银证转账还款
线下还款后需按照《信用金线下还款流程》发起核销流程，核销流程发起后约三个工作日内恢复信用额度

线下还款核销涉及多部门流程处理，无法加急，请预判资金使用情况做好安排，或采用线上还款方式实时恢复额度
