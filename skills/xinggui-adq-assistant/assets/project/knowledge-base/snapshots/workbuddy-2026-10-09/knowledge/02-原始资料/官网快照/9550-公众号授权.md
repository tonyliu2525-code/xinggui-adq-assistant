# 一、能力介绍

用户在使用公众号推广目标时，需先得到需要推广的公众号主的授权，允许使用相关能力内容或资产进行推广或投放。

# 二、适用范围

* 支持投放端：仅adq投放端

* 支持跨主体商业模式：同集团公司 （需提供股权关系证明）

* 客户主体和公众号主体行业不一致，不支持跨主体投放 

# 三、操作指引

## 1. 使用入口

1.1. 在【工具】—【微信生态授权管理】—【公众号授权】中发起授权







## 2. 发起授权

2.1. 输入要投放的公众号开发者ID（AppID），点击校验并勾选协议后发起授权。



a. 同主体授权：授权的公众号与投放营销的客户账户属于同一主体时可直接授权。



b. 跨主体授权：如果授权的公众号与投放营销的客户账户不属于同一主体：

* 若为同主体子客场景：则需要公众号管理员扫码完成授权

* 若为跨主体直客/子客场景：

* 则需在“发起授权”后，按对应操作提交相关证明材料。

* 在公众号管理员扫码确认授权且相关资质材料广审通过后才可以绑定成功





## 3. 取消授权

3.1. 对于公众号主，可在腾讯营销助手小程序端管理对应的授权关系，点击“已授权”的绑定关系，可以操作取消授权，取消授权，存量营销会同步做下线处理



3.2. 对于客户，可直接在投放端-工具箱或营销创建流程中取消公众号授权

# 四、能力说明

* 一个客户账号暂时只支持绑定一个公众号，一个公众号可授权至多个客户账号

* 授权时间：客户可以自定义授权的时间，最短1天，最长永久，公众号管理员可以修改对应授权时间
