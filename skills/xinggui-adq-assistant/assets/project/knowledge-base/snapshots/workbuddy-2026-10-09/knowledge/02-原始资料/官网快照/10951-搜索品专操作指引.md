# 一、能力介绍



搜索品专支持投放搜一搜超级品牌专区、QQ浏览器移动和PC超级品牌专区和品牌专区，售卖方式为CPT，保价保量。



# 二、解决哪些问题



开阔的展示区域凸显官方品质，全方位塑造品牌形象；提供丰富的私域组件，便捷满足用户多元需求。帮助品牌实现品牌塑造及私域转化等营销诉求。



# 三、操作说明



### 3.1 投放入口



点击【品牌推广】——>【搜索营销】进入推广管理页面，点击【新建营销】进入投放主流程



![1.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018164607_145400.png)



### 3.2 投放主流程



**3.2.1 创建计划**



选择营销版位、合约类型。



微信搜一搜版位支持超级品牌专区，浏览器（移动）和浏览器（PC）支持超级品牌专区、品牌专区。



![2.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165221_491137.png)



**3.2.2 创建营销**



配置投放时长、上线时间、地域定向、添加关键词并提交审核。



![3.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165517_352283.png)



![4.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165530_507529.png)



关键词审核通过后可查询报价，报价有效期21天，超过有效期需重新查询报价



![5.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165553_428034.png)



查询报价后可锁定排期



![6.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165615_992024.png)



锁定排期后可点击【下一步】创建创意



![7.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165637_728712.png)



**3.2.3 创建创意**



1个营销下最多支持10个创意，须将关键词分配到创意，保证关键词在所有创意上不重不漏。



![8.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165717_872393.png)



创意内容支持设置顶部运营位（素材、跳转、直播等）官方信息、官方账号、热门活动、相关视频等



![9.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165758_271202.png)



![10.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165815_900560.png)



![11.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20241018165828_452931.png)



页面右侧可查看创意预览。



# 四、常见问题



Q1：为什么提交关键词后很长时间没有出询价结果？



A1：提交关键词后需要先进行关键词审核，审核通过后才能查询报价。
