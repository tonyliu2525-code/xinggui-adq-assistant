# 账单负数条目
| *更新日期* | *2023-12-5* | *内容更新* |
| -------- | -------- | -------- |

## 负数条目来源

当合约项目已记账后进行实结或改单，基于财务会计准则，前序结算周期内已录账目不会进行变更。当结算金额减少时，会在实结当月记录负数条目以负数条目补齐投放项目的总金额

## 负数条目结款

负数条目无法进行线上自助还款，请按[《线下付款核销》](https://support.e.qq.com/detail?cid=4073&pid=9718)流程中的合约核销流程进行负数条目勾兑

## 负数条目说明

* 实结和改单都以实际操作日期记账
* 若负数条目对应的原项目应收已全额付款，负数可勾兑至贵司其他合约排期以抵充应收
* 负数勾兑以实际申请时间做为还款时间，若需用于抵充待还款项目，请及时发起
