# 一、功能介绍

定向包分析包含受众分析和人群包分析两个维度的报表，供客户查看定向包相关的效果数据，并根据数据调整和优化相关定向，提升投放效果。

![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240724162933_487665.png)

# 二、受众分析

受众分析是营销领域中的一个关键环节，它涉及对潜在或现有顾客群体的深入了解和研究。这种分析能够帮助客户识别和理解您营销的目标受众，以便更有效地定位产品、制定营销策略和营销创意。我们的受众分析报表主要聚焦于人口统计特征，包括地域、年龄、性别分布等基本属性。

| 维度 | 时间维度 | 数据计算key |

| -------- | -------- | -------- |

| 地域     |支持分日分析，天更新 | 省份/城市  |

| 年龄   | 支持分日分析，天更新  | 年龄段 |

| 性别   | 支持分日分析，天更新  | 男/女     |

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240724163309_635347.png)

在图表信息右上角， 您可以切换当前分析的主要指标，支持按照曝光量、点击量、目标转化量、目标转化率四个指标进行数据分析。 默认选择曝光量。

## 2.1 地理位置分布

![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240724163733_343462.png)

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240724163743_025853.png)

![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240724163752_191257.png)

●报表中心为您提供了两种直观的方式来展示营销效果的地理位置分布：图片形式和表格形式。这些展示方式不仅增强了数据的可读性，也使您能够更快捷地获取关键信息。



○图片形式的展示特别采用了地理位置热力图，这是一种颜色编码的地图，可以在全国乃至全球范围内直观地展示您的曝光量。热力图上，颜色的深浅代表了不同地区曝光量的多少，让您能够一眼看出哪些地区是投放的热点区域。当您将鼠标停留在地图上相应的省份或地区时，系统会自动突出显示该区域，并弹出一个信息框，展示该地区的详细曝光量数据，包括但不限于曝光量、转化率等关键指标。这种交互式的设计使您能够即时获取特定地区的营销效果分析。



○热力图还支持用户交互功能，您可以通过拖动地图来查看不同地区的数据，或者使用放大工具来聚焦于某个特定区域，以便更细致地查看内容效果的地理分布情况。



○表格形式的展示则提供了一个结构化的视图，列出了各个省份或地区的营销效果数据。如果您偏好数字和统计数据，您可以从表格中快速扫描和比较不同地区的性能。



●数据计算的最细颗粒度为城市，您可以在界面上或者右上角点击下载，查看全部的数据信息。当所需要下载的报表数据量级较大（超过500条）时，您的下载将转移至离线下载中心，您可以在离线中心统一管理下载文件进度，请注意离线下载中心仅保留近7天的数据。



●点击自定列，可以切换您需要查看的指标。

## 2.2 年龄和性别分布

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240724163913_296834.png)

●报表中心支持以图片形式和表格形式为您呈现营销效果的年龄和性别分布。鼠标停留可以查看到详细数据。



●年龄分布支持的年龄段，和定向选择的年龄段一致：18岁及以下，19到24岁，25到29岁，30到39岁，40到49岁，50岁及以上，共计六个年龄段。



●性别分布支持按照男/女进行分析。



●请注意，由于用户隐私设置等可能造成营销采集的信息缺失，因此在地理位置/年龄/性别等分布上均可能出现“未知”， 这不影响您分析已知的数据，但是如果想要看总计的数据，建议以账户或者营销维度的结算数据为准。

## 2.3 功能筛选

![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240724164131_191469.png)

受众分析当前仅支持筛选营销信息。如果您从推广列表中，单条点击进入数据分析侧拉窗口，则在该页面中会为您默认进行营销筛选。

# 三、定向包分析

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240724164218_988533.png)

如果您在投放的时候设置了不同的人群包，您可以在人群包报表内，按照账户/营销/营销创意维度进行人群包的分析，当前支持筛选人群包ID。



●时间选择及时间维度：目前定向包报表单次查询跨度不超过一年。跨长时间周期数据的查询可能影响您的查询性能。



●指标口径切换：目前支持营销播放、数据上报、激活时间三个口径展示报表数据，不同的报表口径会将营销带来的转化数据统计到不同的发生时点，关于口径的详细介绍请查看文档“报表口径”



●数据趋势：默认为折叠状态，您可以点击“展开趋势图”获取完整的趋势图信息。您可以点击“自定义展示指标”定义趋势图中需要呈现的数据指标，最多支持6个指标进行对比，点击确定后关闭指标筛选器。在趋势图卡片内，您可以点击对应的指标名称，决定是否将该指标展示在趋势图内。目前暂不支持自定义图形类型。



●数据下载：点击下载报表可进行数据下载，当所需要下载的报表数据量级较大（超过500条）时，您的下载将转移至离线下载中心，您可以在离线中心统一管理下载文件进度，请注意离线下载中心仅保留近7天的数据。

# 四、常见问题

Q :受众分析出现“未知”数据？



A :由于用户隐私设置等可能造成营销采集的信息缺失，如由于ip等原因没归到具体地域，或者微信场景关闭了个性化营销推荐。因此在地理位置/年龄/性别等分布上均可能出现“未知”， 这不影响您分析已知的数据，但是如果想要看总计的数据，建议以账户或者营销维度的结算数据为准。



Q：如果出现了定向外的曝光数据？



A：营销在正常情况下会按照您所设置的定向进行精准投放，但是如果在报表内查看到了异常数据，不是报表进行的数据突破，是直接出现了定向外的异常展示，请联系腾讯营销进行排查。
