# 平台店铺库

## 一、定位和适用场景

●【**平台店铺库**】适用于在腾讯营销推广开在**非腾讯的其他第三方电商平台上的品牌自有店铺**，如XX品牌的天猫旗舰店、XX品牌的京东旗舰店等；  

● 创建资产时，须正确选择和填写店铺链接、所在平台，模型会根据您创建的正确信息作为输入用于投放和优化；



## 二、创建推广产品（客户工作台/服务商系统）

在客户工作台或服务商系统左上角/右上角登录进已创建的“业务单元”中，仅“业务单元”支持创建和管理“平台店铺库”的资产。



### 1、创建入口

进入后点击资产，左侧列表展开推广产品，选择平台店铺库。

![image (9).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144238_195231.png)

### 2、创建流程和要求

1）**创建流程**  

点击新建产品，出现新建弹框，填写资产关键属性和附属属性  

➢关键属性：所有活动的关键属性为店铺主页类型+店铺主页地址。  

➢店铺名称：可以由客户自定义，用于区分和管理创建的店铺。  

![image (10).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144302_652773.png)

2）**创建要求**  

不可在同一个“业务单元”下创建店铺主页类型和店铺主页链接完全相同的平台店铺，如有重复创建，在提交时会进行报错提醒。详见页面说明。  

➢如新产品与库中已有平台店铺的店铺主页类型和店铺主页链接完全相同，则无论二者店铺名称是否相同，在提交时都会进行报错提醒  

➢每个业务单元下最多可以创建1500个平台，如果库中平台店铺超过了1500个但仍需创建新店铺，则需要手动删除库中的旧店铺。



## 三、使用推广产品（投放管理平台）

创建营销时，点击“选择产品”：  

●当只有工作台/服务商其中一个来源有资产时或者已经在工具中明确产品来源，默认展示该来源的资产。

![image (11).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144315_309393.png)

●如果有多个来源，且没有在工具中设置来源，则需先选择来源，选择后拉取所选择的业务单元的产品。

![image (12).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144329_762484.png)

●一条营销仅支持选择一个产品，点击“产品信息”可查看具体设置的关键属性。不可对同一个产品创建完全相同的多个营销。

注意：当账户切换所属的业务单元后，新建营销将只可以拉取到新归属的业务单元下的产品。历史产品（前业务单元的产品）创建的营销建议删除，如不删除，对于相同关键属性的产品，也不可再创建相同的营销。  

●如需切换资产来源（如从客户工作台资产切换至服务商系统资产），可进入资产-产品库进行修改。

![image (13).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144345_367498.png)

# 微信小程序库

## 一、定位和适用场景

若考核自建小程序内所有商品的页面访问量、下单量、成交GMV等业务场景，则选择【微信小程序】推广产品，注意填写正确的小程序原始ID以及相关信息；



## 二、微信小程序产品备案（客户工作台）

在客户工作台或服务商系统左上角登录进已创建的“主体”中，仅“主体”支持“微信小程序”资产的备案管理。



### 1、资产备案入口

进入后点击上方的“管理”tab，点击左侧“备案管理”，进入微信小程序的备案页面。

![image (14).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144404_833408.png)

1）**微信小程序产品备案**  

a)备案流程：  

点击新建备案，出现新建弹框。先填写小程序原始ID，再输入小程序昵称，然后输入小程序主体名称，最后上传资质证明图（股权证明/授权书）。  

➢以上均为必填  

➢一般24小时内审核完成

![image (15).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144418_417418.png)

b)备案状态：  

查看微信小程序的备案状态，“备案成功”后即可进入投放端选择并使用小程序。  

➢如提示备案失败，请点击“详情”查看备案失败原因进行修改并“重新新建备案”。  

![image (16).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144430_766702.png)



## 三、使用微信小程序产品（投放管理平台）

创建营销时，根据投放诉求选择推广产品为“微信小程序”，输入已备案成功的小程序ID，即可按照需求投放小程序。

![image (17).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144443_611593.png)

# APP应用（Android应用/iOS应用）

## 一、定位和适用场景

若考核APP内所有商品的页面访问量、下单量、成交GMV等，则使用【Android应用】或【iOS应用】推广产品库，注意填写正确的APPID。



## 二、获取APP ID

● **Android应用 APP ID获取**	  

➢如果在在“应用宝”上传应用，通过后即可获取APP ID  

➢如果在腾讯营销的应用推广管理工具上传应用，具体操作如下：  

1）进入[腾讯营销 - 资产 - 资产页](https://ad.qq.com/atlas/60682988/assets/index) ，点击上方“资产”tab，选择“应用管理”

![image (18).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144502_400536.png)

2）点击“添加安卓应用”

![image (19).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144512_622897.png)

3）按照要求依次填写应用的基本信息，如应用名称、行业类型等，审核通过后即可生成对应的APP ID。

![image (20).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144525_263104.png)



● **iOS应用 APP ID获取**  

iOS应用开发者即可获取已上架的iOS应用的APP ID。



## 三、使用APP应用产品（投放管理平台）

●创建营销时，根据投放诉求选择推广产品为“Android应用”，填写Android应用的APP ID，系统会自动识别应用相关信息，即可按照需求投放非游戏Android应用。

![image (21).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144540_390915.png)





●创建3营销时，根据投放诉求选择推广产品为“iOS应用”，填写已上架的iOS应用的APP ID，系统会自动识别应用相关信息，即可按照需求投放非游戏iOS应用。

![image (23).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250814144549_794103.png)
