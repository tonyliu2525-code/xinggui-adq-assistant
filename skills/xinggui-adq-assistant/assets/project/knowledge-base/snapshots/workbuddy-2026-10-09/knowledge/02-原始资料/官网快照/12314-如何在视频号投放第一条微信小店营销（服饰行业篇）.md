# 二、创建营销



|**步骤板块**    |    **流程 和 选项**    |	**图例**   |

| -------- | -------- | -------- |

| 1. 新建营销    | 登录【[腾讯营销投放管理平台](https://ad.qq.com/)】 -> 竞价推广 -> 新建营销     |

![2.1.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182056_626144.png)   |

| 2. 营销内容    | 1.营销目的 -- 选择【商品销售】
2.推广产品 -- 选择【微信小店商品】
●选择商品
a.微信小店 -- 点击搜索框 -- 下拉菜单中选择目标小店 *确保小店已授权
b.选择商品 -- 勾选想推广的商品 *确保商品已上架
3.营销载体 -- 选择【页面跳转】
4.优化目标 -- 选择【下单】     |

![2.2.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182113_915898.png)  

![2.2.2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182124_396480.png)![2.2.3.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182135_553987.png)![2.2.4.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182146_811292.png) |

| 3. 营销版位    | 版位选择 -- 选择【选择特定版位】 -- 选择【微信视频号】（*更多版位详情见：[帮助中心](https://support.e.qq.com/detail?cid=4552&pid=10144)）     |

![2.3.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182222_290799.png)     |	

| 4. 定向&出价与预算     | 1.【定向】建议全部不限制  （*如何理解定向见[帮助中心](https://support.e.qq.com/detail?cid=4596&pid=2612)）
2.出价 -- （”元/下单“指愿意为获得用户的一次下单所花费的营销成本。例子：愿意为获得用户的一次下单花费55元，即填写出价为55元。）     |

![2.4.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182232_563095.png)

![2.4.2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182241_751397.png)   |

| 5. 提交    | 点击【提交并创建创意】    |

![2.5.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182250_841587.png)    |







# 三、创建创意 



|**步骤板块**    |    **流程 和 选项**    |	**图例**   |

| -------- | -------- | -------- |

| 1. 图片/视频     | 1.点击/拖拽可从本地上传营销视频素材
*视频格式要求：MP4/MOV/AVI，大小 ≤ 500M，5s ≤ 时长 ≤ 300s     |![3.1.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182336_271452.png)  

![3.1.2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182410_205876.png)  |

| 2. 文案    | 1.点击【输入框】添加营销文案
2.点击【新建文案】可以增加文案条数量（一个创意最多匹配三条文案）    |![3.2.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182358_867701.png)     |

| 3. 落地页     | 1.选择【微信小店商品页】
2.点击下方【+】加号 ->【新建微信小店商品页】 -> 系统会自动匹配生成对应的小店id和商品id（*确保小店已关联，商品在二、2已选择）-> 点击【确定】
3.勾选刚添加的小店商品页选项     | 

![3.3.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182438_514976.png)

![3.3.2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182447_541423.png)

![3.3.3.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182457_095764.png)       |

| 4. 品牌形象     | 1.选择【视频号】
2.勾选对应视频号形象（*确保视频号已关联）     |

![3.4.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182507_486788.png)   |

| 5. 营销组件     | 1.营销组件 -- 确保打开【浮层卡片】
2.浮层卡片 -- 点击【+】加号添加浮层卡片
3.新建浮层卡片
a.点击从本地上传浮层卡片的图片
*图片格式要求：800px x 800px，.jpg/.jpeg/.png/.bmp，大小＜400KB
b.输入【文案标题】和【文案描述】
c.点击【选择按钮文案】出现下拉菜单选项，选择【了解更多】
d.点击下方蓝色【确定】创建浮层卡片
4.浮层卡片 -- 勾选一个浮层卡片作为使用    |

![3.5.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182520_480210.png)![3.5.2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182524_163553.png)![3.5.3.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182529_242580.png)![3.5.4.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182533_951646.png)![3.5.5.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182538_150987.png)                 |

| 6. 创意设置     | 填写自定义【创意名称】     |

![3.6.1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250612182554_950041.png)   |

| 7. 提交创意    | 左下角点击【提交创意】    |
