# 一、功能介绍



## 1. 功能说明





客户可以对新营销分配一笔起量预算，系统在6小时内快速花完预算，激进探索，帮助营销快速获取转化量，或快速判断营销失败





## 2. 适用场景





新投放初期，无法快速获取曝光量和转化量，从而：营销无法起量，客户也无法快速判断营销未来是否能够起量，从而难以做出投放决策。





因此，需要在新营销初期，加速营销拿量进度，实现：营销快速起量从而存活，或，系统快速判断营销效果较差可以关停，避免预算浪费。





具体场景包括：





a.  商品大促/新游大推场景，从新营销快速起量的角度，帮助客户整体快速花费预算，获取转化量





b.  常规投放场景：



✓ 客户希望营销快速起量，或希望快速获取效果反馈





✓ 预算充分，且对新投放前期成本波动容忍度较高





✓ 数据回流快





# 二、使用指引





## 1. 适用营销





* oCPM/oCPC营销





## 2. 使用方法





* 新建/编辑营销时，可以开启一键起量功能，并设定起量预算

* 起量预算：结合账户内营销起量速度和自身预期来进行设置，如无明确预期，可设置为出价/深度出价的10倍。

* 一键起量支持全流量通投

![1.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250520195706_530400.png)



* 一条营销可使用多次一键起量（仅限3月10日后新建的营销），操作方式如下：

* 投放流程：当该营销的一键起量完成或中止时，可以点击蓝色的“再次开启”功能。点击后，请设置新一轮一键起量的起量预算，并保存营销设置。系统将开始新一轮起量。

![2.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250520195758_020435.png)





* 批量操作：当多个营销的一键起量完成或中止时，可以对多个营销进行勾选，批量操作工具内选择“更多>一键起量”：



![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2023/211_20231012154635_462753.png)





第一步：针对勾选的营销，先关闭开关，点击确定



![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2023/211_20231012154718_109621.png)



第二步：针对勾选的营销，再开启开关，设置新的一轮起量预算，点击确定，即可基于新的起量预算，开始一次新的起量周期（一定要在第一步关闭+确定后，再进行第二步，才能开启新一轮一键起量）

![3.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250520195847_710368.png)





## 3. 投放建议





### 3.1. 功能使用时机：





✓ 如您账户内数据量较充分，且转化数据回流快，则可在新建营销时即开启一键起量；



✓ 如您账户内数据量较少，且转化数据回流慢，可以尝试当营销积累若干（3-5个）转化量后，如起量速度不满意，再开启一键起量（以上两种方法可同时使用，进行测试）；





### 3.2. 起量预算设置：





✓ **结合账户内营销情况和自身预期来设定**，如：账户内头部营销在6小时内可花费1000元，您希望可以提升到1200元，则可将起量预算设置为1200元；



✓ 使用初期，可以**阶梯化设置**起量预算，进行效果测试；





✓  一键起量预算请勿设置过低，否则系统没有充分的探索空间，还可能会导致一键起量消耗超过预算；建议将起量预算设置为出价/深度出价的3倍-30倍之间（如您出价较低，如2元/激活，则可适当提高倍数，但建议不要超过20000元），如无明确预期，一般建议设置为**深度出价的10倍左右**



✓  	一键起量的消耗可能存在部分大于预算的情况





### 3.3.  **定向：请勿设置较窄**，否则系统缺乏探索空间，激进探索后会出现不起量/成本偏高的问题





### 3.4. 流量：建议使用全流量通投，扩大系统的探索空间





### 3.5. 当转化数据回流较慢时，系统在6小时内进行成本控制的难度较大，不适合作为一键起量的观察对象；极端举例如：次留第二天才能回流，则一键起量期请观察激活成本。





## 4. 效果预期





* 功能开启后的6小时内：花完起量预算，帮助营销获取转化量，但由于系统激进探索，期间转化成本会偏高

* 如在探索过程中，系统判断营销效果过差（竞争力本身过差/成本偏差过大），则会停止探索，防止预算浪费。

* 当预算花完，起量完成，营销恢复正常投放，系统会使用起量期间积累的转化数据来帮助营销平稳成本，继续获量





## 5. 成本保障政策





* 一键起量期间的消耗不计入赔付金额计算，产生的转化量也不计入赔付门槛。

举例：一键起量期间产生了500消耗和2转化，非一键起量期间产生了1000消耗和4个转化。计算是否应该赔付时，由于非一键起量的转化量4小于6个门槛，所以这个营销不符合赔付要求，不予赔付。

* 一键起量消耗可能存在大于一键起量预算的情况。





# 三、常见问题





**1. 起量预算一定会在6小时内花完吗？**



不一定：①营销探索过程中成本过高，系统会判定为学习失败，并停止探索；②如营销自身竞争力较差，也可能无法花完预算





**2. 起量期间是否转化成本一定会偏高？**



大概率偏高，因系统会进行激进探索，来加速新营销的冷启动进程，从而导致成本偏高





**3. 因营销暂停投放/预算花完等原因导致起量中止后，如果再次开启营销，系统还会继续探索吗？**



不会





**4. 营销结束起量期后，是否量级会大幅下降？**





营销结束起量期时，系统会将出价平滑恢复至正常水平，同时，营销获取的转化量逐渐下降，成本也逐渐回落，直至完全恢复正常投放；正常投放时的量级还是需要依赖营销自身竞争力，因此是有可能出现较大的下降的。
