# 一、线索管理平台介绍

线索管理平台是腾讯营销的后链路管理工具，目标是帮助客户更高效精细的管理线索，充分发挥线索价值，指导优化投放，提升ROI

# 二、产品优势
* 提升线索响应时效，加快线索流转
* 利用线索管理平台的能力，可以使线索近实时的归属给专属客服，提升客服响应速度，加快线索转换，提升线索转化回流速度，进而提升营销深层优化目标投放效果。

* 提升线索外呼接通率，提升线索价值
* 线索通免费稳定的外呼能力，多种外呼方式和智能分配策略可以提升线索外呼接通率，使得线索可以被跟进，降低有意向线索成本。

* 支持多种线索标记方式，反哺投放
* 支持不同行业的定制化线索状态，按照线索状态、评分、标签等字段进行标记，同时支持API方式回传线索后效，多维方式闭环投放数据，提升投放效果。

# 三、使用门槛

# 四、操作说明
1. 绑定主、子账号可以轻松在一个账户下管理多个投放账户的线索，可以统一设置分配规则，管理客服，转发线索，回传线索后效。

2. 支持客户根据不同场景进行线索自动分配规则配置，可基于员工、团队维度支持按照线索量、线索未跟进量补齐的方式进行线索分配，提高线索分配效率。

3. 针对管理员和客服人员通过微信模板消息和短信方式分别进行线索通知提醒，提高线索跟进及时性。

4. 提供数据看板，支持以管理视角查看线索分配、跟进情况。

5. 线索管理平台外呼使用智能的中间号分配策略，提升本地号码/手机号码分配率，提升外呼接通率。

详见文档：[https://doc.weixin.qq.com/doc/w3_AKcAswb5AFMwupFaUAeSBWZD4gRj2?scode=AJEAIQdfAAoaT6oVoXAKcAswb5AFM](http://)

6. 支持在管理平台PC端和小程序端进行线索标记，对于未接通状态的线索经过验证和符合赔付规则时，会给予无效赔付。家居、房产、医药行业除通用线索状态外，还有定制的行业化线索状态，更贴近行业实际业务场景；管理员可以一键切换，客服打标流程与通用线索状态一致。

7. 提供网页咨询页和微信客服原生咨询页咨询组件，满足咨询链路使用在线沟通的方式获取用户线索。咨询组件支持数十家第三方IM厂商，支持用户开口和留资的行为转化数据上报。用户留资后，可直接在线索管理平台查看和管理。

8. 支持将线索拉取或推送到客户自有CRM进行管理。
