# 1.产品功能介绍
投放端-「创意资产管理」中「删除」功能新增「删除策略」选择，支持同时删除使用该图片/视频拼接的多图、橱窗组件，同时对使用该图片/视频的创意进行解绑。

应用场景：需要下线图片/视频，并不再进行播放，可同时勾选所有删除策略。

**● 功能入口**

仅支持投放端-合并后的「创意资产管理」，点击「删除」后，会出现以下弹框选择对应的「删除策略」。（业务单元维度的创意资产管理仅支持删除资产，未支持此次功能）
![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121012_068809.png)
![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121018_062370.png)

**● 功能效果**

| **选项**	| **操作要求**	| **选择后操作效果**|
| -------- | -------- | -------- |
| 同时删除使用该图片的多图、橱窗图片、橱窗视频	| 1）删除单图/单视频时默认会出现该选项；（即使没有被用于多图等组件也会默认展示）
2）删除多图/橱窗图片/橱窗视频不会出现该选项| 1）单图和使用该单图的**多图&橱窗组件均会一起删除**
2）视频和使用该视频的**橱窗视频组件均会一起删除**|
| 同时与创意解绑，从创意中移除并不再播放该图片/视频| 	当该创意资产有关联非删除创意时（包括暂停的创意），可勾选该选项；反之该选项置灰不可选。	| 1）会将单图和使用该单图的多图&橱窗组件和**当前账户下**已关联的创意解绑，解绑后将不再播放该图片（其他未解绑的创意资产仍可正常播放）
2）会将视频和使用该视频的橱窗组件和**当前账户下**已关联的创意解绑，解绑后将不再播放该视频
**特别注意：如果单图/视频授权给了其他账户且被使用，会由于无权限跨账户操作而无法对其他账户的创意进行解绑，所以其他账户如有使用该单图/视频仍会正常播放，但不可再新增创意使用已删除的图片/视频进行投放**|
| 若解绑创意导致创意不完整，则同时删除创意| 	必须勾选“同时与创意解绑，从创意中移除并不再播放该图片/视频”，才可勾选该选项。	| 当解绑时创意上只关联了即将删除的图片/视频，会因为是唯一的主视觉而解绑失败；此时会将该创意直接删除，删除后该图片/视频不再播放。|

# 2.功能使用说明
**步骤 1 **选择需删除的图片或视频，可批量选择图片或视频（仅支持操作自有资产，被授权和业务单元资产均没有删除的操作权限）
![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121219_100502.png)

**步骤 2** 选择相关删除策略，可在下方“已关联创意”中查看删除的创意资产关联了哪些创意（包含智投手动创意）；策略勾选后对应的操作效果见“1.产品功能介绍的功能效果”。默认勾选，可自行根据诉求取消勾选。
![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121223_941233.png)

如图片/视频有被使用在全库智选创意中，可额外在“全库智选创意”下展开查看：
![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121228_561409.png)

**步骤 3** 点击确定后，会发起离线任务进行删除操作；
![image (5).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121233_553007.png)

**步骤 4** 可前往任务中心查看任务运行情况
![image (6).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121238_692534.png)

任务列表可查看当时选择的具体删除策略，点击“下载执行详情”可查看具体执行结果：
![image (7).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121243_991004.png)

执行结果以表格形式呈现，展示具体账户下删除的组件ID，解绑/删除的创意ID，执行结果，失败原因等
![image (8).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260331121248_045619.png)
