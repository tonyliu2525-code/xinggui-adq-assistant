# 1. 能力介绍

是腾讯营销提供的，面向客户组织/人/资产/资金的 一站式经营管理平台。

# 2. 产品目标

真实还原组织的管理模式，提升人户/资产/资金的管理效率，规避套户等风险

# 3. 适用角色

管理多账户/多团队/多资产的客户管理者、优化师、数据分析师、财务人员等

# 4. 核心能力

多账户管理：跨账户经营、多维度数据分析，助力客户加速决策部署；



组织人员管理：分角色授权，组织划分清晰，让管理和协作更敏捷；



资产管理：明确赛道圈子，资产自动共享，让投放更高效；



资金管理：建立客户钱包，资金自动共享，提升资金利用率。
