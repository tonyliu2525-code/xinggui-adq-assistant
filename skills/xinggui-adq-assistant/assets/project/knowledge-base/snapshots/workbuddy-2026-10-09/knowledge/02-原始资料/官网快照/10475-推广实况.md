# 一、能力介绍



推广实况模拟用户在特定版位、流量场景和地域搜索特定关键词时的推广效果。



# 二、解决哪些问题



搜索营销在不同地域的推广效果动态变化；搜索营销主跨地域投放，需要了解在特定地域的自身营销和竞对的营销排名等情况，便于及时进行价格、创意等的优化。推广实况通过模拟用户在特定版位、流量场景和地域搜索特定关键词时的推广效果，满足客户上述需求。



# 三、使用门槛



仅适用于搜索直投营销【QQ浏览器等】版位。



# 四、操作说明



## 4.1 工具箱入口



**4.1.1 入口**



工具——>效果分析——>推广实况









**4.1.2 操作**



【实况查询】中输入关键词，选择地域、版位、流量场景，点击【查询】。



每次支持查询1个关键词，地域、版位、流量场景单选。









## 4.2 推广列表入口



**4.2.1 入口**



推广——>搜索营销——>关键词列表——>操作列【实况】









**4.2.2 操作**



选择地域、版位、流量场景，即可查看所选关键词的模拟搜索结果。









# 五、常见问题



**Q：推广实况搜索结果的营销为什么和线上实际结果不一致？**



A：原因主要有两个——1、推广实况仅使用地域、版位定向，突破其他定向，对搜索结果进行模拟；2、搜索营销组件化投放，引擎根据用户综合信息进行组件优选并拼接成最终创意，推广实况的用户信息和线上用户信息不同，导致创意样式有差异。
