# 一、基础功能介绍

组件、背景图、喝彩图标无需在投放流程进行配置。直播间内跳转能力现有三个可配置项：跳转组件、喝彩图标、背景图。



客户可提前配置跳转组件，审核侧预审通过后可以待使用，允许配置多个。

# 二、使用门槛

**注：营销组件特指营销提供特有的跳转营销推广页的能力；微信平台本身提供的购物车橱窗、打赏入口、链接推送能力等均不属于营销组件；**



* 目前营销组件仅可跳转原生页；

* 

* 特别注意：



*    **电商相关行业暂不支持开通**：当前直播电商仅支持使用微信平台官方提供的能力进行商品售卖（购物车等），不支持使用营销组件进行商品售卖（详见下方「电商带货」介绍）；



*    **游戏行业暂不支持开通**：游戏相关的组件需统一走微信平台官方提供的组件能力（含小游戏，游戏下载）；



* 能力需开通白名单，具体可与腾讯营销行业/渠道运营经理沟通申请；

# 三、产品能力说明

1. 能力入口：【工具】—【直播间配置管理】





2. 新建组件：营销组件新建后，需审核通过后才能上架，建议客户提前新建营销组件。

3. 组件上下架说明

* 组件上架：可新建多个营销组件，同一场直播只能上架一个



○**竞价**：直播营销在投状态下可在工具箱中配置上架



○**合约**：直播营销在投或合约投放投放开始时间前24h可配置上架



* 直播间推送：营销组件需在上架状态下，主播才可在主播端进行推送，推送后直播间的用户可立即看到



○**跳转组件**：开播过程中可上下架



○**喝彩图&背景图**：直播间开播前，可手动选择上线，直播过程中不能修改或者下线	



* 组件下架：直播下播时或营销下线时，营销组件自动会下线；下一场直播要使用时，需重新上架并推送；

4. 彩排模式：

合约可在合约投放投放时间开始前24h，用测试模式/彩排模式等进行试播，上架&推送组件
