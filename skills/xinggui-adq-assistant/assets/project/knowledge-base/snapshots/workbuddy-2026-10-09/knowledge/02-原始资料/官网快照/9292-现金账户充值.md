# 腾讯营销 现金账户充值

| *更新日期* | *2025-12-26* | *流程更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您需要 对现金账户进行充值，请通过以下方式发起：

## 在线充值
* 登录投放管理平台 → 顶端“财务”标签 → 二级导航栏“财务信息” → 进入资金总览板块。

* 点击“在线充值”按钮，弹窗输入充值金额。

* 可以选择“微信支付”进行订单支付，打开手机微信扫一扫支付二维码完成支付。

* 可以选择“网银支付”进行订单支付，选择银行类型和付款银行，将跳转至网银进行支付。

* 通过“微信支付”或“网银支付”完成支付后，对支付结果进行确认后，款项实时到账。

## 在线充值的补充说明：更多银行
* 若原有11家企业网银无法满足您的在线支付需求，可以通过「更多银行」的能力，实现其他全量企业网银完成在线订单支付。
* 在“网银支付”界面，选中“更多银行”进行订单支付

* 检查充值金额，并选择“新版网银支付”

* 首次使用时需微信扫码登录进行身份验证，注意：仅为保障交易安全性，并不会使用微信付款

* 微信扫码验证成功后，界面中会出现腾讯专用收款账户信息，企业财务根据收款单信息，完成订单资金的转入。
* 基于收款主体，以下图为例，会生成唯一的收款账号，用户根据以下要素复制粘贴，完成对公打款。
* 特别注意：在使用新版网银首次支付时，务必填写WQ开头的转账附言，否则会被自动退回
* 务必使用指定的付款户名进行转账，随意使用其他户名转账，资金会被退回

* 打开企业网银后台，在转账/汇款模块内粘贴或填写收款信息，并完成转账

* 转账成功后，支付页面显示付款成功

* 回到营销充值页面，点击已成功支付

* 订单有效期为6天，请在下单的6天内完成付款。
* 到账时间说明，使用新版网银，请合理安排打款时间，大于100万的交易请留意以下时段
* 在使用期间，会在支付页面判断当前时间段并对您进行相应提示

## 转账汇款
* 登录投放管理平台 → 顶端“财务”标签 → 二级导航栏“财务信息” → 进入资金总览板块。

* 点击“转账汇款”按钮，弹窗指引支付流程。
* 先录入付款方银行信息，务必与付款银行的开户名称保持一致。
* 再使用录入的付款方账户汇款至显示的收款方账户，此收款方账户为随机生成的账号，以辨识账户与充值关系。
* 转账汇款由于涉及人工处理流程，将于一个工作日充值到现金账户中。

## 无法充值的问题排查
在特定规则的场景下，账户无法充值的，若充值按钮灰度显示，鼠标移至按钮悬停后会提示限制规则，请按指引解除限制，即可充值。

| 限制规则 | 限制说明 | 解除方式 |
|-|-|-|-|-|-|
|账户状态|仅有效状态的账户允许充值或转入|提交账户资质，审核通过后解除|
|账户类型|仅直客账户、服务商账户可充值，子客账户需服务商进行资金划转|登录直客账户进行充值投放、或联系服务商进行资金划转|
|登录人权限|仅直客账户的超级管理员、管理员、财务人员允许充值|在投放端右上角查看当前角色，若不符请联系相关人员进行充值|
|对公验证状态|对公验证完成后才能够充值|在投放端-账户中心-对公打款验证页面按提示要求完成对公验证|
|保证金缴纳状态|部分行业要求缴纳保证金才可以进行充值|如判定需要缴纳保下金，投放端消息中心会有相应提示，按流程操作缴纳完成即可|
|出海账户类型|特殊类型的账户仅允许线下充值，不允许线上自助充值|请查阅本板块内线下充值流程进行线下充值|
