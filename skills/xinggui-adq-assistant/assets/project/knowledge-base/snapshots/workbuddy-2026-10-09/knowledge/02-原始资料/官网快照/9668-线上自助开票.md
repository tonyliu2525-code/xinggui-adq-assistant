| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您需要	开具发票	，请通过以下方式发起：

# 线上自助开票

*
## 功能入口

**客户**	登录腾讯营销投放管理平台 → 顶端“财务”标签 → 二级导航栏“发票管理” → 进入发票管理板块

**服务商** 登录腾讯营销服务商系统 → 顶端“财务”标签 → 二级导航栏“发票管理” → 进入发票管理板块

*注：以上平台，仅限账户超级管理员、管理员和财务人员，可进入发票管理板块查询和提交开票*

*
## 操作指引
### 发起申请
点击“发票开具”按钮后，进入发票申请页面

* ## 功能入口

客户：登录腾讯营销投放管理平台 → 顶端"财务"标签 → 二级导航栏"发票管理"

服务商：登录腾讯营销服务商系统 → 顶端"财务"标签 → 二级导航栏"发票管理"

注：仅限账户超级管理员、管理员和财务人员可进入发票管理板块。

* ## 操作流程

**第1步：进入申请开票入口**

在发票管理板块首页，可查看各账户的开票状态（可开票金额、已开票金额等），点击"申请开票"按钮发起开票。

**第2步：填写开票信息**

| **开票项** | **更新后选项/规则** |
| - | - |
| 发票抬头 | 开票主体即账户开户主体，无法修改（遵守"交易一致性"原则） |
| 开票方式 | 默认开具电子发票（纸质发票因辖区税局税控管理已无法开具） |
| 开票口径 | 按消耗金额开票 |
| 开票类型 | 现金开票 / 信用金开票 |
| 发票类型 | 增值税专票（默认）/ 增值税普票 |
| 发票项目 | “生产生活服务 * 信息技术服务费” / “生产生活服务 * 广告发布费”或“生产生活服务 * 广告费” |
| 消耗类型区分 | 系统将根据竞价/合约/互选消耗类型自动匹配发票类目比例 |

注：竞价消耗提示——发票信息填写页面顶部会显示红色通知"竞价广告开票类型变更为：信息系统服务91.5%，广告发布费8.5%"，请注意查看。

**第3步：确认发票类目**

提交开票申请后，系统将按消耗类型自动拆分发票类目：

* 竞价消耗发票：一张发票内包含两个类目行（“生产生活服务 * 信息技术服务费” + “生产生活服务 * 广告发布费”或“生产生活服务 * 广告费”）
* 合约消耗发票：一张发票包含一个类目行（“生产生活服务 * 广告发布费”或“生产生活服务 * 广告费”）
* 互选消耗发票：一张发票包含一个类目行（“生产生活服务 * 信息技术服务费”）

**第4步：填写纳税人信息**

纳税人信息必须与税务登记、企业开户许可证保持一致。请务必在开票申请提交前复核完整纳税人信息，避免开票失败或开具发票无法使用。

注：数电发票购买方信息栏仅展示公司名称和税号，如需展示企业注册地址电话、开户行及账号等信息，请在对应选项中勾选。

**第5步：查看开票结果**

提交开票申请后，可在发票管理板块首页查看申请记录。开票完成后，点击"电子发票"可预览或下载PDF、XML和OFD格式的发票文件，核实发票类目是否按新规则开具。

## 注意事项
* 因数据限制，2024年1月1日前的充值和消耗，无法使用自助开票功能，请[线下邮件申请发票](https://support.e.qq.com/detail?cid=4075&pid=2069)
* 请及时申请发票，若因发票未开具无法付款造成的逾期，同样适用相关扣罚规则
* 若申请人发起申请后未在处理时效内收到反馈，或对反馈结果有异议的，请主动[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)了解具体情况
* 以上仅针对营销充值和投放的发票开具，保证金开票请前往保证金管理平台提交[保证金发票申请](https://support.e.qq.com/detail?cid=4091&pid=10295)
