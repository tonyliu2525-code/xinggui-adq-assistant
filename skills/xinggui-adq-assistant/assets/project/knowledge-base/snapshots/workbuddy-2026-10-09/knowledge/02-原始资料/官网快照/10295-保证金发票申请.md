# 腾讯营销 保证金发票申请

| *更新日期* | *更新日期 2024-4-12* | *流程更新* |
| -------- | -------- | -------- |

全国各省级税务机关陆续发布《关于开展全面数字化的电子发票试点工作的公告》，全国各地已经开始试点并持续加大全面数字化的电子发票（以下简称“数电票”）的推广使用力度，腾讯营销的各签约主体公司均列入试点单位，于2024年3月起全面切换数电票。保证金扣罚产生的发票，需以电子发票的方式提供，请按以下方式申请发票：

## 保证金扣罚开发票
*注：仅针对已扣罚的保证金可支持开发票*

1）登录保证金管理平台进入保证金财务记录模块，勾选可申请的开票记录选择“申请开票”

2）填写开票信息，并提交申请

3）二次提醒客户开票后无法申诉，确定后进行开具发票

4）开票单状态变为待处理，等待平台开具发票

5）过程中可以支持撤销开票申请
