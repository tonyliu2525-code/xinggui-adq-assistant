# 腾讯营销 服务商注册入库和信息更新

| *更新日期* | *2025-4-27* | *内容发布* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您在返点结算过程中需新增或更新服务商入库信息，请通过以下方式发起：

# 新增入库

请联系您的渠道经理，向您发起注册邀请

您在收到邀请邮件后，按邮件指引提交注册信息，在完成审核后即注册成功

注册信息将用于返点结算的支付信息获取

# 入库信息更新

若服务商发生 工商变更、新增或变更银行信息、营业执照过期 等情况，请通过邮件方式发起入库信息更新

*
## 邮件详情
收件人：AMS_JS@tencent.com

抄送人：*[ 您的渠道经理 ]*

*
## 邮件主题
【腾讯营销】服务商入库信息更新 - *[ 主体名称 ]*

*
## 邮件正文

因XXXX原因，需对服务商入库信息进行更新。

原信息：

需更新为：

同时附上申请材料见邮件附件

*
## 邮件附件
* 工商信息变更：提供工商变更证明及新营业执照
* 银行账号新增或变更：提供 开户许可证 或 可以体现主体与账号关系的证明（例如付款底单、银行业务回执等）
* 营业执照过期：提供新营业执照

# 注意事项
* 服务商新增入库，请与您的渠道经理确认处理时效；服务商入库信息更新，将于收到申请邮件并提供完整的申请信息和附件后一周内处理完毕
* 若申请人发起申请后未在处理时效内收到反馈，或对反馈结果有异议的，请主动联系结算专员了解具体情况。[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)
