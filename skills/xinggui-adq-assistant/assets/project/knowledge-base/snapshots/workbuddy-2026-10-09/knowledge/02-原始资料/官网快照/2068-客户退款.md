# 腾讯营销 客户退款

| *更新日期* | *2024-11-27* | *流程更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您需要 对客户现金账户余额申请退款，请通过以下方式发起：

# 线上自助退款

登录投放管理平台 → 顶端“财务”标签 → 二级导航栏“退款管理” → 进入退款板块。

注意事项
* 支持线上自助退款的账户包括：ADQ客户账户、MP客户账户
* 申请退款板块仅限账户超级管理员、管理员、财务人员可以有相关权限，其他账户身份无此权限
* 原路退回仅支持商户号原路退回，即通过微信支付、财付通和微企付进行的支付，通过银行转账的支付（包括固定识别码）仅支持银证转账退款
* 由于各银行限制不同，充值超过一定限期（175天至360天）可能无法原路退回，具体以线上可选项为准。超过360天仅支持银证转账退款
* 线上自助退款的申请，在材料全部齐全后，原路退回约1个工作日到账，银证转账约7个工作日到账

# 线下邮件申请
请优先从线上进行退款申请，若线上退款无法提交，请通过邮件进行线下退款申请

# 子客账户退款
由服务商管理的客户，由于您的交易对象为服务商，如有退款需求请联系您的服务商进行直接沟通

# 注意事项

基于[交易合规要求](https://support.e.qq.com/detail?cid=4066&pid=9784)中交易过程需遵守资金流一致的原则，退款同样需要遵守一致性原则
* 公司与企业：仅支持退款至与客户账户的主体名称一致的银行账户中
* 个体工商户：支持退款至与客户账户的主体名称一致的银行账户中，或法人的个人账户中
* 个人：仅支持退款至与客户账户的主体名称一致的个人银行账户中

若所退款项已涉及开票，退款前请先进行退票流程，待退票完成后才可发起退款
* [电子发票退票申请](https://support.e.qq.com/detail?cid=4076&pid=10341)
* [纸质发票退票申请](https://support.e.qq.com/detail?cid=4076&pid=9742)

关于退款的处理时效
* 退款的线上发起，在材料全部齐全后，原路退回约1个工作日到账，银证转账约7个工作日到账
* 退款的邮件发起，在材料全部齐全后，原路退回约10个工作日到账，银证转账约25个工作日到账
* 若申请人发起申请后未在处理时效内收到反馈，或对反馈结果有异议的，请主动联系结算专员了解具体情况。[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)

如果您的申请退款主体已注销，需额外提供以下材料
