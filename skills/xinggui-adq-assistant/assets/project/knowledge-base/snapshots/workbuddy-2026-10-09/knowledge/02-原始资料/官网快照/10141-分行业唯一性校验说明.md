# 一、什么是3.0营销唯一性？

## 1、3.0营销唯一性的定义

新投放（3.0）从底层逻辑上对营销系统进行全面升级，从赋予营销唯一的专属身份、减少同质化营销数量等方面提升系统算力，让系统更懂营销诉求，大幅提升拿量稳定性。新投放（3.0）的核心在于围绕“新营销ID”进行了全面升级，让每个营销拥有一张专属“身份证”。  

“3.0新营销”的唯一性的计算维度包括表达「营销内容」的“营销目的、推广产品、营销载体和优化目标”，这些维度是所有行业都会进行唯一性计算的维度，同时基于不同行业的经营诉求，对于后效有差异化出价测试的营销设置（版位和定向）也会进行唯一性计算，账户下唯一性校验一致的营销，只能创建一条。

## 2、营销唯一性现状及升级规划

在营销唯一性原则下，多数客户都通过“新营销ID”来表达合理的投放诉求，但仍有少数客户或优化师在激烈的市场竞争压力中，源于对效果的追求和对未知风险的谨慎，存在对“堆基建”策略的路径依赖，期望通过微调定向细节来试图提升投放效果。然而，从推进的结果看，只是与系统在做无效博弈，既难以复制，更无法获得确定性收益。冗余的营销基建会干扰模型运作，稀释投放效能，使得增长转型的第一步变得艰难。  

因此，为营造更加健康的投放生态，提升平台效率与系统稳定性，腾讯营销投放平台拟针对“营销唯一性”做一系列的产品升级；

# 二、营销唯一性判定标准

## （一）3.0营销唯一性判定原则

系统根据单账户下营销的“营销内容+营销设置”来判定是否满足“营销唯一性”，其中，营销内容模块的“营销目的、推广产品、营销载体、优化目标”为全行业参与唯一性校验的维度，营销内容不同的营销必然通过唯一性校验。账户下同营销内容的营销需进一步结合“营销设置”进行判定，基于不同行业的经营诉求存在差异，参与唯一性校验的营销设置也存在差异，您只需关注自身开户行业参与唯一性校验的营销设置即可，具体可通过[【3.0营销唯一性计算维度说明】](https://doc.weixin.qq.com/sheet/e3_ABgAxgYPACoCNIQ0iEx1PSgWeIaRn?scode=AJEAIQdfAAoU26ysmEABgAxgYPACo&tab=BB08J2 )进行查询。

# 三、3.0营销唯一性判定标准升级规范

## （一）各维度管控规则升级

### 1、单账户维度：

3.0普通单账户下，所有行业上限可建5000条营销；  

针对开启“智能投放”的账户下，所有行业上限可建5000条营销或项目；



### 2、单账户同“营销内容”维度：

3.0普通单账户“同营销内容”下，所有行业上限可建100条营销；  

针对开启“智能投放”的账户下，所有行业上限可建100条营销和100条项目；



### 3、单账户同“营销内容”下仅“单一定向不同”维度：

3.0普通单账户以及开启“智能投放”的账户下“同营销内容仅单一定向”不同时，可创建营销/项目上限受“定向设置”影响存在差异，针对“定向设置”差异可建营销数上限详见下表：

### 4、单账户同“营销内容”下禁止创建人群高度相似营销/项目：

在“单账户同营销内容”下，针对「营销版位、版位定投场景、出价类型、计费方式、投放素材标签」维度，只需选择不同选项则可通过营销唯一性校验。  

**但针对“定向参数（地域、年龄、性别、学历、婚恋育儿状态、操作系统版本、设备品牌型号）”** 的调整需特别注意：即使定向参数不完全相同，系统仍会根据“定向人群重复度”来进行唯一性判定，**如两条营销/项目定向人群高度相似，则只允许创建成功1条**，建议您在定向设置中尽量避免维度交叉重叠，确保各营销/项目人群相对独立，合理表达您的营销诉求。

# 四、高频问题&解答

**Q1：系统会针对老营销会重新计算唯一性吗？**  

A1：不会重新计算唯一性，平台会保证已有营销持续在线投放。但是，如果修改老营销，则可能触发唯一性校验。

![image (10).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250812160503_794568.png)



**Q2：老营销修改哪些选项不会重新校验唯一性，哪些选项会重新校验？**  

A2：只有客户修改版位、定向时，才会重新计算唯一性。其他选项不会触发唯一性校验，详见下表。（注意：对于修改不校验的维度，如果是在投放端进行修改，需要从营销管理列表中进行修改，如果从编辑营销内进行修改会重新校验）



| 模块	| 可修改的选项	| 修改后是否重新校验| 

| -------- | -------- | -------- |

| 出价与预算	| 出价	| 不校验| 

| 出价与预算	| 营销日预算		| 不校验	| 

| 出价与预算	| 一键起量		| 不校验	| 

| 出价与预算	| 一键起量加强		| 不校验	| 

| 营销设置	| 投放日期		| 不校验（若计费方式为“CPS”，重新校验）	| 

| 营销设置	| 	投放时间		| 不校验	| 

| 营销设置	| 	营销名称		| 不校验	| 



**Q3：希望新建营销，已经修改了部分定向设置，但报错【当前营销的设置内容高度相似，无法创建，请修改定向设置或 前往查看已有营销（xxx），返回码：1901634】**  

A3：收到这个报错提醒说明您的投放账户内新建的营销与历史营销的定向高度相似，所以无法新建营销，对此有两种解决方案：  

解决方案一：您可以编辑已有营销（xxx）的校验维度，表达营销新诉求。  

解决方案二：您可登陆 【投放端-账户中心】，查询账户所属的开户行业，再参照[【3.0营销唯一性计算维度说明】](https://doc.weixin.qq.com/sheet/e3_ABgAxgYPACoCNIQ0iEx1PSgWeIaRn?scode=AJEAIQdfAAoU26ysmEABgAxgYPACo&tab=BB08J2) ，查询您所在开户行业参与唯一性判定的定向设置维度，自查与已有营销（xxx）在这些定向设置维度的差异，在新建营销中重新调整这些维度的参数，尽量避免维度设置的参数交叉重复。
