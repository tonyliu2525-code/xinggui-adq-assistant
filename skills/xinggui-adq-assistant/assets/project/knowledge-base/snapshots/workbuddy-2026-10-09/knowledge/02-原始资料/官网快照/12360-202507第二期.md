# 【规则新增】染发产品 “护发功效” 审核执行

1）染发产品涉及护发功效，需同时满足下列两点：


（1）提供护发功效相关质检报告


（2）素材内清晰标注质检报告来源（如 “数据源自 XX 检测机构报告”）



# 【规则新增】教育-军队文职培训禁投

1）禁止推广军队文职培训相关内容



# 【规则放宽】金融--房产二抵贷款准入审核要求

1）可支持房产二次抵押贷款业务，但需满足以下要求


（1）不支持夸大房产二抵业务适用范围，包括但不限于"不管是否有纠纷均可办理“、”所有房产均可办理"、"无剩余价值也可贷款"等


（2）不支持出现任何关于贷款审批或放款的绝对性保证表述，包括但不限于"无条件通过"、"100%放款"等


注：若涉及其他违规场景，需同时满足抵押贷款及通用规则执行



# 【规则放宽】危害身体健康的饮酒、吸烟行为细则

1）酒水营销不支持涉及在主驾驶位宣传产品，包括主驾驶位真人推广、产品摆放在主驾驶位附近等


2）酒水营销可支持将酒水摆放在后备箱或其他无法判定在主驾驶位的场景



# 【规则调整】元素重复拼接审核规则

1）图片素材，不支持使用2个或2个以上重复元素拼接设计样式


2）“多图”营销位，不支持使用所有图片完全一致的素材


3）视频营销，不支持全屏使用重复元素拼接设计

# 【规则新增】金融-境外银行准入审核规则

支持准入持有国内金融牌照的境外银行主体，允许投放内容：


1）推广品宣推广


2）推广该银行的境内业务（如人民币存款、贷款、支付结算等）；


3）禁止涉及任何境外业务，包括但不限于：境外货币存款（美元/港币等）、跨境理财产品、海外保险/证券投资服务、离岸账户开立等
