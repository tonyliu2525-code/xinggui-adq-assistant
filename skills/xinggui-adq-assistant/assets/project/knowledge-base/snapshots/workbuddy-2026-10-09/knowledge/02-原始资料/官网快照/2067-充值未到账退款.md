# 腾讯营销 充值未到账退款

| *更新日期* | *2025-1-23* | *流程发布* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

若您 因支付信息错误、多打款等原因，需要对线下转账至腾讯营销对公账户还未进行充值到投放账户的资金进行退款，请通过以下方式发起：

## 邮件附件
* 付款凭证（转账汇款银行底单等）
* 《腾讯营销退款申请表》扫描件，模板见本文末尾
* 《营业执照副本》扫描件
* 被委托人身份证正反面扫描件

# 注意事项
* 基于[交易合规要求](https://support.e.qq.com/detail?cid=4066&pid=9784)中交易过程需遵守资金流一致的原则，退款同样需要遵守一致性原则，仅支持退款至付款凭证上的付款方信息进行原路退回
* 每笔退款只支持一次提交一笔未充值资金流水退款，如有多笔需充值未到账资金退款，请分别邮件发起
* 若申请人发起申请后未在处理时效内收到反馈，或对反馈结果有异议的，请主动[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)了解具体情况
