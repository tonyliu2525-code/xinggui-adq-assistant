《保证金退款场景所需材料及要求》
## 一、收款账户类型：企业
| **场景** | **需提交材料** |**签章要求** |
| -------- | -------- | -------- |
| 客户主体对公账户| ①客户主体营业执照 ② 收款银行账户开户证明③【保证金结算确认函】④涉及工商变更的，补充工商变更证明     |主体存续企业 / 个体户：加盖公章；无公章个体户：经营者签字按手印 +经营者手持身份证原件照片  |
| 代缴公司对公账户|①双方营业执照②【保证金结算确认函】③【保证金代缴协议】、【委托代收保证金退款说明】、付款凭证④收款银行账户开户证明⑤涉及工商变更的，补充工商变更证明 |主体存续企业 / 个体户：加盖公章；无公章个体户：经营者签字按手印 +经营者手持身份证原件照片|
| 其他第三方对公账户（主体注销）|①主体注销证明②注销前股权关系证明③收款方营业执照④收款银行账户开户证明⑤【保证金结算确认函】⑥【企业注销保证金退款说明】⑦涉及工商变更的，补充工商变更证明| 主体已注销无法加盖公章：原法人/经营者签字按手印 +法人/经营者手持身份证原件照片|
