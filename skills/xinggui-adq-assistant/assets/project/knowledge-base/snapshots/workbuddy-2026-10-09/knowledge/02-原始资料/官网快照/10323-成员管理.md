# 1、成员定义

组织下的真实成员，包含4类角色:

|职务 | 权限 |
| -------- | -------- |
| 主管理员     | **·** 企业主要管理者，对该组织下账户拥有查阅数据、操作账户投放等所有最高权限，可新建业务单元
**·** 该角色多为企业法人、营销负责人等     |
| 管理员     | **·** 除无法增加其他成员的管理员权限外，其他权限与主管理员一致
**·** 该角色多为投放组长、区域负责人等     |
| 协作者     | **·** 被主管理员邀请一起管理账户的企业成员，仅能拥有主管理员分配的权限范围，可共享组织资产
**·** 主管理员可以根据协作者的角色分配账户及权限 （如：给财务同学分配转账权限）
**·** 该角色多为优化师、运营人员、数据分析师、设计师、财务专员     |
| 未认证员工     | **·** 未通过组织认证的客户管家员工，仅能查看/管理自己名下的账户，无法成为业务单元的管理员     |

# 2、成员管理

## 2.1.添加成员

### 2.1.1.邀请成员加入

如果需要在组织内添加对应的成员，可以在管理-成员管理-添加，将对应的二维码发给对应的成员进行身份验证

![2.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/211_20240426104231_345505.png)

![3.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/211_20240426104241_500573.png)

### 2.1.2.成员申请审批

**注意：仅组织的主管理员&管理员才可以查看此页面**

完成身份验证的用户，管理员可在此进行审批

![4.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/211_20240426104344_109113.png)

## 2.2.编辑成员

### 2.2.1.编辑角色为管理员

**注意：管理员会拥有组织下全部账户的管理权限，请谨慎操作**

![5.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/211_20240426104433_151352.png)

### 2.2.2.编辑角色为协作者

**注意：除了协作者的角色，还有一些特殊的权限可以给协作者配置**

转账权限：可在组织内进行转账操作

商品库管理权限：可管对应的商品库

保证金管理权限：可使用保证金模块功能

业务单元管理员：可在此组织下创建业务单元

![6.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/211_20240426104517_500844.png)

## 2.3.删除成员

注意：成员删除后再无权限查看此组织数据，请谨慎操作
