# 一、定位和适用场景

【综合家政产品库】是为本地生活行业的综合家政赛道量身打造的推广产品库，适用于投放推广家政服务（如家庭清洁、保姆护理）、维修服务、二手回收服务等的业务场景。您可根据实际推广诉求，灵活选用库中和自身生意模式相匹配的资产类型，实现精准投放。



# 二、创建推广产品（客户工作台/服务商系统）

在客户工作台或服务商系统左上角/右上角登录进已创建的“业务单元”中，**仅“业务单元”支持创建和管理“综合家政产品“的资产**。

## 1、创建入口

进入后点击资产，左侧列表展开推广产品，选择综合家政产品库。

![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144325_698606.png)

## 2、创建流程和要求

1）**创建流程**  

点击新建产品，出现新建弹框。先选择类目，根据所选择的类目，将联动展示不同的关键属性，所有关键属性都是必选。以综合家政服务/家庭保洁/日常保洁类目为例：  

➢关键属性包含类目、品牌、价格区间  

➢产品名称：可以由客户自定义，用于区分和管理创建的产品。

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144335_372606.png)

2）**创建要求**  

不可在同一个“业务单元“下创建关键属性完全相同的产品，如有重复创建，在提交时会进行报错提醒。不同类目下产品的关键属性不同，详见页面说明。  

➢如新产品与库中已有产品的关键属性完全相同，则无论二者产品名称是否相同，在提交时都会进行报错提醒，如图。

![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144346_541310.png)



# 三、使用推广产品（投放管理平台）

创建3.0营销时，点击“选择产品”：  

●当只有工作台/服务商其中一个来源有资产时或者已经在工具中明确产品来源，默认展示该来源的资产。

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144355_096645.png)

●如果有多个来源，且没有在工具中设置来源，则需先选择来源，选择后拉取所选择的业务单元的产品。

![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250909144405_944870.png)

●一条营销仅支持选择一个产品，点击“产品信息”可查看具体设置的关键属性。不可对同一个产品创建完全相同的多个营销。  

注意：当账户切换所属的业务单元后，新建营销将只可以拉取到新归属的业务单元下的产品。历史产品（前业务单元的产品）创建的营销建议删除，如不删除，对于相同关键属性的产品，也不可再创建相同的营销。  

●如需切换资产来源（如从客户工作台资产切换至服务商系统资产），可进入资产-产品库进行修改。
