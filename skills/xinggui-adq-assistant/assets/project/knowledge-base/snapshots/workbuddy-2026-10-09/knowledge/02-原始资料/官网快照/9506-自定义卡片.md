账户概览页的所有卡片均可进行设置，并且支持自定义拖拽位置和大小（拖拽卡片边缘，或右下角进行放大和缩小）



# 一、卡片设置

点击首页右上角的“卡片设置”，可以打开设置窗口，选择首页展示哪些类别的卡片。





# 二、核心数据

默认展示4项汇总数据，用户也可以点击卡片右侧的设置按钮，修改要展示的指标项，支持设置的指标项包括：

今日花费（元）、当前余额（元）、曝光量、点击量、点击率、目标转化量、目标转化率、目标转化成本（元）、深度转化量、深度转化率、深度转化成本（元）、有消耗的账户、我管理的账户。



# 三、 账户列表卡片

展示多营销账号基本信息和基础报表数据，包括您所管理的所有ADQ账户和投放平台账户



# 四、智能投手卡片

展示当前用户所管理账号的托管状态



# 五、每日TOP账户

展示用户当前管理的所有账户根据某一项指标进行TOP排行，客户可通过卡片左侧的设置按钮，设置想查看排行的指标和TOP账户数。





# 六、快捷入口

默认4项快捷入口，用户也可以通过卡片右侧的设置自定义添加其他URL或删除。





# 七、趋势图

账户趋势图：用户指定2个账户和1个指标进行对比，最长可选择区间为2周。



指标趋势图：用户所有ADQ或投放平台账户、指定2个指标进行对比，最长可选择区间为2周。
