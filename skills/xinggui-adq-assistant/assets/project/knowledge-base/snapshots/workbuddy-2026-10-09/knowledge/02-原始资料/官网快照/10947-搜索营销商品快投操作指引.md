# 一、能力介绍



搜索营销商品快投主要服务于电商行业客户，在常规搜索营销上绑定搜索类型商品库和商品系列，客户不需要单独设置商品样式，由引擎优选样式，展示商品营销样式。



# 二、使用门槛



商品快投是白名单能力，客户需要联系运营经理开白才能投放。



# 三、操作说明



商品快投仅支持搜索直投营销。



### 3.1 创建计划



推广目标支持商品推广、应用推广、销售线索收集、品牌活动推广



### 3.2 创建营销



营销形式选择常规搜索营销，并填写商品库和商品系列。



版位支持微信搜一搜及QQ浏览器等的移动QQ浏览器等流量场景。



其他配置项与常规搜索营销相同。

### 3.3 创建关键词



需要添加关键词。



### 3.4 创建创意



创意与常规搜索营销的配置项相同。



# 四、常见问题



Q1：常规搜索营销配置商品库和商品系列，是否一定出商品样式？



A1：常规搜索营销配置商品库和商品系列后，样式由引擎优选，可能出商品样式或非商品样式。



Q2：搜索商品快投能绑定的商品库有哪些要求？



A2：需要满足以下要求：（1）商品库类型为搜索；（2）搜索商品库创建后，需将商品库授权至具体的投放账户；（3）商品库需要审核通过。
