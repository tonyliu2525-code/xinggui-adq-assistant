# 一、能力介绍



针对搜索直投营销需要从账户维度进行开启/关闭等管理操作的能力，使用搜索营销配置管理工具进行统一管理。当前包括衍生管理和同屏展示管理。



# 二、解决哪些问题



● 衍生管理：为提升营销的物料丰富度和点击率，系统支持根据关键词、搜索词、创意等物料生成更多组件，包括子链、图片；衍生管理支持客户开启/关闭该能力。



● 同屏展示：同一账户内的营销在同一屏搜索结果页中最多展示一个，同屏展示支持展示同一账户内多个营销。



# 三、使用门槛



衍生管理和同屏展示适用于搜索直投营销，同屏展示仅对搜索直投营销的【QQ浏览器等】版位生效。



# 四、操作说明



## 4.1 入口



工具——>投放管理——>搜索营销配置管理















## 4.2 衍生管理



包括自动衍生素材和自动衍生子链。



自动衍生素材：默认开启，支持关闭，目前仅对【QQ浏览器等】版位生效；当该选项与投放主流程中的自动衍生素材选项同时打开时，营销的自动衍生素材能力才生效；



自动衍生子链：默认开启，支持关闭，开启后对搜索直投营销生效；















## 4.3 同屏管理



默认开启，支持关闭，开启后，在同一屏搜索结果页中可展示账户维度下的多条搜索营销。 仅对搜索直投营销【QQ浏览器等】版位的营销生效。
