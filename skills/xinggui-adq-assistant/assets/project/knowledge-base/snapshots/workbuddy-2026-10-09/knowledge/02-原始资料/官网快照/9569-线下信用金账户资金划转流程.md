# 处理流程
1. 申请人发起邮件申请信用金账户资金划转
2. 腾讯营销业务侧复核投放需求和划转需求并邮件回复划转意见
3. 结算专员内部系统提交划转申请
4. 内部流程审核后资金划转到账

# 注意事项
* 请优先使用线上自助划转功能进行划转，请参照帮助中心内[《自助信用金账户资金划转流程》](https://support.e.qq.com/detail?cid=4071&pid=9568)
* 请于“腾讯营销服务商系统”通过绑定同一集团下不同主体（已签署账期协议或担保函提供互相担保）或者同一主体下不同账号，实现ADQ和ADQ之间信用金跨主体自助互转，ADQ-MP之间同主体自助互转，总授信额度不变
* 竞价滚动信用额度和合约滚动信用额度不能互转
* 资金账户的账期不一致不能互转
* 转移时需转出账户信用金余额大于转出额度
* 若申请人发起申请后未在处理时效内收到反馈，或对反馈结果有异议的，请主动[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)了解具体情况
