# 说明





| 场景| 优先级 |

| -------- | -------- | -------- |

| 营销类型：搜索营销 出价方式：oCPM、oCPC     | 按照设置的营销出价进行竞价，不支持对关键词进行出价    |

| 营销类型：搜索营销 出价方式：CPC     | 设置关键词出价优先使用关键词出价进行竞价，没有设置关键词出价的默认使用营销出价进行竞价 |
