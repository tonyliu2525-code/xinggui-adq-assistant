# 1.产品功能介绍
投放端-「创意资产管理」中新增「添加警示语」功能

●功能效果
○使用添加警示语功能，有助于提高审核通过率，但会增加上传的等待时间
○警示语内容根据账户所属行业自动配置，部分行业有多条警示语可自行选择，不可自定义编辑文本内容
○警示语添加效果**不能确保 100% 符合预期**，需在投放前自行确认效果，再使用该图片/视频进行投放

# 2.功能使用说明（版本1）
●功能入口：
○投放管理平台「资产」-「创意素材管理」
○客户工作台「资产」-「创意资产」-「创意素材」
○服务商系统「投放」-「创意资产管理」

●功能说明：
1.在上传新图片/视频时开启功能，警示语添加完成后的图片/视频将上传保存，原始图片/视频不会上传；已入库且未添加警示语的图片/视频使用添加警示语功能，不会影响原始图片/视频。
2.此功能有助于提高审核通过率，但会增加上传的等待时间
3.请确认警示语添加效果后，再使用该图片/视频进行投放
4.可用组件范围：自建组件（不包括授权获得的组件）

# 5.Q&A
1.添加的警示语效果一定可用吗
——测试可用率已达到可用标准，但不是 100% 都可用，有可能会出现警示语颜色与图片/视频背景色区分度不高、遮挡其他关键元素的情况，需要在投放营销前自行确认效果；不满意效果的可以在管理列表中删除该图片/视频

2、是否所有图片/视频都支持添加警示语——仅自建组件
