# 一、 账户来源

账户列表所展示的账户来源包括：



通过商务管家设置的操作者或观察者。



通过服务商系统设置的自理投放管理员。



通过直客投放端-协作者管理设置的管理员、操作者、观察者等。

# 二、账户筛选与排序

登陆工作台后，账户列表默认展示您所管理的所有腾讯营销平台账户，所有的报表指标项均支持排序，同时您也可以通过筛选项对所管理的账户进行筛选，筛选项包括：



按账户名称或ID：账户名称支持模糊匹配查询，账户ID支持完整匹配查询，您可以通过空格或逗号分隔来查询多个搜索条件



按照新老营销：可筛选对应账户的 新旧营销的各类投放数据



按所属服务商：支持按账户所属服务商的名称或ID进行筛选



按所属新管家：支持按账户所属新管家的名称或ID进行筛选



按账户类型：支持按直客或子客进行筛选（直客为客户自主注册的投放账户，子客为服务商开通的投放账户）



按备注：支持按设置的备注名称进行搜索



按标签：支持按设置的标签名称进行搜索



展示昨日同比：勾选后将展示各项报表指标与前一天数据的对比



过滤无数据：勾选后将过滤所有无数据的投放账户

# 三、账户操作

在账户列表中，您可以对投放账户进行一些基本操作，包括：



跳转到投放平台



将账户置顶或取消置顶



设置备注（备注仅针对自己生效，其他管理该账户的用户不可见）



开启或关闭一键托管功能



进入智能投手的自定义托管页面



进入该账户的账户中心
