# 腾讯营销 开具发票的种类

| *更新日期* | *2024-12-5* | *内容更新* |
| -------- | -------- | -------- |

尊敬的合作伙伴，您好

腾讯广告开具的发票为增值税发票，基于不同资质的客户有不同的要求：

* 有一般纳税人资质的客户可以申请开具增值税专用发票
* 小规模纳税人资质的客户请申请开增值税普通发票
* 境外的客户请申请开增值税普通发票
