# 功能介绍

| 优化目标 | 含义 |
| -------- | -------- |
| 关注     | 关注是指潜在用户成功关注 客户推广的公众号或视频号，以获取产品或服务的最新信息和优惠等。计算方法和口径：点击后1日内关注人数    |
| 公众号内注册     | 用户在公众号内部留下手机号、微信号等个人信息，以便进一步联系计算方法和口径：点击后7日内公众号注册次数     |

| 次日留存     | 次日留存是指新用户在首次使用产品或服务后，在接下来的第二天仍然继续使用的情况。次留需客户上报数据，务必进行数据上报对接。计算方法和口径：激活/注册/浏览关键页/启动后第2日的启动app行为     |
| 24小时变现ROI     | 计算指标，用于优化激活/注册/浏览关键页后24小时内的营销变现ROI 。app 类需要同时回传变现成本和变现金额，小游戏和短剧数据由平台监测和计算。     |
| 营销变现     | 营销变现指 将腾讯流量导流到客户平台，在客户平台进行营销变现的行为。计算方法和口径：激活/注册/浏览关键页后24小时内的营销变现行为     |
| 24小时下单     | 点击营销后的24小时内完成购买或订购产品和服务的行为计算方法和口径：点击后24小时内下单人数     |
| 七日变现ROI     | 计算指标，用于优化优化激活/注册/浏览关键页后7日内的营销变现ROI 。     |
| 付费     | 潜在客户在使用或了解投放内容后，确实对所推广的产品或服务产生兴趣，7日内完成购买、订阅或购买虚拟物品等实际支付行为。计算方法和口径：激活/注册/浏览关键页/启动后7日内的付费行为     |
| 七日内每次留存成本     | 七日内每次留存成本是指 “激活 t+7日内每次留存的成本” ，适合有长留需求的客户使用。计算方法和口径：激活后（不含激活日）7日内的每次留存行为     |
| 关键行为     | 特指7日首次营销变现行为计算方法和口径：点击后7日内的首次营销变现行为     |
| 电话拨打     | 电话拨打是指潜在客户在查看内容后，拨打营销中提供的联系电话与企业、销售或客服人员沟通。如使用蹊径/微信原生落地页，并使用电话组建，则电话拨打可由平台监测，无需上报数据。如使用自定义落地页，需客户上报数据。计算方法和口径：点击后1日内电话拨打人数     |
| 跳转按钮点击     | 跳转按钮点击是指潜在客户在查看内容后，点击营销中或落地页中的跳转按钮（例如“立即购买”、“了解更多”或“免费试用”等），进入指定网页获取详细信息的行为计算方法和口径：点击后1日内点击跳转按钮人数     |
| 友赞     | 友赞是指用户在查看内容、社交媒体帖子或内容后，表达赞同或喜欢的行为计算方法和口径：点击后1日内点赞人数    |
| 直播观看一分钟     | 用户进入直播间观看直播一分钟以上计算方法和口径：点击后1日内观看直播1分钟以上人数    |
| 互动问答     | 用户在落地页留下手机号等个人信息后，会看到一个或多个互动问题，问题内容一般可以帮助判断用户意愿，用户勾选任意答案完成互动均会上报计算方法和口径：点击后3日内完成互动问答人数     |
| 关注后发消息     | 关注后发消息是指潜在客户在关注品牌、企业或网站的公众号）、订阅号或社交媒体帐号后，主动向该帐号发送消息以获取更多信息或进行互动计算方法和口径：点击后7日内关注后并发消息人数    |
