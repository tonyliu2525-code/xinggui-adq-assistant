# 一、定位和适用场景

【Android应用】和【iOS应用】是各行业相对通用的推广产品库，主要适用于考核整个APP应用场内的用户增长/商品销售的场景。您可根据实际推广诉求，判断Android应用/iOS应用资产是否和自身生意模式相匹配，从而正确选择实现精准投放。



# 二、获取APP ID

●**Android应用 APP ID获取**	  

➢如果在在“应用宝”上传应用，通过后即可获取APP ID  

➢如果在腾讯营销的应用推广管理工具上传应用，具体操作如下：  

1）进入[腾讯营销 - 投放管理平台](https://ad.qq.com/atlas/60682988/assets/index) ，点击上方“资产”tab，选择“应用管理”

![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829160652_899609.png)

2）点击“添加安卓应用”

![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829160700_745873.png)

3）按照要求依次填写应用的基本信息，如应用名称、行业类型等，审核通过后即可生成对应的APP ID。

![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829160709_929222.png)



●**iOS应用 APP ID获取**  

iOS应用开发者即可获取已上架的iOS应用的APP ID。



# 三、使用APP应用产品（投放管理平台）

●创建3.0营销时，根据投放诉求选择推广产品为“Android应用”，填写Android应用的APP ID，系统会自动识别应用相关信息，即可按照需求投放非游戏Android应用。

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829160943_411424.png)





●创建3.0营销时，根据投放诉求选择推广产品为“**iOS应用**”，填写已上架的iOS应用的APP ID，系统会自动识别应用相关信息，即可按照需求投放非游戏iOS应用。

![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829160951_355519.png)
