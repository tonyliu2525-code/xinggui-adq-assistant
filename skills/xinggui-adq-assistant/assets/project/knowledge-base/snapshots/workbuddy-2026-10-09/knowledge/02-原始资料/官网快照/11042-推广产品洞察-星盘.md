# 一、能力介绍

## 专注腾讯流量的官方权威的推广产品投放情报，帮助客户看清品类机会以及优化动作

**产品定位：** 提供专注腾讯流量的官方权威的推广产品投放情报。基于推广产品视角，提供看清不同品类的经营机会、竞争格局以及同品对标优化建议与策略；指引客户及时发现并跟进爆品优品机会，设计商品的包装方向，制定全面有效的商品投放策略方案。



**适用行业与客户：** 使用新投放系统的客户投放主管、客户的优化师、服务商的优化师等。



**使用场景：** 星盘为不同的推广产品库提供定制化解决方案。



1、看清品类经营——选品测品情报：小说、短剧、电商等行业有日常选品测品场景。系统提供品类情报（消耗规模、竞争格局、消耗增幅、健康度）帮客户捕捉新品、潜力品、爆品等机会，提升选品的确定性。



2、看清优化动作——日常商品投放策略优化情报：日常投放需要投放增量的场景。基于同行标杆的对比，指明定向、版位、出价、创意、链路优化方向及提升建议，知己知彼，从从盲目投放到对症下药。







# 二、解决哪些问题-为什么



### 2.1 看清品类经营：捕捉新品、在投优质品、爆品的机会



适合行业：小说、短剧、电商、教育、两品一械等行业有日常选品测品场景。



**2.1.1 教育行业**



**解决问题：** 教育中老年兴趣赛道，星盘披露「高热度未投放新课」、「高潜力已投放老课」品类洞察的信息，为不同拓课诉求的客户提供指引方向。



① 高热度新课：，通过腾讯全域用户热度数据洞察，定位适配AMS投放的高潜新课，帮助客户提升新课孵化效率。



② 潜力老课：，通过消耗量级/消耗增长速度/客户竞争自由度/课程健康度等指标展示课程分布趋势，提升客户跟品选品效率。







**2.1.2 阅读行业**



**解决问题：** 小说短剧赛道，需要不断选品测品，打造爆品提升消耗。可投的小说短剧很多数以千计，但是缺乏可靠的适合腾讯流量的选品指导。



① 星盘提供系统当日实时、近期热门的爆款小说短剧资讯，客户可以第一时间获取新品爆品信息，并及时跟品投放。



② 此外，星盘还披露作者、爆量版位、最近14天爆量趋势，辅助客户进行跟品的判断。







### 2.2 看清优化动作：知己知彼，学习优秀同行标杆的投放设置，从盲目投放到高效优化



**解决问题：** 新投放升级后，投放优化视角从营销升维到推广产品，亟需回答2个问题：如何评价推广产品投放效果，如何围绕在投的推广产品找到优化突破点。帮助客户从盲目投放到高效投放，将“运气博弈”化为“可视数据”，实现增长的确定性。



星盘提供推广产品的全局分析，帮助客户知己知彼，看清自身投放的产品的份额和指标趋势；学习投放同类产品 的竞争对手投放妙招，给出定向、版位、出价、创意、链路、策略使用等多维度建议。



# 三、使用门槛和产品入口



● 功能生效范围：需使用以下产品库的推广产品，最近30天消耗大于0元。不同产品库的星盘推广产品洞察功能不同。



支持的产品库：商品库、小说库、短剧库、教育产品库、金融产品库、婚恋摄影产品库、丽人产品库、综合家政产品库、招商加盟产品库、运营商产品库



●使用者权限：



- 具有业务单元的管理/协作权限的人员，适合工作台入口；能够看到业务单元下某个推广产品的全部数据。



- 管理部分投放账户的优化师，适合投放端入口；能够看到某一业务单元下自身有权限的账户范围* 某个推广产品的全部数据。



### 3.1  工作台入口



● 适用人员：具有业务单元的管理/协作权限的人员



● 入口路径：登陆客户/服务商工作台→切换对应的产品对应业务单元→ 进入对应产品库→ 查看推广产品洞察分析



● 说明：当期望分析A推广产品，需要切换A推广产品所属的业务单元







**特殊说明：** 当使用“商品库”时，需要进入全域商品平台查看星盘洞察功能。



第一步：登录后进入工作台页面，确保切换组织身份为业务单元，在资产中找到电商商品库。











### 3.2  投放端入口



● 适用人员：管理部分投放账户的优化师



● 入口路径：登陆投放端→资产→ 推广产品洞察（星盘）→ 选择具体的产品库→ 查看推广产品洞察分析



● 说明：



1、代表该投放账户归属于的组织，一个推广账户id只属于一个业务单元组织，此处不支持筛选，仅披露业务单元组织id供参考。



2、支持筛选投放账户：勾选的投放账户数据，将在洞察能力中作为“我的产品”的投放数据，与同类产品数据进行对比分析。此处会拉取业务单元下的所有uid，但仅允许登录人选择有操作权限的账户。支持选择多个账户，多个账户数据会合并进行分析。



3、商品库暂不支持该入口。

# 五、常见问题



**Q：星盘的产品入口在哪里？**



A：星盘共有2个不同的入口。



● 如果是一线优化师建议使用投放端入口，分析的是有权限的账户投放的推广产品数据（不支持跨业务单元分析），对比同类产品的投放洞察分析，产品路径是「登陆投放端→资产→ 推广产品洞察（星盘）→ 选择具体的产品库→ 查看推广产品洞察分析」。



● 如果是客户负责人，拥有业务单元管理或协作权限，建议使用工作台入口，分析的是本推广产品全部数据，对比同类产品的投放洞察分析，产品路径是「登陆客户/服务商工作台→切换对应的产品对应业务单元→ 进入对应产品库→ 查看推广产品洞察分析」。



● 商品库入口比较特殊，当使用“商品库”时，需要进入全域商品平台查看星盘洞察功能。可以登录工作台或者投放端进入全域商品平台，确保切换组织身份为业务单元，在资产中找到电商商品库，可查看推广产品洞察分析；预计11月支持部分权限的账户投放的推广产品的星盘洞察分析。



**Q：星盘已经支持的产品库有哪些？哪些行业的客户可以使用？**



A：星盘已经支持的产品库包括：商品库、小说库、短剧库、教育产品库、金融产品库、婚恋摄影产品库、丽人产品库、综合家政产品库、招商加盟产品库、运营商产品库。 任意开户行业的客户，只要使用上述产品库并有至少1个最近30天消耗大于0的推广产品，均可查看星盘洞察分析能力。



**Q：如何理解星盘的同类产品？**



A：不同产品库的同类产品定义不同，详见文档[星盘推广产品同类产品定义说明](https://doc.weixin.qq.com/doc/w3_AZ4A0gY0AI00zeYws5rRMqHrFFMVH?scode=AJEAIQdfAAosjO81ObAZ4A0gY0AI0&isEnterEdit=1)。
