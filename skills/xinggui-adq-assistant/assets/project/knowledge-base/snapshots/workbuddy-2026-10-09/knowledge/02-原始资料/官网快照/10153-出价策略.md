# 一、能力介绍
为了满足客户对于oCPA投放时不同场景的需求，同时为了便于客户理解，我们将原有的出价类型（手动出价和最大转化量投放）以及出价策略（稳定拿量、控制成本上限）做了整合统一为出价类型，如客户有提升拿量能力的需求可以自主提高营销出价或者使用最大转化量投放。控制成本上限，有想使用该能力的客户请联系对应的行业经理申请开白移步至最大转化量投放下使用。所以目前支持的出价类型为如下两种：

|	出价类型（原出价类型与出价策略）	 |	说明	 |	使用场景	 |
|	--------	 |	--------	 |	--------	 |
|	稳定拿量	 |	系统会在尽可能使成本与目标出价贴合的情况下为您的营销获取转化量，根据客户的目标出价自动进行调节；
该模式下的出价修改结果为实时生效（5min内），为了成本相对稳定，不建议频繁修改出价（低于5次/日）	 |	预算有一定限制，对成本波动容忍度较低，希望投放期成本稳定且贴近目标出价	 |
|	最大转化量投放	 |	最大转化量投放根据客户的投放诉求和预算，在尽可能花完设定预算的基础上、努力为客户达成最大转化量的投放目标；
客户设定预算后，产品会根据客户所在的行业、客户历史消耗、竞争环境变化、优化目标等预估消耗曲线，将预算按照预估曲线去分配，出价从低到高探索进行投放，保证预算尽可能按照客户自身产品的流量需求进行投放，并结合实际消耗速度对投放的出价进行修正，以此来达到最大转化的效果	 |	"预算相对充足，对成本波动容忍度较高

同一营销的类型切换：
投放开始后，不可以在两种类型之间进行切换

如以下场景：

● 电商大促/新游大推等有需要大量买量的场景

● 新账户/新品/新素材，希望快速积累投放数据，提高模型预估准确度的场景

● 转化稀疏、转化回传时间长导致起量困难的场景"	 |

# 二、解决哪些问题
出价类型是基于客户的诉求，系统为您提供可选择搭配使用的不同出价类型，以满足您对于营销效果的不同诉求（稳定成本的前提拿量、画完设定预算前提下拿到尽可能多的转化），可以对不同营销进行不同设置。

# 三、使用门槛
出价类型是针对全部客户进行开放使用的，但是最大转化量投放需要客户可以合理设置预算并且能在初期积累一定转化量保证系统出价准确。

# 四、操作说明
可以在投放管理平台中的营销设置下属的“出价与预算“环节中看到”出价类型“选项，基于上述说明选择对应的出价类型即可。

# 五、常见问题
**Q1**：为什么我使用稳定拿量，我的成本依然高于我的目标出价？

**A1**：因为稳定拿量也是在oCPA前提下，oCPA营销系统总是以优化目标出价去寻找最合适的用户，但是系统预估与用户实际行为难免存在合理偏差，因此，就单条营销、单天数据而言，实际转化成本很难和目标出价完全一致

**Q2**：最大转化量投放如何理解，如何合理设置？

**A2**：最大转化量投放有专栏说明，请移步至 [腾讯营销 | 帮助中心](https://e.qq.com/ads/helpcenter/detail?cid=3162&pid=9387)
