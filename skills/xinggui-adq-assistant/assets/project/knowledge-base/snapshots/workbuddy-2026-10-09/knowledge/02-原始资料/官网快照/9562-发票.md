# 一、 充值后应如何获取发票？

自助注册的客户与代理商在充值后，请点击【财务管理】—【发票开具】，在打开的页面中完成发票申请； 由代理商提供服务的客户请向所属代理商索要发票。

# 二、 在“发票开具”页面应如何操作？

1. 功能入口：点击财务管理-发票开具后，您可以查看当前已开具发票列表，如未开具过发票，则列表默认为空





2. 申请开票：点击“发票开具”按钮后，进入发票申请页面如下





3. 如果您的账户是初次申请开具发票，请按要求填写发票信息（包括发票类型、发票项目、充值对应月份及发票金额）、一般纳税人信息（企业客户必须填写）、邮寄地址







4. 完成填写后，点击“提交”按钮，则成功发起发票开具申请，腾讯营销官方会对您所填写的信息进行审核，如无问题，则按照您填写的地址邮寄发票。



5. 仅账号主管理员、管理员及财务员可以申请开具发票。
