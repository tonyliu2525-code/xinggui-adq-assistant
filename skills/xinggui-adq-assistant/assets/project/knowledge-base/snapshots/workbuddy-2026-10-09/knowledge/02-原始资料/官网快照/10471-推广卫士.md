# 一、推广卫士简介



推广卫士对搜索直投营销生效，是一款集IP策略展现屏蔽、访客策略展现屏蔽、手动展现屏蔽功能于一体的无效点击防护工具。支持个性化设置展现屏蔽。



当前推广卫士支持手动展现屏蔽，对【QQ浏览器等】版位的PC流量场景生效。



# 二、解决哪些问题



搜索营销按点击计费，恶意点击会造成客户预算被恶意消耗，推广卫士-手动展现屏蔽支持客户在账户维度手动屏蔽指定的ip，系统对屏蔽的ip不再展现该账户的搜索直投营销。



# 三、使用门槛



客户需要提前准备好需要屏蔽的ip信息。



# 四、操作说明



## 1、入口



工具——>投放管理——>推广卫士









## 2、配置手动展现屏蔽IP



点击【新增手动展现屏蔽IP】，在【屏蔽设置】弹窗中添加需要屏蔽的IP或IP段。









● 在左侧IP屏蔽列表中逐个输入或粘贴IP或IP段，回车新增；

● 支持添加IPV6和IPV4版的单个IP，以及最后一段或两段是* 的IPV4版IP地址；

● 最多可以添加200个IP或IP段，其中最后1段为*的IP最多可以添加50个，最后2段为*的IP最多可以添加3个；

● 左上角展示本次已输入多少个、账户当前最多还可添加多少个IP或IP段；

● 支持逐个删除或清空全部已输入的IP或IP段；









## 3、其他操作



支持模糊查询和精确查询、删除已添加的IP或IP段；



支持查看该IP或IP段共被多少账户屏蔽。









# 五、常见问题



**Q：推广卫士-手动展现屏蔽对哪些版位生效？**



A：对【QQ浏览器等】版位的PC流量场景生效；
