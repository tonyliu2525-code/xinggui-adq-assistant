# 一、概览



通过 [腾讯营销-客户工作台](https://ad.qq.com/cm/home) 登录后，即可进入腾讯营销-客户工作台概览页







### 1.1 今日数据概览



● 展示user名下所有账号的汇总数据，支持点击卡片右上角，自定义修改指标



● 可切换指标包括：今日花费、账户余额、曝光量、点击量、点击率、目标转化量、目标转化率、目标转化成本、深度转化量、深度转化率、深度转化成本、有消耗的账户数、我管理的账户数







### 1.2 个人信息



● 展示user关联的所有组织数、user身份=管理者的组织中的成员总数、user名下的账户总数。



● 点击“组织概览”，可以跳转至组织概览页面。



● 点击“指南”，收起组织搭建建议。







### 1.3 账户列表











**1.3.1 支持功能**



● 展示账户范围相关设置



- 搜索、筛选账户



- 查看重点账户



● 展示数据相关设置



- 更换时间范围



- 更换数据展示口径



- 更换列表展示指标--自定义列



- 刷新列表内数据



- 下载数据



**1.3.2 账户来源**



● 全量账户列表包括



- 账号关联的所有直客账号



- 账号加入组织后，角色=协作者时，被分配到的投放账户



- 账号加入组织后，角色=管理员时，管理的组织内所有投放账户



● 主体加入工作台后，用户能够在工作台管理该主体下所有账户；主体下新开账户将自动归属到主体在工作台组织下，无需手动添加



● 支持通过账户ID、账户名称进行账户搜索，支持搜索多值







**1.3.3 筛选面板**



● 账户列表默认展示用户名下全量账户中，有数据的账户列表；**若想看到新开账户，可以将“过滤无数据”筛选项调整为否**



● 支持点击蓝色小漏斗，展开筛选面板







● 筛选面板中，筛选项有内容后，将自动在外层列表上方展示。可通过外层筛选项后方的”x“，将该项从常用筛选项中删除。删除后，在面板中重新选择即可恢复。



● 筛选项能力介绍



| 筛选项 | 能力 | 备注 |

| -------- | -------- | -------- |

| 投放账户     | 支持切换「腾讯营销账户」或「公众平台账户」     | 外层筛选项不可删除     |

| 账户类型     | 支持切换「直客」账户与「子客」账户     |      |

| 标签     | 支持筛选出标签中包含输入内容的账户     |      |

| 备注     | 支持筛选出备注中包含输入内容的账户     |      |

| 过滤无数据     | 支持从账户列表中，过滤掉无数据的账户     | 外层筛选项不可删除     |

| 所属服务商ID     | 支持筛选出归属于该服务商的账户     |       |

| 所属服务商名称     | 支持筛选出归属于该服务商的账户     |       |

| 所属组织    | 支持下拉选择，或通过输入组织ID/组织名称，筛选出归属于该组织的账户。     | 通过组织筛选时，账户列表中将展示**用户在该组织下，已认领的账户**；若用户尚未在该组织下认领该账户，则无法在账户列表中通过组织id搜索到。可通过管理-组织概览-其他投放账户查询到相关投放账户。     |

| 余额状态     | 支持筛选出不同余额状态的账户     |      |

| 数据版本     | 支持切换不同数据版本，筛选出对应账户     |    |



**1.3.4 支持功能**



● 自定义列：



- 账户列表支持调整列宽

- 

- 常用列表内容，可保存为常用自定义列







● 账户信息调整功能：快捷登录投放平台、快捷设置为重点账户、快捷修改标签备注











● 若无法跳转投放平台，或无法快捷修改标签备注，请确认管理员已审批通过加入组织申请
