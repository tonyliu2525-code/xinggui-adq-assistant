# 一、定位和适用场景

【企业微信库】是各行业相对通用的推广产品库，主要适用于考核整个企业微信账号加粉、转化的场景。您可根据实际推广诉求，判断企业微信资产是否和自身生意模式相匹配，从而正确选择实现精准投放。



# 二、企业微信授权（投放管理平台）

➢进入[腾讯营销 - 投放管理平台](https://ad.qq.com/atlas/53195370/overview/index)，点击上方“工具”tab，选择“企业微信授权与客服管理”。

![image.jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829162348_161586.jpg)



➢点击“工具箱”，选择“企业微信授权与客服管理”。

![image (1).jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829162358_841790.jpg)

➢点击“授权企业微信”，授权成功后选择“我已授权”，页面将自动刷新，授权成功。

![image (2).jpg](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829162407_937247.jpg)

![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250829162417_838016.png)



# 三、使用企业微信（投放管理平台）

●在[腾讯营销 - 投放管理平台](https://ad.qq.com/atlas/53195370/overview/index)创建3.0营销时，选择营销目的，然后根据投放诉求选择推广产品为“企业微信”，选择授权成功的企业微信，即可按照需求投放企业微信。
