# 一、定位和适用场景

【商品聚合页库】适用于投放静态的多商品集中展示的业务场景，如不同品牌、规格、款式或促销活动商品集中展示的页面。该产品库包含**电商、零售、餐饮**三个类目，**请客户务必正确选择和本身生意模式相匹配的类目进行资产创建**，模型会根据您创建的正确产品进行找人优化。



# 二、创建推广产品（客户工作台/服务商系统）

在客户工作台或服务商系统左上角/右上角登录进已创建的“业务单元”中，**仅“业务单元”支持创建和管理“商品聚合页库“的资产。**



## 1、创建入口

进入后点击“资产”，左侧列表展开推广内容，选择商品聚合页产品库，如下图，如果无法进入到工作台，请参考[【客户工作台】操作手册](https://doc.weixin.qq.com/doc/w3_AXQAsgaGABAGvhwf0N5T5mrc8YELP?scode=AJEAIQdfAAophqJ0z0AXQAsgaGABA)完成前置工作（比如工作台权限、比如先创建好业务单元等）。

不可在同一个“业务单元“下创建类目完全相同（无关键属性）或者类目*关键属性完全相同的产品。

# 三、使用推广产品（投放管理平台）

● **创建营销时，点击“选择产品”，可拉取到账户所属业务单元下创建的所有产品**。一条营销仅支持选择一个产品，点击“产品信息”可查看具体设置的关键属性。不可对同一个产品创建完全相同的多个营销。  

● **注意**：当账户切换所属的业务单元后，新建营销将只可以拉取到新归属的业务单元下的产品。历史产品（前业务单元的产品）创建的营销建议删除，如不删除，对于相同关键属性的产品，也不可再创建相同的营销。
