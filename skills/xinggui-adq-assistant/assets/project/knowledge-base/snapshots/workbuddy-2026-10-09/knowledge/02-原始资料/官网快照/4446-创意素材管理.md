# 一、什么是【素材】

**腾讯营销（3.0）中定义的素材包含以下两大类——**



|   **创意素材类型**  |   	**创意素材支持上传规格**  | 

| -------- | -------- | 

| 视频-单个视频	| 16:9、9:16、4:3| 

| 图片-单个图片	| 16:9、9:16、4:3、1:1、3:2、3:4、4:3、5:4、4:5、20:7、7:2、100:9|

## 3.创意素材管理（素材库）基础能力

**以下为素材库的基础能力，不论是业务单元/单账户都支持** —— 若只在一个维度上支持，会在对应功能做额外说明.



|   **功能点**   |   **功能说明**   |

| -------- | -------- |

|   素材上传	   |   ●点击「上传素材」可以从本地进行批量的素材上传

![image (8).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613123455_854384.png)  |   

|   筛选管理	   |   支持如下筛选项：
●搜索：支持视频名称、ID的搜索 （预计6月底支持部分数字、字母的模糊搜索）![image (9).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613123516_092030.png)
●标签：支持内容管理标签、投放素材标签两种标签的筛选
●所属账户：支持筛选出当前账户的素材 or 经由其他账户授权给该账户的素材
●生成方式：原“素材来源”；支持筛选查看素材的生成来源（来源如图）![image (10).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613123531_700717.png)
●视频时长：0-15s、16-30s、31-45s、45-60s、60s+
●尺寸筛选
●创建时间：上传素材的时间
●统计时间：素材在这个时间内产生的数据
●自定义列：自定义列支持多指标![image (11).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613123545_757788.png)
●下载：支持下载当前页面的素材ID、指标数据  | 

|   素材评估   |   	支持展示系统对于该素材的质量评估信息，如：首发、低质...   |   

|   投放素材标签	   |   详见：[3.0——投放素材标签使用指引](https://doc.weixin.qq.com/doc/w3_ADsAJAZaACo0nXewwsET1y0lTER71?scode=AJEAIQdfAAoyzdNo9XALsAcQaSAD4 )
简介：在营销3.0项目中，营销会做唯一性校验，为满足客户在一次营销推广时，针对不同素材测试出价的诉求，投放平台支持了「投放素材标签」的管理与配置能力。客户可在投放流程进行关联投放素材标签，一次营销推广的营销关联不同投放素材标签后，可创建出价不同的营销，达到测试的目的。![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613123635_065410.png)
支持在标签管理-投放素材 添加   |   

|   内容管理标签   |   	仅作为投放平台素材管理使用，用于提高素材筛选效率![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613123653_794849.png)
支持在标签管理-内容管理标签 添加   |   

|   素材授权	   |   支持将当前账户的某种类型素材，全部授权给其他维度的账户（不支持单个图片、视频的授权）![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613123705_453828.png)![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250613123709_114454.png)   |
