# 一、规则更新
## 1、对比贬低尺度
* 不支持商品对比中涉及辱骂拉踩
* 不支持涉及数据贬低，需提供数据证明
## 2、分期到账或分期兑现的权益
* 不支持通过权益（包括但不限于话费、礼金券、赠品等）分期到账/兑现形式，诱导用户进行现金支付
* 可支持用户不需要先支付现金即可领取相关权益，即宣传“免费领”或“0元购/充值”

| -------- |

|X素材中出现话费分期兑换描述，如【每月返10元】，不支持 |

## 3、公众号利益诱导
* 不支持通过利益诱导关注公众号行为，包括但不限于“关注公众号即送100元大礼包”、“关注公众号即可参与抽奖”、“关注公众号后查看答案”等

## 4、国家机关背书
* 不得使用涉嫌假冒国家名义、形象背书，包括但不限于利用国家颁发奖项/资质为产品品质、效果做担保等

## 5、身份指向性
* 不支持素材中出现身份指向性描述，包括但不限于“1970-2000年出生”、“身份证为612开头”等

| **素材投放示例** |

## 6、利用虚假情景演绎的形式做宣传
* 不支持以演绎的形式营造虚假人设，误导消费者对营销信任与认可
* 不支持利用无法证实的营销手段或借用/模仿社会热门事件做营销宣传
* 不支持虚构产品市场变革或科技前沿变化做营销噱头
* “归你了”类句式——用户还未购买，商品并非归属用户，不能明确表明商品归属，属于虚假营销

## 7、医疗健康行业-“医用面膜““械字号面膜"等擦边球词汇

# 二、拒绝top行业
## 1、教育
### （1）教育混淆招聘
* 教育行业素材不支持出现包括但不限于二维码、QQ号、企微、个微、阅读原文引导等引流方式
* 教育标题推广需明确培训属性，并体现培训内容

| **素材投放示例** |
| -------- |
|![image11.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250310091937_902846.png)   |
|X素材涉及引流加群，不支持  |

### （2）仿国家政策通知
* 不支持使用模仿国家政策等，涉嫌诱导点击的描述；如“最新通知”、“好消息”、“重磅”、“权威”、“注意”等宣传描述
* 不支持素材图片使用红色主题样式
* 不支持明确政策调整类词汇

| **素材投放示例** |
| -------- |
|![image12.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250310092017_302108.png)  |
|X素材中涉及模仿国家政策通知的内容，如【定了！刚刚明确：】，不支持   |

### （3）功效承诺
* 不支持使用夸大、承诺、绝对化用语及虚假宣传的描述

| **素材投放示例** |
| -------- |
|![image13.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250310092059_644936.png)   |
|X素材中涉及使用虚假宣传的描述，如【学习使人长寿】，不支持   |

## 2、游戏
### （1）涉及活动不一致
* 推广内容涉及需提供活动备案时，需与备案内容保持一致

### （2）虚假保障性内容
* 推广实物奖品兑换及现金活动业务，不得出现具体可量化收益表述，包括但不限于一年买一套房、半年还清贷款等

### （3）指向性
### 规则解析：

| **场景** | **不支持场景** | **支持场景** |
| -------- | :-------- | :-------- |
| **箭头**  |1. 不支持视频画面中出现任何指向组件区域(包括不限于引导购买、下载、咨询服务等)的箭头
2. 不支持营销文案中出现任何指向组件区域的箭头，包括但不限于文案中的手势表情包等|支持箭头为创意设计，无指向含义引导用户点击操作文案中出现指向性箭头，若指向的某个细节（地点、商品、人物等） |
| **字幕**    | 字幕引导的指向区域方向有误，包括但不限于点击右侧购买、左/右滑查看详情等
（**正确方向**:非直播在左下角、直播在右下角） |支持任何文字中出现指向左下方、下方组件区域描述，如：“点击下方购买”“点击左下方查看更多精彩内容”，不区分字幕概念|
| **口播/手势**     | 1. 不支持口播/手势引导点击头像，引导用户购买或下载
2. 口播/手势引导的指向区域方向有误，包括但不限于口播内容“点击右侧购买”、“左/右滑查看详情”等
（**正确方向**:非直播在左下角、直播在右下角） | 1. 支持手势或口播指向左下方、下方组件区域（补充左下方、下方细节描述）
2. 支持不具备任何指向引导意义的手势 |

## 3、食品
### （1）时效过期
* 营销推广内容应当保持时效性

| **素材投放示例** |
| -------- |
| ![image17.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250310092338_735613.png)  |
|X素材中推广日期与宣传时间不相符，如【投放时间为三月，宣传内容为临近春节】，不支持   |

### （2）混淆医疗
* 营销宣传不得暗示医疗效果，包括但不限于非医疗行业暗示医疗功效、宣传24项保健品功效、单独出现疾病治疗性词汇等

| **素材投放示例** |
| -------- |
| ![image18.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250310092418_326331.png)  |   |   |
|X非医疗行业素材中使用暗示医疗效果的描述，不支持   |

### （3）渲染恐慌情绪
* 禁止使用营造恐慌、渲染恐慌情绪的表述，包括但不限于通过描述“一场大风暴就要来了，无人幸免”和“残酷真相让人不寒而栗”等，引起用户恐慌情绪

| **素材投放示例** |

|![image19.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250310092439_648982.png)   |

## 4、互联网电商服务
### （1）一致性
* 推广产品型号/价格/折扣优惠/产品需保持一致

### （2）负向价值观
* 营销素材宣传导向禁止出现违背社会公序良俗，产品在剧情中的应用场景需要正向积极

## 5、医疗健康
### （1）模仿政府文件
* 不支持使用模仿政府红头文件等形式作为营销创意，包括但不限于红色抬头、红线、政府机构/军警名义或红旗、国徽元素、文件号、机关盖章、落款等元素

| **素材投放示例** |
| -------- |
|![image23.png](https://bbx-pic.gtimg.com/bbx/pictures/2025/443_20250310092708_425352.png)   |
|X素材中出现类似于红头文件设计，不支持   |

### （2）保证类/绝对化描述
* 不支持使用包括但不限于“效果词汇+病症/病症群体"等的描述，以暗示产品可以彻底治愈、必定起效
* 不支持表示对产品功效、安全性的断言或者保证

| **素材投放示例** |

### （3）超广审
* 营销外层素材内容需遵照广审样件表以及说明书功效范围描述，不得超出范围描述
