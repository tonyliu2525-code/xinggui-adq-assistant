# 一、功能说明

* 工作台支持用户在相同商务管家和相同服务商下的子客间进行自由转账。

* 如需使用转账功能，需子客账号所属的服务商在服务商系统配置【允许资金自理】后，才可以在相同商务管家中子客账号之间的资金划转。

# 二、开通条件

投放账户需满足以下条件，方可在工作台内使用转账功能

* 投放账户已被认领至相同的商务管家内

* 投放账户属于相同的服务商

* 服务商已为您设置可自理资金

# 三、操作流程

1.进入【财务】的【资金管理】模块，选择需要转账的子客账号，可通过营销账号ID/服务商进行筛选。



2.操作转账，针对选中的子客账号，“转入”即从其他子客账号下转入本账号，对于非有效的营销账号，没有“转入”操作，不再支持资金的转入。点击“转入”，弹出的小窗中先选择资金来源的子客账号，再选择该账号下的资金账户。





3.操作转账，针对选中的子客账号，“转出”即从本账号转至其他子客账号。点击“转出”，弹出的小窗中先选择本账号的资金账户并输入转出的金额，再选择转入账号。





# 四、服务商设置方式

若工作台内没有转入/转出功能，可联系投放账户所属服务商进行设置，设置完成后方可使用转账功能。

操作入口：服务商系统-财务-财务信息-账户列表-支持客户资金自理-点击设置为【是】
