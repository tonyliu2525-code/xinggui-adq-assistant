# 处理流程
1. 申请人发起邮件进行账单收件人登记/更新
2. 腾讯营销业务侧复核人员身份并邮件回复更新意见
3. 结算专员更新收件人并邮件回复更新结果

# 注意事项
* 账单联系人的登记和更新，已触发的账单不会重新发送，将于下期生效
* 若申请人发起申请后未在处理时效内收到反馈，或对反馈结果有异议的，请主动[联系结算专员](https://support.e.qq.com/detail?cid=4059&pid=9107)了解具体情况
