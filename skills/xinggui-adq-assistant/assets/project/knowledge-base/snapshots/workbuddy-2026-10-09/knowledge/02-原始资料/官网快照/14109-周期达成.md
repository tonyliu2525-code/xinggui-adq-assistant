# 一、背景
●部分客户在投放过程中对于单日的超成本现象较为敏感，且如果客户预算有限，单日的转化量稀疏，会进一步加剧超成本现象，客户常常会通过停投或拉空时段等方式来对抗系统，进一步加剧系统优化难度。

●因此腾讯营销推出周期达成产品，通过使客户以固定周期投放，减少客户/代理商的操作频次和盯盘成本，同时给予系统更充分的探索和优化空间，实现成本更稳定、跑量更持续的投放状态。
# 二、适用客户
●单日预算有限的客户，通过一笔周期性的总预算帮助系统积累更多转化数据，进一步提升达成效果

●单日达成波动较大的客户，通过周期性投放契约从多日维度考察达成效果

# 三、流程概述
由于新标的可能存在不起量等问题，建议测试期一个账户创建2条以上周期达成项目
![image.png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260624111122_217981.png)
## 3.1 功能入口
●在「线索艾米」场景中新增「周期达成」开关（目前支持线索智投场景下的全部OG），开启后则项目按照固定周期投放，无需客户频繁操作，系统学习多天累计数据以进行更充分的探索，帮助客户以更稳定的成本获得更高转化

●开白后，周期达成开关默认开启，客户可手动关闭，关闭后则变为常规智投项目
![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260624111131_152180.png)

## 3.2 投放表达
### 3.2.1 周期天数
●当前版本支持「3天」或「7天」两种周期选择，周期天数默认为7天。

●项目开始投放后不支持由一种周期天数修改为另一种周期天数。
![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260624111142_592225.png)

### 3.2.2 周期总预算
●客户需要针对所选周期一次性出一笔周期总预算，为保证给系统充分的探索学习空间，进一步保证达成效果，周期总预算不能低于3x出价x周期天数。

❗️❗️建议预算和同标的跑量项目对齐，按最低值设置可能影响项目跑量
![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260624111154_079337.png)

### 3.2.3 投放日期
●系统默认选择当天为投放开始日期，客户可自主选择投放开始日期

●不支持选择投放结束日期，若客户未开启续投，则投放结束日期=投放开始日期+周期天数-1
![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260624111203_376356.png)

### 3.2.4 项目续投
●新增「项目续投」按钮，默认开启。开启续投，项目在完成当前周期后，会自动投放下一个周期，投放设置复用上一个周期。

●客户在项目投放过程中，可随时选择关闭或重新开启「项目续投」按钮。项目创建成功且保持投放状态中，客户可在项目管理列表随时更改此设置。

●如果客户关闭了「项目续投」按钮，则项目仅投放至该周期结束，且项目结束后不能再次开启续投。
❗️建议开启续投，多个周期投放，给系统更多的学习空间，进一步稳固达成效果

●客户需要手动删除过期项目。
![image (5).png](https://bbx-pic.gtimg.com/bbx/pictures/2026/458_20260624111211_290906.png)

## 3.3 项目编辑
●为保证系统充分探索空间，周期达成类项目提交成功后，支持客户以下项目编辑动作：
○提高出价
○提高周期总预算
○编辑创意
○项目删除
○可选投放时段

●为进一步稳定项目达成效果，周期达成类项目提交成功后，不支持以下项目编辑动作：
○降低出价
○降低周期总预算
○定向编辑
○项目启动和暂停

❗️❗️建议客户至少完成1个投放周期，请勿提前删除项目。测试金赔付需投满一个完整周期
❗️建议创建项目时定向对齐已跑量项目
# 四、准入方式
通过白名单方式可见周期达成开关，请与对应行业运营提报

# 五、赔付政策
## 5.1 测试期赔付规则
●复用历史自动赔付规则，自动赔付无法覆盖的部分用测试金赔付

●客户需至少完整投满一个周期，才能享受测试金赔付

●测试金赔付周期：3.21-7.23

●历史自动赔付规则
[腾讯营销 帮助中心](https://support.e.qq.com/detail?cid=4597&pid=2004 )

●测试金赔付规则
○空耗赔付金额=空耗金额x50%
○超成本赔付金额=转化>0的项目，超成本20%以上的部分进行赔付-自动赔付部分

●单客户上限
○单客户赔付金额不超过1w
