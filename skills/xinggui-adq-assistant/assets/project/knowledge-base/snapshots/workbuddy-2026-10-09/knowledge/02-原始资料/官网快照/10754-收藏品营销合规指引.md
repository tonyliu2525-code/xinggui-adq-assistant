一、收藏品营销通用合规要求



1. 各类收藏品营销中，不得使用国家机关及其工作人员的名义，不得使用“破例批准”“打破惯例”等营销用语；使用“XXX收藏”“XXX鉴定”“XXX检验”等利用其他企事业单位、社会团体、组织或者个人的名义、形象进行宣传的，应当查验该单位、团体、组织或者个人出具的书面证明材料（包括许可使用其名义、形象进行营销宣传的书面材料）。





2. 各类收藏品营销中不得含有诸如“必将一路飙涨”“升值潜力无限”“市值很可能一跃千里”等无根据的升值承诺或者含有投资回报的内容，不得使用“最佳”“最高级”“顶级”“极品”等绝对化用语。





3. 使用人民币图样制作各种收藏品，必须按照一事一批的审批制度经过中国人民银行审批；未经审批，营销中不得出现人民币图样。





4. 各类收藏品营销应当符合下列投放形式要求：


4.1 应当具有可识别性，通过大众传播媒介发布的收藏品营销应当显著标明“营销”，与其他非营销信息相区别，不得使消费者产生误解；


4.2 大众传播媒介不得以新闻报道形式变相发布收藏品营销，不得使用“热点追踪”等标题误导消费者；


4.3 以知识介绍、体验分享、消费测评等形式发布收藏品营销，并附加购物链接等购买方式的，应当显著标明“营销”；


4.4 禁止通过虚假的播放、开始、暂停、停止、返回等标志以及虚假的奖励承诺、内容等方式欺骗、误导用户点击、浏览营销；


4.5 以弹出等形式发布的营销，应当显著标明关闭标志，确保一键关闭；


4.6 营销展示页和营销落地页、跳转链接内的内容需要具有一致性。







5. 各类收藏品营销使用数据、统计资料、调查结果、文摘、引用语等引证内容的，应当真实、准确，并表明出处。引证内容有适用范围和有效期限的，应当明确表示。





6. 各类收藏品营销中表明推销的商品、服务附带赠送的，应当明示所附带赠送商品或者服务的品种、规格、数量、期限和方式，优惠价格或者促销活动有限制或者附加条件的，应当在营销中明确表明。





7. 营销代言人在收藏品营销中对商品、服务作推荐、证明，应当依据事实，符合和有关法律、行政法规规定，并不得为其未使用过的商品或者未接受过的服务作推荐、证明。





8. 不得利用不满十周岁的未成年人作为收藏品营销代言人。

二、人民币、纪念币、纪念章（品）相关营销合规要求



除遵守收藏品营销通用合规要求外，涉人民币、纪念币、纪念章（品）相关营销的，还应当遵守如下合规要求：



1. 人民币、纪念币相关营销资质要求：


1.1 流通人民币及装帧的流通人民币：投放宣传经营的流通人民币以及装帧的流通人民币营销，应当提交相关的中国人民银行经营流通人民币许可证、装帧流通人民币许可批准文件。


1.2 纪念币：人民币纪念币包括普通纪念币、贵金属纪念币，是限量发行、具有面值的国家法定货币，由中国人民银行统一发行并在发行时向社会公告。发布人民币纪念币营销，应当查验中国人民银行相关公告文件，核对纪念币信息及有权进行预约兑换、装帧销售、分销等活动的相关主体信息。


普通纪念币由中国人民银行组织发行招标，中标的承销团负责普通纪念币预约兑换和装帧销售。贵金属纪念币由中国金币总公司总经销、中国人民银行批准的中国金银纪念币零售企业分销，相关资质信息在 [中国金币网](https://www.cgccl.cn/) 可查。


发布以其他国家和地区名义发行的法定贵金属纪念币营销，应当查验该纪念币经中国人民银行同意进口的审批文件和该纪念币海关报关凭证。


1.3 人民币图样：投放的营销中使用人民币图样，或者发布含有人民币图样商品的营销，应当提交相关的中国人民银行人民币图样使用许可批准文件。





2. 人民币是国家法定货币，禁止发布伪造、变造的人民币营销，禁止在营销中或者其他商品上非法使用人民币图样：


2.1 该“图样”包括中国人民银行历年来发行的所有版本的人民币图样。使用方式包括使用人民币完整图案和主景图案（放大、缩小或者同样大小）；


2.2 收藏品营销中包含有流通人民币或者退出流通人民币商品销售的，在未经中国人民银行批准的情况下，也不得在营销中使用人民币图样来展示所销售的人民币商品。







3. 不得投放非法买卖流通人民币的营销。如：将现行流通人民币以“顺子号”“豹子号”等方式进行销售，或者以“赠品”为名，将正在流通的第五套人民币与自行制作的其他纪念品组合销售。





4. 非法定货币发行机构发行的各类贵金属纪念章、纪念品以及经许可使用人民币图样的商品，不是法定货币，不得在营销中称为人民币和纪念币，亦不得存在以下虚假宣传行为：


4.1 在自制的纪念章（券）、人民币装帧纪念册等产品中冒用中国人民银行、中国钱币博物、印钞造币厂等中国人民银行所属企事业单位名义进行营销宣传，采用“中国人民银行权威发行”“绝版 限量发行”“官方发行”“国家破格准许”“中国人民银行库藏极品”“中国人民银行高价回购”等表述误导、欺骗消费者；


4.2 以“纪念币”“纪念钞”“测试钞”命名商家自制的章券类纪念品，让人误以为该纪念品是中国人民银行发行的纪念币或纪念钞，以此迷惑消费者；


4.3 虚构发行机构，擅自利用重大政治题材，将自行制作的纪念品称为“金箔钞”“纪念金币”等，虚构中国驻外领使馆外交认证，联合发行史无前例、仅此一次等不实表述；


4.4 其他国家和地区发行的法定流通货币（包括流通纪念币）营销中出现“等值流通”“等值兑换”“官方兑换”“官方发行”“全国限量”“中国大陆兑换官方通道”等不实表述。







5. 不得通过营销宣传销售或购买普通纪念币进行投资、增值等内容；贵金属纪念币可以通过营销宣传投资价值，但不得在营销素材中承诺、夸大收藏及保值、升值价值，避免构成对收益作出承诺性保证，明示或者暗示保本、无风险或者保收益的风险。





6. 各类纪念章（品）以及人民币、纪念币相关营销中，不得使用国家机关及其工作人员名义做宣传；使用他人或其他机构形象、名义的，要事先取得同意或授权。





7. 销售非人民币货币收藏品的，营销中不得宣称“等面值兑换”“等额兑换”及类似用语。





8. 禁止发布高仿真钱币衍生品的营销进行营销宣传。如：以销售练功券、电影拍摄道具、魔术道具为名，经营销售高仿真外币衍生品。

三、 集邮票品营销合规要求



除遵守收藏品营销通用合规要求外，涉及邮票品营销的，还应当遵守如下合规要求：


1. 集邮票品营销资质要求：


1.1 作为通信使用的普通邮票，由邮政企业专营。除邮政企业和邮政企业委托的邮票代售处以外，任何单位和个人均不得经营普通邮票；


1.2 投放除普通邮票以外的邮资凭证和集邮品等相关营销，提供的营业执照中应当包含相应的经营项目；

1.3 办理收购、委托寄售集邮票品业务的，需向公安机关办理备案手续；


1.4 集邮票品集中交易市场开办者应当在邮政管理部门办理备案手续。部分地区要求经营集邮票品的单位和个人在邮政管理部门备案，应当提交在监管机关的相关备案材料；


1.5投放各种集邮票品营销，应当提交国家邮政主管部门对相关集邮票品的发行、审批文件，各类仿制邮票不得谎称为邮票、个性化邮票不得谎称为纪念邮票欺骗误导消费者。







2. 集邮票品营销不得使用“经国家邮政局审批”“经国家邮政部门批准”或“国家邮政主管部门限量发行”等国家机关名义做宣传。





3. 集邮票品营销可以介绍邮票理念交易价格和当前市场行情等客观、真实情况，不得在营销中发布有关集邮品以及邮票价格升值预测和投资回报承诺等内容。





4. 集邮票品营销中有关集邮品的发行（或联合发行）单位名称、发行时间、生产单位名称、售价、鉴定机构等内容的，应当真实、清楚、明白。





5. 禁止发布下列集邮票品的营销：


5.1 伪造、变造的邮资凭证；


5.2 国家禁止流通的集邮票品；


5.3 1949年10月1日以后发行的带有“中华民国”字样的集邮票品；


5.4 未经国家邮政主管部门审批的仿印仿制邮票图案制品；


5.5 属于走私进口的其他国家（地区）发行的邮票及其制品。
