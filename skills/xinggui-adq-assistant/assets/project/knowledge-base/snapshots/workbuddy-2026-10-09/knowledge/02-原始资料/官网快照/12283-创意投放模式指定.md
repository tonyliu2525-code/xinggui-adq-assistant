# 1.能力介绍

腾讯营销可覆盖腾讯多种流量媒体，对应丰富的形态样式。在创意投放过程中，支持客户按照“不指定创意形式” / “指定创意形式”两种投放模式，满足客户不同诉求。  

![image (2).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250527173747_534645.png)

# 2.不指定创意形式（默认）

默认选项，客户无需选择创意形式，在投放流程中直接选择希望投放的创意图片或创意视频，系统会自动匹配创意形式，建议无特殊投放诉求的客户使用该模式进行投放，减少操作成本。  

在一次创意投放流程中，可选择最多15个不同尺寸图片视频同时投放，自动匹配多个创意形式（如投放16：9视频+1：1图片+9：16图片等）  

选择图片/视频后，可参考投放流程右侧的流量覆盖比例，根据建议上传更多图片/视频

![image (3).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250527173822_648502.png)

# 3.指定创意形式

若客户有特定创意形式投放诉求，可打开左上角“指定创意形式”开关，并选择对应创意形式。建议选择带有“通投”标签的创意形式，可覆盖所有版位。  

该模式下，创意投放的组件类型及要求会根据创意形式进行筛选。如需投放其他创意形式，可点击上方新增创意。

选择创意形式后，可参考投放流程右侧的流量覆盖比例，根据建议选择更多创意形式
