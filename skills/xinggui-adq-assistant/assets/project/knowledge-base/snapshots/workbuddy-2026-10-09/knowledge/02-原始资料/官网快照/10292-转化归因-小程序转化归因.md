## 1. 转化归因是什么

### 1.1. 概念说明



**转化归因** 指「效果营销」场景下，在特定时间周期内，将用户的一条「转化行为」（例如：购买，下载，安装等）归属到一条具体「营销」上的过程。 您可以通过数据源上报/转化接入/平台上报等渠道回传转化数据，归因后的转化数据用于精准衡量投放带来的转化量与转化成本。转化归因功能介绍参考[帮助中心-产品介绍说明](https://e.qq.com/ads/helpcenter/detail?cid=3556&pid=10217)。



**数据源** 是接入、查看、授权、分发数据的工具，您可以基于网站/应用/线下/小程序/公众号/小游戏等建立对应的数据源，接入对应场景下的用户数据、商品数据、订单数据等，并将接入的数据作为资产授权给其他账号或分发给各应用场景。数据源接入参考数据接入平台 [DataNexus](https://datanexus.qq.com/doc/develop/intro/inner_app_intro/attribution/attribution_common)（以下简称DN，原有的知数DMP所有数据接入功能已全部迁入）。



**营销链路** 指用户在营销活动中，从点击到完成转化所经过的**完整路径**，由承接转化的**营销载体**和多个行为**节点序列**组成。客户通过在营销创编中选择营销链路，精准表达营销标的和转化路径。



### 1.2. 产品介绍



转化归因承载了客户接收营销触点数据（营销监测服务）、客户上报转化数据（转化上报服务）、平台归因以及投放对应的标的物、优化目标等概念，是打通数据和投放的重要模块。



针对主要投放**小程序**客户，无论您是否已在DataNexus（原知数DMP）建立数据源，转化归因均支持创建小程序类转化。



当前支持 **API** 上报方式。



## 2. 如何在创建营销时使用转化归因

### 2.1. 判断上报方：自建上报还是平台上报？

腾讯营销采用两种方式收集转化数据，我们称之为两种上报类型，即自建上报和平台上报：

| 上报方 | 说明 | 操作指引 |

| -------- | -------- | -------- |

| 自建上报     | 需要您通过SDK/API/JS三种接入方式，自主将转化数据上报至腾讯营销| 请选择该类上报方式的营销主继续阅读2.2与2.3，依次按步骤操作|

| 平台上报 | 当您使用微信原生推广页、蹊径、枫页、阅宝、应用宝落地页、互动推广页、有赞、一叶智能、微盟、有数进行推广时，无需创建转化规则，无需自主上报转化数据，由上述平台自动将转化数据上报至腾讯营销|请选择该类上报方式的营销主直接阅读2.3的步骤4即可 |



### 2.2. 自建上报前置准备



### 2.2.1. 转化归因权限 

您可以在投放平台-工具箱-转化归因，进行营销监测服务配置和转化数据上报。

![image (9).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/46_20240417154135_525174.png)



### 2.2.2. 营销链路权限

在转化归因中创建规则时，如需选择营销链路，请联系对接的行业运营开通相关权限。



![123.png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240919163439_198886.png)

### 2.2.3. 有效的微信小程序APPID，并且已经进行APPID对账户的授权（必填）

* 新建微信小程序转化时需要有效的微信小程序APPID，与投放营销时推广的微信小程序链接一致；请注意这里的小程序APPID是以wx开头的ID

示例 wx06e6ebc139b5436d

* 需要将该小程序对进行上报数据的账户授权，否则微信用户的ID标识无法转换，可能导致您的转化数据归因失败，可参考[工具箱 - 申请微信AppID](https://datanexus.qq.com/web/doc/manual/2672/7392)





### 2.2.4. 点击/曝光监测链接（选填）

* 如果您需要接收平台下发的点击/曝光信息，请准备可以接收下发数据的服务器接口地址，填写所需字段如clickid等，生成点击/曝光监测链接。具体使用方式详见[点击监测链接使用指南](https://datanexus.qq.com/doc/develop/guider/interface/conversion/ad_track_click)

* 监测链接不支持SNI，下发时是IP，建议是http / 服务器上不要多个域名。



示例：



https://www.example.com/click/?adgroup_id=ADGROUP_ID&ad_id=AD_ID&muid=MUID&callback=CALLBACK



* 除了通过点击下发获取点击数据的方式外，推广Web落地页时也常使用落地页拼参方式获取点击数据。在腾讯营销推广时，每次点击都会生成一个 click_id，在跳转到落地页时，会将 click_id 作为参数传入对应的 URL 中。对于腾讯营销非微信流量为URL中的参数qz_gdt的值，对于微信流量为URL中的参数gdt_vid的值。





## 2.3. 操作步骤演示与说明

### 步骤1: 选择新建转化方式



入口：投放平台-工具箱-转化归因-网页转化-新建网页转化

![image (10).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/46_20240417154546_027260.png)



请联系为您上报转化数据的技术侧，确认该营销的转化行为由以下哪种方式进行上报：



### 新建方式一：首次数据接入（推荐）



* 如果您计划或已使用点击下发的CALLBACK(cb)或新版转化归因进行数据上报，可以继续使用该方式上报；



* 在投放微信小程序时，支持API上报数据，请选择您计划使用的数据接入方式。



### 新建方式二：已有数据源上报



* 如果您的转化数据已通过DataNexus的数据源进行上报，您可以选择已有的数据源创建转化，用于投放；



* 数据源内已有的数据可能是通过不同上报方式接入的，当前支持获取API方式上报至数据源内的数据。



例如，计划投放的小程序A 在腾讯已有投放记录，数据源ID 123，您可以选择使用数据源123直接创建一个转化，转化投放标的物为小程序A ，该转化可以直接用于投放。



![image (13).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/46_20240417155126_570554.png)

* 已有数据源上报时，数据源列表来源于 [DataNexus数据源管理](https://datanexus.qq.com/doc/develop/manual/data_source)。若您创建转化时没有在列表中找到计划使用的数据源，请确认（1）该数据源是否是您登录账户下自建/被授权的数据源；（2）在DN平台已支持转化归因场景，并且开启了 [资产分发](https://datanexus.qq.com/doc/develop/manual/asset_distribute)。





### 步骤2: 填写基本信息、选填监测链接 

入口：投放平台-工具箱-转化归因-网页转化-新建网页转化-新建页面

![image (14).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/46_20240417155726_411693.png)





*

### 转化名称（必填）

* 支持中文、英文及数字，总计不超过120字符；

* 可根据实际情况命名，账户内不同转化配置名称不能重复。



*

### 转化类型（必选）

* 选择小程序类型，输入有效的微信小程序AppID。

* 当您用已有数据源创建转化时，如果数据源内已有唯一准确的微信小程序AppID，系统会自动获取并填充微信小程序AppID；如果数据源内没有或者不止一个微信小程序AppID，需要您填写本次转化希望使用的AppID。





*

### 优化目标（必填）

* 投放营销时希望达成的目标，模型会根据设定的优化目标来寻找更倾向于发生这些行为的用户；

* 优化目标列表为您在投放小程序类型营销时，可选的所有优化目标；请确认您计划投放的营销内容、营销版位后选择优化目标；



* 选择优化目标后，需要将相应的转化行为上报，转化激活后才能在投放时使用。



*

### 深度优化目标（选填）

* 用户在优化目标的基础上发生的行为可以设定为深度优化目标。

* 深度目标优化：区分优化转化行为和优化ROI，对应营销需要进行出价。

* 深度辅助优化：对应营销不需要客户出价，由系统辅助出价；该字段有白名单控制，非全量可见。



*

### 营销链路（需开通权限）

* 营销链路：表示用户在一条营销发生曝光/点击之后实际发生的转化行为序列；

* 链路开关：如果您的账户配置了链路权限，才可见营销链路开关，默认开启；如果您需要开启营销链路，请联系您所对接的行业运营，为您进行内部配置；

* 链路选择：选择链路时，会默认展示对应转化类型和优化目标组合下可用的营销链路，可进行筛选，仅支持单选；

* 上报节点：选择链路后，可以指定要上报数据的对应节点；其中链路要求必报的节点会默认勾选且无法取消，建议上报的节点可自行取消勾选

*

### 归因方式（必填）

* 选择优化目标和深度优化目标使用的归因方式，默认点击归因。

* 点击归因：最常见的归因方式，转化效果关联最后一次点击，适合大多数场景。

* 曝光归因：转化效果优先关联对应周期内的点击，若关联不到点击会关联曝光归因时间窗内的曝光。曝光归因有助于增加转化量，摊薄成本，更快速地渡过冷启动。曝光归因非标准选项，如有需要，请联系您所对接的行业运营同学，进行内部申请配置。

*

### 监测链接（选填）

* 监测链接的配置，通过选择 DN 配置的监测链接组（具体使用方式可以详见[数据监测-营销效果监测](https://datanexus.qq.com/web/doc/manual/2841/10243)），也可以在界面上直接填写

* 点击监测链接：

* 在用户点击的时候往指定接口地址发送明细信息，具体使用方式详见[点击监测链接使用指南](https://datanexus.qq.com/doc/develop/guider/interface/conversion/ad_track_click)

* 点击监测链接主要用于客户自归因，您通过点击监测接口可以获取到用户点击明细，通常包含clickid、设备id、ip信息等；接下来，客户内部进行数据匹配，将全网的转化数据与收到的点击信息进行匹配；最后，将匹配成功的转化信息上报至 AMS 的回调地址。

* 曝光监测链接：

* 在用户曝光的时候往指定接口地址发送明细信息，具体使用方式详见[曝光监测链接使用指南](https://datanexus.qq.com/doc/develop/guider/interface/conversion/ad_track_impress)

* 该服务非标准字段，如有需要，请联系您所对接的行业运营，进行内部申请配置。





### 步骤3：通过联调激活转化

入口：投放平台-工具箱-转化归因-网页转化-转化联调



在转化创建成功后，使用联调工具能帮助您模拟真实投放情况下的数据情况，查看点击转发、数据上报链路是否正常，从而保证您在投放后能够正常进行数据回传，避免不必要的预算浪费

**step a：联调信息确认**



![image (1).png](https://bbx-pic.gtimg.com/bbx/pictures/2024/48_20240919153242_481523.png)

* 您需要点击“AMS 联调测试营销”，触发您想要检测的行为发生，并观察联调页面内的点击数据情况。

* 平台将统计点击次数并提供点击数据明细。若转发失败，请根据提示问题进行调整。



**step d：检测数据上报（重点）**

您需要点击“AMS 联调测试营销”，触发您想要检测的行为发生，并将相关数据上报给平台。如何进行数据上报、上报代码示例请参考开发者文档：







| 新建方式/接入方式 | API | 

| -------- | -------- | 

| 新建方式一：首次数据接入    | [APP转化数据API自归因文档](https://datanexus.qq.com/doc/develop/guider/interface/conversion/trackingcgi_api_app)     |

* **数据上报详情**：平台将统计收到的所有转化数据并提供上报数据明细。有数据延迟，您可以点击该模块左上角的"刷新"或者点击"查看"明细，更新页面内显示的数据和时间。请注意：联调预览营销的有效时间为1小时。



* **联调通过标准**：

* 未选择营销链路：当平台收到优化目标和深层优化目标（如有）的数据上报并确认数据正确，点击完成就可以完成联调并激活转化。

* 已选择营销链路：当平台收到全部**必报节点**的数据上报并确认数据正确，点击完成就可以完成联调并激活转化。

# 二、常见问题

## 1. 转化规则创建和管理



**Q：在「工具→转化归因」的列表中，对应的转化规则没有【删除】入口？**



被授权的转化规则无法进行【删除】操作，请联系转化规则的创建方进行删除处理



**Q：配置监测链接时，无法填写曝光监测链接/选择带有曝光监测链接的监测链接组？**



配置曝光监测链接，需对应选择「曝光归因」这一归因方式；如有需要，请联系您所对接的行业运营，进行内部申请配置



**Q：编辑转化规则的点击监测链接时，提示「can't add feedback_url for conversionSpce with empty feedback_url」报错信息？**



如果转化规则创建时未配置点击监测链接，目前暂不支持在编辑时，在该转化规则下新增监测链接。可重新创建一个转化规则填写对应的点击监测链接



## 2. 转化规则联调



**Q：为什么转化规则创建后，没有进行联调，转化规则的状态自动变成了「已激活」？**



需判断是否以下原因：

* 是否联系过对接的行业运营，对当前账号配置了「免联调」权限

* 相同应用（App ID）下，相同优化目标如历史已联调成功过，新建相同优化目标的转化规则时，无需重复联调

* 部分优化目标（如「点击」）无需联调



**Q：为什么点击【开始联调】按钮后，报错「您使用创意形式、版位和商品类型组合不支持当前品牌形象类型。」？**



这是因为您没有对应营销版位的投放权限，导致联调营销创建失败，请联系您所对接的行业运营，开通相关营销版位的权限：

* App、网页、QQ 小游戏类型的转化规则：需开通「腾讯平台与内容媒体」版位的权限

* 企微、小程序、公众号、微信小游戏类型的转化规则：需开通「微信朋友圈」版位的权限



**Q：为什么点击【开始联调】按钮后，报错「未通过身份验证，暂不支持使用，请前往ADQ完成身份验证」？**



如投放账户未通过身份验证，将被限制投放营销素材，导致联调营销创建失败。请完成身份验证后，且账户将恢复投放等功能后进行重试



完成账户身份验证的流程具体可参考：[新身份验证流程指引（对外）](https://doc.weixin.qq.com/doc/w3_AJUAqgZGACgLB1A6zbaTcG1UEWmII?scode=AJEAIQdfAAoik5OaiIAH8A_QZ1ACg)



**Q：为什么点击【开始联调】按钮后，报错「不支持的营销四元组类型,XXXX。」？**



如投放账户没有对应的营销内容（如营销目的、营销载体等）的投放权限，将导致联调营销创建失败。请联系您所对接的行业运营，开通相关营销内容的权限



**Q：为什么联调时，使用手机 QQ 扫码后，无法找到联调营销/显示「暂无可预览的营销」？**



* 可将手机 QQ 客户端更新到最新的版本后重试；

* 如创建转化时选择的是「Android」类型，请使用安卓设备进行联调，如选择的是「iOS」类型，请使用 iOS 设备联调；

* 请确认手机 QQ 相关能力是否开启：

* 1.qq-＞设置 一＞个人信息保护设置 一＞营销推荐设置一＞个性化营销 开关打开

* 2.qq-＞ 设置-＞隐私一＞授权管理-＞管理列表中有腾讯营销相关的应用

* 3.打开qq空间刷动态，直到刷出任意一条营销



**Q：为什么联调时，上报数据一直显示为 0？**



需按如下步骤完成自查：

* 与开发同学确认对应的数据（action_type）是否成功上报

* 确认上报的数据是否对应点击联调预览营销发生的转化（例如 clickid/用户 ID 是点击预览营销用户对应的 ID）

**Q：新建营销时，无法选择已有的监测链接组？**



需判断是否以下原因：

* 在 DataNexus - 数据监测 - 营销效果监测 中配置监测链接组时，选择的「营销载体类型」与投放实际选择的类型不符。如您投放的是 Android 应用，请在 DataNexus 中的「营销载体类型」也选择 「Android 应用」
