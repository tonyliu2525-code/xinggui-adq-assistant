# 一、产品介绍



客户通常会投放多个媒体渠道，转化数据分布在各个渠道，不利于模型充分学习转化行为，尤其对于转化事件稀疏的客户。一方人群跑量加强产品旨在通过让客户回传的全渠道营销数据，为平台补充更多一方数据知识，系统将其作为补充样本针对性优化OCPX模型，并助力提升投放拿量能力。



# 二、使用说明



1.开启条件：需要 联系行业运营申请白名单，一方数据审核通过后方可申请接入。



2.使用场景：仅针对oCPM/oCPC场景生效。
