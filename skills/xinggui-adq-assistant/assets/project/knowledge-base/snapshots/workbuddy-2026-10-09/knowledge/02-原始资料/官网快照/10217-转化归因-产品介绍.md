# 一、功能介绍

## 1.概念说明

**转化归因** 指在特定时间周期内，将用户的一条「转化行为」（例如：购买，下载，安装等）归属到一条具体「营销」上的过程。 您可以通过数据源上报/转化接入/平台上报等渠道回传转化数据，归因后的转化数据用于精准衡量投放带来的转化量与转化成本。



**数据源**  是接入、查看、授权、分发数据的工具，您可以基于网站/应用/线下/小程序/公众号/小游戏等建立对应的数据源，接入用户转化数据，并将接入的数据作为资产授权给其他账号或分发给各应用场景。数据源接入参考数据接入平台 [DataNexus](https://datanexus.qq.com/doc/develop/intro/inner_app_intro/attribution/attribution_common)（以下简称DN，原有的知数DMP所有数据接入功能已全部迁入）。



**营销链路** 指用户在营销活动中，从点击到完成转化所经过的**完整路径**，由承接转化的**营销载体**和多个行为**节点序列**组成。客户通过在营销创编中选择营销链路，精准表达营销标的和转化路径。



## 2.产品背景

转化归因专区为腾讯营销提供给客户的全新的转化工具，承载了客户接收营销触点数据（营销监测服务）、客户上报转化数据（转化上报服务）平台归因以及投放对应的标的物、营销链路、优化目标等概念，旨在提供一体化的转化数据链路相关工具的维护和使用，同时打通数据与投放，帮助客户实现更高效、更准确的数据上报，从而提升投放效率及效果。



对应升级点如下：



| 模块 | 升级前 | 升级后 |

| -------- | -------- | -------- |

| 营销监测     | 在「投放管理平台-工具-监测链接」中配置点击监测链接     | 在 DataNexus 中完成监测链接组的维护后，只需要在创建转化归因时选择对应监测链接组即可     |

| 营销链路     | 不支持营销链路     | 支持在创建转化归因时选择营销链路     |

| 数据上报     | 在 DN 中创建数据源后上报数据     | 支持通过监测下发的 callback 参数获取上报地址     |

| 数据联调     | 不支持联调     | 提供模拟投放的数据联调工具     |



## 3.为什么需要转化归因

转化归因是客户查看报表、投放oCPA营销、优化营销效果所依赖的重要功能。同时，转化归因也是流量方与客户进行结算的依据。归因分析可以帮助客户尽可能识别所有对最终转化产生贡献的投放，了解到自己的营销花费是否起到了效果，并对投放内容，投放人群，营销出价是否合理，有了更具象，量化的感知。根据转化归因得到的结果，客户可以对转化效果好的营销追加投放，对转化效果不好的营销停止投放，尽可能在有限的预算下达到最好的营销转化效果。

## 2. 如何从旧版转化归因能快速切换到新版转化归因？



### 2.1. 判断您是否在使用旧版转化归因？



符合以下 2 个条件时，即在使用旧版转化归因：



**·** 接入数据时，使用 DN 的「数据源」，通过「MKT API」或「SDK」进行接数 



**·** 创建营销时，直接选择「优化目标」，部分客户会选择「精准归因」并绑定「数据源」



### 2.2. 判断您的营销转化数据是平台上报还是自建上报？



**· 平台上报**：当您的营销转化数据是由腾讯、或已和腾讯营销对接的合作伙伴进行上报，例如：微信原生推广页、蹊径、枫页、阅宝、应用宝落地页、有数、互动推广页、有赞、一叶智能、微盟、及医疗行业咨询托管页(商务通、快商通、易聊、53快服、智聊通、美洽、live800、螳螂科技）；则为平台上报，说明您可以不需要自己负责转化数据的上报。平台上报的客户，可以直接跳至2.4。



**· 自建上报**：需要您或您使用的服务商通过SDK/API/JS三种接入方式，自主将转化数据上报至腾讯营销。自建上报的客户，请按2.3～2.4 步骤依次操作。



### 2.3. 在「投放端-工具箱-转化归因」模块建立“转化规则”（仅针对“自建上报”类客户）



请根据营销载体和数据上报方式，在本文档的第 1 部分找到对应的**操作文档**，阅读对应操作手册的「2.3 步骤1～3」（请仔细阅读操作手册，可以配合2.4的视频演示）



### 2.4. 创建营销时，绑定对应标的物的优化目标转化



**·** 针对平台上报类客户，可直接选择符合您想投放的优化目标的“平台上报-转化规则”



**·** 针对自建上报类客户，可直接选择符合您想投放的优化目标的“自建-转化规则”



请根据营销载体和数据上报方式，在本文档的第 1 部分找到对应的**操作文档**，阅读对应操作手册的「2.3 步骤4」（请仔细阅读操作手册，可以配合2.4的视频演示）



# 三、常见问题



## Q: 为什么需要新版转化归因？



**优势1：接入更简单**： 新客户数据接入时长可从平均一周缩短到3天



**·** API接入流程大幅缩短，从7步缩短到3步，开发者和优化师无需反复配合授权，服务开发好后，优化师自主可以完成配置、联调，大幅缩短开发周期，减少沟通成本；



**·** SDK接入流程集成整合，避免配置遗漏，不易出错，同款APP只需接入一次SDK即可在所有账户通用；



**优势2：服务更稳定**：数据上报不强依赖数据源token，可以从转化归因直接上报数据，不易出错



**优势3：数据更准确**：SDK付费默认归因到激活，API根据点击完成校准，数据准确性达到98%



**·** 数据准确是您优化营销和提升竞争力的基础，众多户客户在数据校准后，竞争力和消耗水平都有显著提升；



**优势4：点击下发更灵活**



**·** 点击下发支持宏替换，方便多个媒体的接收服务兼容；



**·** 点击下发支持更多字段（例如：投放小程序营销的wechat_open_id)，后续平台新增的监测字段仅新版支持；



**·** 支持不同账户/计划/营销使用不同点击下发地址，可自主在营销上绑定，配合渠道包可以实现更灵活的归因方案，详见报表搭建指南；



**·** 针对行业运营提供的白名单客户，支持客户自行配置曝光下发。



**优势5：联调更安心**



**·** 对于APP类和网页类转化，创建转化后可以使用联调工具，在营销投前检测归因回传通路与逻辑准确，避免营销上线后才发现接入错误导致空耗。



**·** 根据您选择的优化目标，联调中将展示对应的行为协议和代码示例，并检测回传数据准确性及提供失败原因和建议，帮助您方便准确地接入转化行为数据。



**·** 根据您填写的监测链接，联调中支持测试监测数据能否正常下发，保证投放后您能够准确接收曝光/点击数据。
