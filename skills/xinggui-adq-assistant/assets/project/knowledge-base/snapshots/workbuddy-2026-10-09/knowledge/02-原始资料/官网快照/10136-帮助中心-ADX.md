# 一、产品介绍

程序化出价产品是腾讯营销与客户之间实现程序化交易的模块名称，包含RTA、ADX两种类型，是在腾讯营销和客户之间搭建一条实时接口，能够让客户将自有的数据能力实时作用在营销决策环节，从而达到媒体与客户共建和提升营销效果的能力。  

ADX是Ad exchange的简称，客户可以通过接入腾讯营销ADX，来对腾讯营销的流量进行实时竞价，即实现RTB(real-time bidding)。







## 1. 流量&形态覆盖和规模

当前腾讯营销ADX已基本支持腾讯营销全流量，包括朋友圈、视频号等头部资源。

|流量|请求规模（天） |

| -------- | -------- | -------- |

| 腾讯新闻＆视频| 约80亿 |

| 腾讯QQ系| 约180亿 |

| 微信| 约150亿 |

| 腾讯营销联盟| 约550亿 |



## 2. 计费模式

当前腾讯营销ADX支持按曝光出价和按点击出价两种出价方式



# 二、适用客户&场景

## 1. 平台型客户

### 1.1. 客户定位

●客户自身是程序化技术代理商角色，帮助其子客户全渠道投放和优化效果；  

●客户自身为营销平台，其生态体系内的商家是其子客户，如京东京准通、阿里妈妈。

### 1.2. 客户资产

●客户的目标人群；  

●客户生态体系内的核心用户行为数据，如购买。

### 1.3. 投放目标

●站外流量扩展  

●优化子客户（商家）投放ROI

## 2. 直客型客户

### 2.1. 客户定位

●客户自身是某集团的增长团队，通过程序化营销手段来优化投放带来的用户增长效果。

### 2.2. 客户资产

●客户生态体系内的核心用户行为数据，如下载、沉默时间等。

### 2.3. 投放目标

●优化拉活、拉新ROI，如DAU成本、激活成本



# 三、实时竞价流程说明

1.客户在腾讯营销完成DSP身份入驻和联调;  

2.客户在DSP下创建账户与营销，生成营销ID用于参竞;  

3.用户浏览媒体产生营销请求，ADX系统将营销请求转发给客户，客户自行决策是否参竞&参竞营销ID及出价；  

4.参竞的营销在腾讯营销总营销池内统一竞价；  

5.若竞价胜出并产生曝光，曝光营销的相关展点消数据回传给客户。

# 四、常见问题

## 1. 响应时延要求

腾讯营销联盟：200ms  

微信：160ms  

Q系：120~200ms  

新闻&视频：120~150ms  

## 2. 投放审核要求

接入ADX的客户（DSP）以代理商身份入驻腾讯营销，投放营销前的账户创建和营销/创意创建在审核要求上与普通代理商并无差别。详见：[腾讯营销 | 帮助中心](https://support.e.qq.com/detail?cid=3843&pid=6312 )
