# 一、功能介绍

**功能定位：** 腾讯营销助手小程序旨在为客户进行移动场景的快捷修改操作能力



**功能升级：** 为方便客户在手机端快捷访问账户内旧版和新版的营销，“腾讯营销助手”小程序已全量完成能力升级；可以在新版小程序中查看内容和创意数据、支持预算/出价/投放日期/投放时间等账户和营销层关键信息编辑，并支持营销创意筛选、启用暂停、修改次预算、批量操作营销的能力



# 二、使用说明

| 页面概览 | | | | | |



小程序入口：微信搜索【腾讯营销助手】或者扫描下方二维码







### 2.1. 新旧版本切换入口



新版小程序提供与旧版相同的管理/编辑功能，但新旧版的营销数据隔离，不支持在同个管理列表展示







### 2.2. 支持营销的批量修改



支持根据营销和创意状态筛选和管理营销，同时右上角批量选择营销后，支持营销维度的批量启用、暂停、修改投放日期、修改投放时间、修改深度目标出价、修改日预算







### 2.3. 支持修改次日预算



概览 - 次日预算支持修改







# 三、规划中功能



• 支持营销一键起量的启用暂停



• 允许把预算设为不限（日预算、次日预算、营销预算）



• 创意详情页面支持查看组件维度的设置详情
