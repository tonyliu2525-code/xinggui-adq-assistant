# 一、什么是官方落地页-互动版？

## 1. 官方落地页-互动版的定义

1.⼴义的互动⼴告是指所有拥有互动形式的⼴告，⼴告与⽤户拥有互动性，可以进⼀步提升⽤户的参与感从⽽提⾼⼴告点击率或转化率

2.更详细⼀点的说法，即让⽤户在观看⼴告过程中获得切实的权益（⽐如前置体验app感觉到有兴趣或得到红包奖品等），从⽽激发他们进⽽产生下⼀步行为，包括APP下载、激活，提交客资，加粉，支付等落地页常见的转化行为。

# 三、落地页创建&投放

## 1. 申请白名单

除配置模板和解析zip包目前已全量开放之外，内嵌页面制作方式目前仍需联系行业运营进行加白处理，具体要求见下方对应操作手册。

## 2. 落地页创建

1. 创建入口：[官方落地页-互动版](http://page.e.qq.com/playable/list)  - 我的落地页 - 新建落地页 - 选择创建方式，点击后进入落地页创建页面[官方落地页-互动版](http://page.e.qq.com/playable/list)  



2. 创建过程中，可根据客户实际的技术，视觉或者创意等能力条件，结合不同方式的优劣势来选择合适的制作方式

![image (4).png](https://bbx-pic.gtimg.com/bbx/pictures/2025/458_20250701140836_943758.png)  



3. 选择【解析zip包元素】，需提前准备好自制页面，准备技术对接蹊径JSSDK    

1.1 使用门槛：无，目前已全量开放。  

2.2 JSSDK：是官方落地页提供的一种互动试玩落地页制作能力（仅支持下载类），凭借该能力客户可以在自制的h5上接入落地页的下载和转化数据监测等能力。  

3.3 详细能力介绍和对接流程，见：[【互动】JS-SDK接入文档](https://doc.weixin.qq.com/doc/w3_AekA8QavANwCNizAA8yLESs2g5Hvy?scode=AJEAIQdfAAo0rhVYNdAekA8QavANw&isEnterEdit=1&qt_source=Other&qt_report_identifier=1748507146965)  



4. 选择【内嵌页面】  

1.1 使用门槛：联系您所在行业的行业运营申请开通白名单  

2.2 内嵌：是官方落地页提供的一种iframe页面框架，凭借该能力客户可以内嵌自制的h5，嫁接落地页的下载和转化数据监测等能力，目前仅支持下载类落地页。  

3.3 详细能力介绍，见：[【互动】内嵌互动试玩落地页](https://doc.weixin.qq.com/doc/w3_AekA8QavANwCNHQsCRPITTya5tmpW?scode=AJEAIQdfAAoVw1U1wXAekA8QavANw&isEnterEdit=1)  



5. 选择【配置模板】  

1.1 使用门槛：无，目前已全量开放。  

2.2 配置模板：提供数十套已成型的互动模板，客户仅需替换模板的图片，音乐、文本、视频，交互动作数值等参数，无需开发即可一键生成专属互动页。  

3.3 详细能力介绍，见：[【互动】模板配置创建互动试玩](https://doc.weixin.qq.com/doc/w3_AekA8QavANwCNjIl4cQ68SR06XB2p?scode=AJEAIQdfAAos98wQwhAekA8QavANw&isEnterEdit=1)  



6. 选择【云试玩】  

1.1 使用门槛：头部客户邀请阶段，可联系您所在行业的行业运营  

2.2 云试玩：IAP重度类客户摘取游戏代码片段，在先游平台生成符合SDK的代码包后，客户在官方落地页即可完成落地页生成  

3.3 详细测投接入，见：[腾讯营销-云游戏互动营销测试邀请](https://docs.qq.com/doc/DY3RoWUxMSnBVRXha)  



7. 选择【互动视频】  

1.1 使用门槛：4月底开放头部客户测投，可联系各行业运营进行登记  

2.2 互动视频剪辑台：借助剧情引导拼接生成营销落地页引导下载，可灵活应用于换装场景等互动场景  

3.3 提供经典剧情模板三件套，帮助客户快速创建；同时支持不同行业客户，将内部剧情，场景，任务等进行素图片，音乐，视频等素材进行制作，实现场景还原和前置到营销。
