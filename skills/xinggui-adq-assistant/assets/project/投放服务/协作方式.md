# 客户投放协作

使用形式：在 Codex 对话中调用腾讯 ADQ 投放助手。每个客户使用代称，在 `投放服务/客户项目/<代称>/` 保留方案版本和经用户要求保存的脱敏资料。对话中不用提供真实微信号或手机号名单。

| 阶段 | 你提供及执行 | 助手交付 |
| --- | --- | --- |
| 接客户 | 行业与产品、真实报价、曝光或具体转化目标、名单类型和规模、名单与商家的关系、预算边界 | 整理客户简报，只补问影响决策的信息 |
| 投放前 | 后台目标/出价/人群/预算/版位截图，现有落地页及真实证明素材 | 字段检查清单、首轮设置建议、有依据时给出价试验值、观察及停止条件 |
| 做素材 | 品牌资料、可兑现优惠、真实产品图片或案例 | 对标来源及差异说明，原创广告稿、版式或分镜，落地页承接建议；实际图片与视频制作另行执行 |
| 开始投放 | 人工在后台设置，记录开始时间、素材版本和变更 | 核对最终截图；没有操作证据时不声称广告已发布 |
| 回收数据 | 同一周期的消耗、曝光、点击、实际目标事件；有效线索和成交单独补充 | 指标计算、诊断、下一项调整及验证条件 |
| 后续服务 | 按商定观察条件回传结果 | 更新客户方案，积累有适用条件的历史参考 |

固定输入句式：

> 开始服务客户【代称】：行业【】，产品及价格【】，目标【】，名单【微信号/手机号，规模，与商家的关系】，预算边界【】。附件是后台截图和落地页。请给首轮方案及素材。

> 复盘客户【代称】：统计周期【】，使用方案【版本】，本次变更【】。附件是报表，实际有效线索【】，成交【】。请判断下一步调整。

观察周期由预算、事件数量与转化时滞共同确定，不机械每天改价。没有新增数据时不自动作出效果判断。客户规模较小时多版本会分散样本，可先验证一个关键未知；具备足够样本和可比条件时再比较版本。

API 接入后可替代部分手工报表输入；客户目标、真实卖点及后端成交核对仍需配合。当前没有后台监控或自动定时执行。
