星轨投放助手

安装与使用手册

正式交付版 2.0 · 腾讯 ADQ 投放辅助

星轨投放助手用于腾讯 ADQ 开户准备、投放设置诊断、出价分析、广告创意与投后复盘。客户在支持 Agent Skills 的 AI 助手中安装同一份技能，通过对话提交业务资料、后台截图和报表，获取具体操作建议。

01｜获取与安装

方式一：下载技能包安装

1. 下载“星轨投放助手-通用Skill.zip”。支持 ZIP 导入的 Agent 可直接选择该文件；要求文件夹的 Agent 则先解压。

2. 在 Agent 的技能管理或导入入口，选择压缩包或解压后的 xinggui-adq-assistant 文件夹。文件夹内应包含 SKILL.md、references、scripts、assets。保留完整目录。

3. 完成导入后重新加载技能或新建对话，发送下方启用指令。

使用星轨投放助手。请加载技能规则和配套资料，开始投放服务。

没有图形导入入口、但支持本地文件操作的 Agent，可打开解压目录并发送：

请将当前目录中的 xinggui-adq-assistant 技能安装到你支持的技能目录，保留全部配套资料。已有同名技能时先说明版本及处理方式，完成后加载该技能。

方式二：从 GitHub 安装

适用于能够运行终端命令、已安装 Node.js LTS 和 Git、可以访问 GitHub 与 npm 的环境。仓库发布后，在终端运行：

npx -y skills add tonyliu2525-code/xinggui-adq-assistant --skill xinggui-adq-assistant -g

根据安装器提示选择本机需要使用的 Agent，并选择复制安装或链接安装。复制安装可独立保留文件；链接安装需要保留来源目录。安装器未列出的平台使用方式一。

命令行安装器由 Vercel Labs Skills 项目提供，支持范围与平台原生导入功能分别管理。不要把 --all 理解为所有 AI 产品均可安装。

不同 Agent 的安装入口

使用环境安装操作
Codex、Claude Code、Hermes、Cursor 等支持标准 Skill 的 Agent使用平台技能入口或上述安装命令；重新加载后启用星轨投放助手
WorkBuddy 等支持本地 Skill 的 Agent在平台技能入口导入完整文件夹；也可由具备文件操作权限的 Agent 安装
豆包工作任务模式当前入口提供自定义 Skill 导入时，提交同一个技能包；按页面规定的大小、格式和权限操作
其他支持 Agent Skills 的国内外 Agent导入同一个标准 Skill，目录位置依该 Agent 的文档设置
仅支持附件对话的环境使用包内“附件对话接入”资料完成对话服务；该方式不进行本地技能安装

“支持技能调用”与“允许导入自定义技能”由平台分别决定。平台只开放内置技能、限制包体或不能保留配套文件时，使用附件方式或切换支持完整 Skill 的 Agent。本技能不绕过平台限制。

安装后启用

启用后，助手按任务读取产品说明、工作流程及知识库，并提供服务所需的资料清单。如果没有加载技能，发送技能目录的完整路径，要求读取其中的 SKILL.md。不要只上传单个 SKILL.md 后删除其他资源。

02｜建立客户项目

为每项投放业务建立独立项目目录，用于保存业务简报、方案、素材、报表及修改记录。项目名称使用企业简称或内部项目编号。共享技能目录只保存公共规则与资料。

填写技能包内 assets/project/投放服务/客户投放资料.md，或直接在对话提交下列信息：

信息填写要求
业务与产品行业、实际服务、地区、产品价格、活动条件及承接页面
投放目标曝光、成功添加企微、有效线索或成交；明确本次考核的事件
名单情况微信号或手机号、规模、来源、客户关系、匹配状态及可覆盖人数
预算边界日预算、本轮可接受消耗上限、观察周期及可接受成本
当前配置营销目标、优化事件、计费方式、出价策略、金额与单位、人群及版位
已有结果统计周期、同周期数据、最近调整内容及时间；缺失数据填写“未统计”

不需要提供真实客户号码、账户口令或 API 令牌。证照和截图可遮挡与判断无关的身份信息，保留业务类型、设置字段、单位和状态。

项目启动指令

使用星轨投放助手，建立本次投放项目。项目名称：【】；业务与产品：【】；投放目标及事件定义：【】；名单类型、规模与客户关系：【】；预算及成本边界：【】。附件为业务资料、后台设置和投放数据。请先核对资料，再提交具体执行方案，并列出需要补充的关键信息。

03｜按业务场景使用

开户与资质核对

提交主体类型、实际经营业务、经营范围、业务链接及相关资质。助手提供行业初筛、资料清单、开户路径及需要官方确认的事项。开户资格、流量开放与素材审核分别核对。

使用星轨投放助手，核对本项目的开户路径与所需资质。请依据实际业务及附件，列出资料要求、缺口、官方依据与办理顺序。

曝光投放

提交名单状态、人群设置、版位、预算与同周期曝光或触达数据。助手核对目标及人群范围，提出曝光与触达的观察方案。跨平台曝光和触达口径一致后才计算覆盖率与频次。

使用星轨投放助手，为本项目制定曝光方案。请核对名单挂载、人群拓展、版位和预算，并给出具体设置建议、观察指标及调整条件。

出价与转化诊断

上传完整设置页，包含优化事件、计费、出价策略、金额单位及预算；同时提供系统建议范围或适用历史数据。助手结合成本边界提出出价方案和调整条件。没有参考依据时，先排查配置并安排有限预算的验证方案。

使用星轨投放助手，分析当前出价与转化设置。请说明应保留或修改的具体字段、证据、操作顺序、观察周期和消耗上限。

广告创意与制作

提交真实品牌、产品、价格、活动限制、目标人群、版位及可用图片。助手交付文案、画面布局、图片制作说明或视频分镜。需要媒体成品时，使用当前 Agent 可调用的生成或剪辑工具，完成后核对文字、规格与实际服务承诺。

使用星轨投放助手，根据本项目资料制作两组广告方案。每组包括标题、正文、画面布局、制作要求及落地页承接，并注明对标来源或创作依据。

投后复盘

提交上轮方案、变更记录及同周期报表。曝光、点击、跳转、成功添加企微、有效线索与成交分别统计。助手按证据解释变化，给出保留、调整或停止的建议。

使用星轨投放助手，复盘本项目。附件为上轮方案、设置变更及本期报表。请统一统计口径，说明主要问题、下一轮调整及继续或停止的条件。

04｜截图与报表规范

资料必须保留的内容
设置截图营销目标、优化事件、计费、出价单位、金额、预算、人群挂载、拓展及版位
状态截图账户和广告审核状态、人群匹配状态、异常提示及时间
效果报表统计起止时间、报表层级、币种、消耗、曝光、点击及目标事件
后端结果实际新增企微、有效线索、成交及归因方式；说明与平台回传是否一致
素材与落地页当前广告画面、完整文案、点击后页面及联系或提交入口

字段较多时分多张图提交，保留页面名称。报表按广告或素材拆分时，不直接相加跨行去重触达人数。优先上传 CSV、XLSX 或清晰截图；运行数据脚本时使用包内模板字段。

05｜方案执行与记录

助手提交的建议包含当前判断、证据、后台操作字段、调整理由、观察指标及停止条件。由账户负责人核对并在腾讯后台执行，记录修改时间、字段与修改前后的值。

曝光、点击与真实转化可能采用不同的统计或归因口径。出价目标不等于最终扣费或实际获客成本。涉及腾讯规则的判断引用官方资料名称、原句、链接及时间；与后台现行页面不一致时，按官方现行规则确认。

06｜保存、续接与更新

每轮服务结束后发送：

请生成本项目服务记录，包括已确认业务、当前配置、统计周期、实际数据、本轮判断、已执行调整及时间、观察条件和待补资料。请保存到本项目目录；若当前环境不能保存文件，请输出可复制的完整记录。

再次服务时上传上轮记录和最新数据，发送：

使用星轨投放助手，继续本项目。请读取附件中的服务记录与最新报表，再判断本轮变化及下一步操作。

更换 Agent 或电脑时安装同一个技能，并导入客户项目记录。对话历史和客户资料不随 Skill 自动同步。

更新时下载最新技能包或重新执行 GitHub 安装命令。保留客户项目资料，按安装器提示处理已有版本。出现目录冲突时，先确认原版本位置再更新。

07｜常见问题

情况处理步骤
Agent 未识别技能名称重新加载或新建对话；提供完整技能目录路径并要求读取 SKILL.md
导入提示格式或大小不符查看该入口要求；支持文件夹时解压导入，附件对话时按任务提交包内资料
找不到知识库或素材确认安装的是完整目录，未遗漏 assets；重新导入完整包
图片无法识别上传清晰原图或补充对应字段文字，保留金额单位与状态
不能运行脚本通过截图或表格继续分析；需要自动核算时使用支持 Python 的 Agent
安装命令无法访问网络使用已下载的完整 ZIP；无需为使用本技能购买服务器或域名
新会话没有前次记录上传项目服务记录与最新数据，重新启用星轨投放助手

08｜服务范围

本技能提供开户资料核对、投放设置与出价建议、广告创意和投后复盘。账户开通、充值、改价与广告发布由客户或其授权人员办理。腾讯 API 接入需另行完成开发者权限和账户授权。

同一 Skill 适用于支持标准 Agent Skills 并能够访问配套资源的国内外 Agent。各平台的自定义导入、文件容量、图片理解、脚本执行、联网与媒体生成权限，以客户使用的产品版本和套餐为准。仅提供聊天功能的平台使用附件对话方式。

官方知识资料用于规则核对，现时有效性以腾讯公布的规则为准。公开案例和素材用于参考，来源数据及适用条件分别标注，不构成统一出价标准或效果承诺。广告审核、消耗、触达、线索与成交取决于实际投放及业务承接。

素材商业使用前应确认品牌、图片、音乐与人物授权。本包不赋予第三方原始广告素材的复制使用权。

本地安装无需自建服务器或域名；Agent 的账号、模型与工具额度按对应平台规定执行。
