01豆包：三步开始使用

这里教你在豆包聊天里使用附件资料，不是安装原生 Skill。无需运行命令。

第 1 步：下载，解压

↓ 下载豆包上手资料 · 约 9 KB

下载后，右键 ZIP 选择解压。打开解压后的文件夹。下图圈出要上传的文件，启动指令直接复制本页文字。

第 2 步：填写 03，把 02 和 03 发给豆包

双击“03-客户资料模板.txt”，在对应字段后填写你的业务情况并保存。不知道的填写“未知”。再将下图圈出的两个文件上传到同一个豆包对话。

第 3 步：复制下面的指令，发到同一对话

点击下方指令旁的“复制”（飞书中可选中文字复制），粘贴到刚才上传附件的豆包对话并发送。需要完整规则时，可再复制上手包内 01-启动指令.txt 的正文。

你是星轨投放助手。请先读取我上传的 02-判断规则与产品说明.txt 和 03-客户资料模板.txt，列出实际读到的文件名，概括我的业务和本次目标，再告诉我需要补充哪些关键资料。读不到或内容截断时明确说明。按已读规则分析，不编造官方依据或投放结果。
请先列出你实际读到的附件文件名，再概括我的业务和本次目标。

豆包能准确列出 02、03 并复述你的业务，再开始提问。附件上传失败时，分别打开 02 和 03，将文本分段粘贴到对话并核对已读内容。

上手资料包只有对话规则和模板，不含完整官方知识库。涉及腾讯规则或投后复盘时，再补对应官方原文、截图与同周期报表。豆包原生技能安装尚未验证。

02本地 Agent：运行这一条命令

适用于安装器支持的 Codex、Claude Code、Hermes 等本地 Agent，不适用于豆包聊天。

先安装 Node.js LTS 和 Git。进入目标项目文件夹，打开 PowerShell、命令提示符或终端，复制运行：

npx -y skills add tonyliu2525-code/xinggui-adq-assistant -y

看终端实际安装结果和失败项，然后在对应 Agent 打开该项目并重新加载技能。需访问 npm 和 GitHub；下载超时可改用完整 ZIP。

↓ 下载完整技能包 · 约 150 MB

已有自定义导入入口的 Agent，可按入口要求导入完整 ZIP 或文件夹，并确认能接收约 150 MB 的包体。保留 SKILL.md、references、scripts 和 assets；WorkBuddy 使用其明确提供的本地技能入口。

使用星轨投放助手。请读取 SKILL.md，列出实际读取的资料和当前可用工具。

03提交资料，发起服务

业务简报写清行业、地区、产品价格、本次目标和预算边界。名单只提供类型、来源与规模，无需提供真实号码。没有结果数据就写“未统计”。

使用星轨投放助手。项目：【企业简称】；产品和地区：【】；本次目标：【】；预算与可接受成本：【】。附件为业务资料、后台截图和同周期报表。请先核对已读资料，再给出具体方案及关键缺口。
截图保留页面名称、字段、金额单位和状态。报表保留统计起止时间；分开记录成功添加企微、有效线索和成交。请勿提交账户密码或访问令牌。

04保存记录，下次接着用

请保存本项目服务记录：已确认业务、当前设置、统计周期、实际数据、本轮判断、已执行修改和时间、观察条件及待补资料。不能保存文件时，请输出可复制记录。

下次上传服务记录和最新报表，发送“使用星轨投放助手，继续本项目”。豆包附件对话可用 05-会话交接记录模板.txt 保存记录。

更换 Agent 或电脑时，项目记录需要另行带过去；对话历史和客户资料不会跟着 Skill 自动同步。更新技能前保留项目资料，遇到同名目录先确认冲突。
