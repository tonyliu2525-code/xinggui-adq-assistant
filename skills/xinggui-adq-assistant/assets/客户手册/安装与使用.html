星轨投放助手是一份跨 Agent 的标准 Skill。先在你使用的 Agent 中安装，再提交业务资料开始服务。

01在你的 Agent 中安装技能

你使用的环境

安装方法

使用下面的一条终端命令，自动识别受支持的目标。

WorkBuddy 或其他已有自定义 Skill 导入入口的 Agent

没有自定义 Skill 导入入口的聊天产品

参照文末附件兼容方式；不等同于安装完整技能。

方法 A：一条命令安装

安装 Node.js LTS 和 Git 后，进入目标项目文件夹，在电脑 PowerShell、命令提示符或终端执行。不要把命令发到普通聊天框。

npx -y skills add tonyliu2525-code/xinggui-adq-assistant -y

安装器仅支持其目标列表中的 Agent，不代表所有 AI 产品。需能访问 npm 和 GitHub；本项目已验证远程安装文件完整性，未逐一验证所有客户端内调用。

方法 B：导入完整技能包

↓ 下载完整技能包 · 约 150 MB

在已提供自定义技能导入的 Agent 中选择 ZIP 或解压后的 xinggui-adq-assistant 文件夹。按入口要求核对包体上限，保留 SKILL.md、references、scripts 和 assets。没有导入入口时不要把 ZIP 发到聊天框当作安装。

02启用技能，确认能读到资料

安装后在对应 Agent 打开项目，重新加载技能或新建对话，发送：

使用星轨投放助手。请读取 SKILL.md，列出实际读取的产品说明和配套资料，以及当前可用的工具。

检查助手是否读到实际资料。仅有“安装完成”的回复不能作为证据；读不到资料时先检查安装路径和文件权限。

03提交资料，发起服务

业务简报写清行业、地区、产品价格、本次目标和预算边界。名单只提供类型、来源与规模，无需提供真实号码。没有结果数据就写“未统计”。

使用星轨投放助手。项目：【企业简称】；产品和地区：【】；本次目标：【】；预算与可接受成本：【】。附件为业务资料、后台截图和同周期报表。请先核对已读资料，再给出具体方案及关键缺口。
截图保留页面名称、字段、金额单位和状态。报表保留统计起止时间；分开记录成功添加企微、有效线索和成交。请勿提交账户密码或访问令牌。

04保存记录，下次接着用

请保存本项目服务记录：已确认业务、当前设置、统计周期、实际数据、本轮判断、已执行修改和时间、观察条件及待补资料。不能保存文件时，请输出可复制记录。

下次上传服务记录和最新报表，发送“使用星轨投放助手，继续本项目”。豆包附件对话可用 05-会话交接记录模板.txt 保存记录。

更换 Agent 或电脑时，项目记录需要另行带过去；对话历史和客户资料不会跟着 Skill 自动同步。更新技能前保留项目资料，遇到同名目录先确认冲突。

遇到的情况

下一步

豆包只解释命令

参照第 05 节末尾的附件兼容方式。

ZIP 导入失败

找不到知识库或素材

确认完整 assets 目录仍在，检查 Agent 的文件访问权限。

使用本手册的飞书 ZIP 下载链接。

图片看不清 / 脚本不能运行

补清晰截图或字段文字；可按表格继续分析，不假称脚本已执行。

新对话忘记前次结果

上传上次服务记录及最新资料。

附件兼容方式：以豆包普通聊天为例

  1. 下载解压，填写并保存 03-客户资料模板.txt。
  2. 将 02-判断规则与产品说明.txt 和填写后的 03 上传到同一个对话。
  3. 复制下方指令发送，让助手先确认已读附件。
你是星轨投放助手。请先读取我上传的 02 和 03，列出实际读到的文件名，概括我的业务和目标，再按已读规则分析。读不到或内容截断时明确说明，不编造官方依据。

附件模式只使用已读资料，不自动加载完整知识库。需要时继续补对应官方原文或报表。豆包原生 Skill 安装尚未验证，不能用上面的终端命令安装。
