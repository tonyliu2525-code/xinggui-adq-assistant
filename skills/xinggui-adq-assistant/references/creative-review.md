# 广告素材制作与效果复盘

## 素材输入与交付

先确定客户当前名单处在什么关系、推广的真实产品及报价、可展示的证明、用户下一步动作和实际版位。只补缺少且影响素材的资料；没有客户案例时使用经核实公开案例，或标注算例/推演，不虚构经营结果。

曝光素材强调能识别的品牌与具体场景。转化素材围绕本次有效行动的理由，落地页兑现相同承诺。每个方案只有一个主要动作，区分点击按钮与实际成功添加企微。避免“所有人都能赚钱”“保证复购”等未经证实承诺。

广告与口播使用大白话，每段推进一个意思。遵守项目用户规则：不写排比或隐性排比，不连续疑问，不用自问自答及“不是……而是……”推进；不把案例都套成知识付费或个人 IP。真实行业决定场景。

用户只要求方向时先给核心角度；要求成品时交付对应短标题、主文案、画面/分镜与落地页首屏，不自动给一篇长稿。制作多个版本时让差异对应可检验假设，例如利益点不同，说明保持哪些关键条件可比。不要为了测试改写客户不能兑现的优惠。

图片输出根据实际版位规范与用户品牌素材确定尺寸及安全区域，不预设所有广告都适用同一比例。实际生成图片时使用可用 imagegen 技能。视频提供口播与画面制作稿；生成、拍摄或剪辑是否完成如实说明。

素材审核判断读取该行业和版位的官方原文，列来源与时效；不能只做通用敏感词替换就声称可过审。用户要求商业认知内容时另按项目共创流程处理，不扩大本广告技能的范围。

## 数据输入与口径

优先使用脱敏的分日、分计划、分素材数据，并提供投放期间的配置变更。最少围绕当前诊断环节收集消耗、曝光/去重触达、点击或实际目标事件。后端线索和成交单独记录。

算指标前确认字段定义、时间范围、币种、去重规则及归因窗口：

| 指标 | 算法与前提 |
| --- | --- |
| CPM | 消耗÷曝光×1000；曝光计数已知且非零 |
| CTR | 点击÷曝光；明确点击口径及同周期 |
| 平均点击成本 | 消耗÷点击；不冒充后台计费方式 |
| 有效线索成本 | 消耗÷有效线索；有效线索条件一致 |
| 成交获客成本 | 消耗÷归因成立的新成交客户；老客复购另命名 |
| 名单覆盖率 | 名单内去重触达÷同一批可投名单；不能用全部扩展触达代替 |
| 平均频次 | 同范围曝光÷去重触达；不能用提交成功数替代分母 |

分母为零时标“暂无可计算结果”，不写成本为零或收益无限。平台触达、工具曝光及企微添加来自不同系统时先对齐口径，不能直接拼接。

## 复盘输出

先指出与客户目标相比发生了什么，再解释能被数据支持的原因；假设附下一次验证方式。留资质量、销售跟进和复购时滞未明确时不把成交变化全部归因广告。重复曝光有作用也可能疲劳，依据反馈及频次观察判断。

保留一条简洁客户记录：目标、名单性质与规模、配置、预算边界、素材、观察周期、数据、下一步。仅在用户要求保存时写入指定项目的客户记录，不收录真实手机号或微信号名单。不得以无数据的案例包装“最佳出价模板”。
