# 用户确认的产品事实

以下来自产品负责人本次对话，用作产品上下文；不作为腾讯官方政策认证，也不推断永远有效。最新用户更正优先。

## 当前产品

星轨定向投放工具用于已有客户名单的广告触达。客户购买后自行操作。广告通过腾讯营销投放；具体可用版位须结合该账户行业、广告及官方条件确认，不能从“全生态”推断所有版位必定可投。

落地页可引导跳转企业微信或提交手机号，由商家跟进。名单准确性由客户实际数据决定。产品已演示成功曝光与触达；正式客户转化、复购和成本效果仍在收集。

## 两种名单

微信号：个人资料中可见的微信号，不要求 wxid 原始 ID。用户说明当前投放不产生广告消耗，仅支付工具费用。每个营销账户固定承载最多 200 个微信号，投满后名单不可替换、新增或变更；该批人可重复投放。每轮需单独设置并批量发起；多个账户目前逐户操作。不得按旧 PDF 提供名单替换或自动循环功能。一个主体可有多个账户，用户未确认固定上限，不能写成无限或固定 5 个。

手机号：客户向腾讯官方支付广告费用，需要设置出价。名单匹配、计费、回传和投放门槛须从实际后台及官方原文确认，不沿用旧 PDF 的匹配率、充值门槛或曝光单价。

名单由客户提供，运营者一般不提供批量采集工具。开展投放诊断不需要客户交出真实联系方式，优先接收脱敏截图、名单规模与来源说明。

## 收费与演示

工具按公司主体收年费 2,980 元。同一主体下的多个营销账户不额外收工具费；多个公司主体各付一份。协助开户增加 1,000 元，落地页设计再增加 1,000 元；这两项服务费是否按账户或服务范围收费尚未明确，需要报价时补问，不能沿用旧 PDF 的“每户起”。

客户可以提供自己的微信号，运营者现场投放已有广告，让客户体验曝光。该演示不等于完成购买后的开户交付，也不代表手机号广告实际成效。

工具内可查看曝光；腾讯营销后台可查看触达。具体报表字段和去重口径未确认，不能将提交成功数视为实际触达人数。

截图可见 oCPM、稳定拿量、考核点击，出价 0.4 元/点击，日预算不限，长期全天投放，智能定向与定向拓展的开启显示，以及年龄和性别限制。负责人明确它只用于微信号演示，未用于手机号投放。不可由此推断未来客户应使用同样配置；自定义手机号人群包是否挂载在该截图中未能确认。

## 文档新增但未由用户确认

旧 PDF 介绍了小程序访客 OpenID 定向、LBS 和视频号直播推广。接到相关需求时确认当前工具支持情况，并核对对应官方条件。旧 PDF 的价格、曝光定义和服务承诺不作为当前实绩。
