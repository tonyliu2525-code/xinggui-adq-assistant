# Agent兼容与能力路由

同一标准Agent Skills目录提供全部核心规则、知识库、模板及脚本，不按平台派生不同业务规则。安装依平台技能机制进行；相对路径均以SKILL.md所在目录为基准。

Codex、Claude Code、Hermes、Cursor等可使用支持它们的标准技能安装器或原生技能入口；WorkBuddy使用当前版本的本地技能入口。豆包工作任务模式具备技能调用能力，自定义导入时以实际入口的格式、容量和权限要求为准，不推断所有手机端或桌面端版本都允许导入第三方目录。

Vercel Labs Skills的安装器支持范围独立于平台原生导入；不得保证--all覆盖所有AI产品，不为未证实的入口捏造菜单或目录。对无自定义导入入口但能读附件的环境，使用assets/附件对话接入；不称为已安装Skill。

按本次任务核对文件读取、图片理解、Python、Node、联网和媒体生成权限。不能运行Python时可人工核算，不能运行Node时直接读取索引和官方原文。未看图片、未运行脚本不得声称已完成。资料大于平台限制时按主题读取，不将目录存在当加载成功。

客户操作统一遵循assets/客户手册/安装与使用.md。账户修改、发布及预算执行由客户负责；API接入另需应用权限与账户授权。客户服务记录保存在独立项目，不写进共享技能。
