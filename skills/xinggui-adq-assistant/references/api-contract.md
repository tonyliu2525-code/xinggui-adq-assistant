# 腾讯 API 数据层预留

实现文件：`scripts/delivery_source.py`；配置副本位于项目 `投放服务/API接入配置.example.json`。

当前实现离线 CSV 数据源、标准化报表入口和腾讯数据源的明确未接入状态。没有实现 OAuth、令牌刷新或真实 HTTP 请求。未来必须根据届时官方文档与授权范围实现，不能承诺填一个地址即可接通。

统一能力：`read_configuration(account_id)` 返回配置对象；`read_report(account_id, start, end)` 返回与 `投放数据记录.csv` 同字段的行。腾讯实现目前抛出 NotImplementedError，不返回模拟账户数据。配置读取的离线实现同样明确不支持，以人工截图补充。

接入步骤：确认开发者应用及授权账户→确定接口版本、配置读取和报表权限→映射字段、时间范围、归因窗口、币种和单位→补齐分页与令牌刷新→在获授权账户对照后台核验。认证失败或限流立即停止并反馈；不做绕过或无限重试。名单内去重触达未被端点支持时留空，不用总触达替代。

配置只存环境变量名称和账户代称。真实令牌与应用密钥通过本机凭据或环境变量设置，不放聊天、模板、日志和技能包。只读数据层不含发布广告、改价、上传名单及充值操作。

后续腾讯实现输出标准字段后，可以直接交给现有 `analyze_delivery.py` 计算；配置诊断仍须保留原始字段和来源。官方 SDK 可作为适配基础：https://github.com/TencentAd/marketing-api-go-sdk 。具体支持范围届时核对。
